# v4.8.7 正式版验证 / Stable release verification

- 基线为 v4.8.6。主程序、启动器、更新器和开发者工具使用产品版本 4.8.7 和文件版本 4.8.7.0（`ApplicationReleasePolicyTests` 检查开发者工具的版本与主程序一致）。
- 本地 `scripts\test-all.ps1` 全部通过，没有警告：Core 1988、DataStore 24、UpdateAgent 33、EndfieldLaunch 47，覆盖率门槛均达到。代码风格检查无问题。`new-release-notes.ps1 -Version 4.8.7` 生成的发布正文里每个链接都指向 v4.8.7 标签。
- **界面测试**：在这次的构建上一次运行全部 131 个界面测试，全部通过。
- **Windows 11 磁贴（#160）**：
  - `DiscoverabilityTests` 新增：第二次选择同一个功能时直接使用（组合预设视图打开、不再画框），第一次选择的功能会保存；Tab / Shift+Tab 在磁贴分组之间切换。原有的磁贴、搜索、带你过去和上手清单测试仍然通过。
  - 测试辅助 `AppSession.OpenSearch()` 在窗口刚启动、Ctrl+K 没有送达时会聚焦窗口再按一次（以前 `CommandPalette_OffersTheDeveloperTools` 偶尔失败的原因）。
  - 英文深色界面下手动截图检查了打开动画（第一次和之后的打开各一组帧）、完成后的开始屏幕，以及背景的三种透明度；用户选定较薄的模糊亚克力。
- **未在本地做**：从 v4.8.6 升级和回滚的演练（`test-preview-upgrade.ps1` 需要已发布的 v4.8.6 安装包）。GitHub Actions Release 会对最终标签执行测试、构建、界面测试、升级与回滚演练、打包和构建来源证明。
- **尚未核对**：浅色主题、高对比度主题（需要更改系统设置）和俄语界面下的新磁贴；82 个功能逐个“直接使用”的实际效果；4.8.6、4.8.5、4.8.4 和 4.8.3 列出的核对项。见[已知问题](../releases/v4.8.7.md#已知问题)。

The v4.8.7 release is based on v4.8.6. The app, launcher, updater and Developer Tools use version 4.8.7 (`4.8.7.0`); a unit test checks that the tools match the app.

- Local `test-all` passed all four suites (Core 1988, DataStore 24, UpdateAgent 33, EndfieldLaunch 47) and the coverage gates with no warnings. The style check found nothing. `new-release-notes.ps1 -Version 4.8.7` builds the release body, and every link in it points at the v4.8.7 tag.
- UI tests: one full run of all 131 on this build; all passed.
- Windows 11 tiles (#160):
  - New in `DiscoverabilityTests`: picking a feature a second time uses it (the presets view opens and no ring is drawn), and a first pick is saved; Tab and Shift+Tab move between groups of tiles. The existing tile, search, take-me-there and First steps tests still pass.
  - The test helper `AppSession.OpenSearch()` focuses the window and presses Ctrl+K again when the first press, right after start-up, did not arrive (the cause of the occasional `CommandPalette_OffersTheDeveloperTools` failure).
  - Checked by hand in screenshots (English, dark): the opening animation (frames of a first and a later opening), the finished start screen, and three backdrop strengths; the user chose the thin blurred acrylic.

The upgrade and rollback rehearsal from v4.8.6 was not run locally; the tagged release workflow runs it.

Not yet checked:
- the new tiles in the light theme, a high-contrast theme (that needs a system setting changed) and Russian;
- "using" each of the 82 features directly in real use;
- the checks listed for 4.8.6, 4.8.5, 4.8.4 and 4.8.3.

See [Known issues](../releases/v4.8.7.md#known-issues).
