# v4.7.2 正式版验证 / Stable release verification

基线：v4.7.1（f9e7bc0）加 #84（角色目录请求超时与重试）和本次版本号更新。主程序、启动器和更新器的文件版本与产品版本统一为 4.7.2.0 / 4.7.2。

## 发布要求

- 四组件完整测试与覆盖率门槛通过，Release 构建无警告，代码风格检查无问题。
- 精确源码提交通过 GitHub Build and Test；最终包检查版本、源码指纹、运行程序集哈希、许可证、文件清单与用户状态排除。
- 隔离执行 4.7.1 公开包自带的更新器覆盖升级到 4.7.2：仓库、在线偏好、本地标签、组合预设、状态槽位、备份与快照保留，新版启动；旧版目录副本回退后哈希一致。
- 公开附件重新下载并核对 SHA-256。

最终测试数量、CI 链接与运行程序集哈希见包内 `PACKAGE-INFO.json`。

## 本版改动的验证范围

- 8 项新单元测试：仓库 Wiki 地址优先、为空或无效时才用游戏内置地址；卡住的请求超时后重试成功；网络错误重试一次后放弃；调用方取消或其他错误不重试。
- 界面冒烟测试 19 项通过。
- 在真实应用中探测：原神、星铁、绝区零都加载出完整 Wiki 目录；一次绝区零请求卡住后超时重试成功；Wiki 地址为空的原神仓库改用游戏内置地址发出请求。

## 未验证 / 已知问题

- 未在最初报告问题的电脑上验证；卡住的原因（CDN 节点）未当场证实。
- 4.7.1 已知问题不变。
