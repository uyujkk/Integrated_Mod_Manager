## 已知问题与边界

- 曾发生 `Microsoft.UI.Xaml.dll / 0xc000027b` 原生闪退，原始转储不足，根因未确认。已修正独立复现的图片缓存竞争并增加本地诊断与窗口关闭后的回调检查，不能据此认定原生闪退已根治。
- 旧更新器使用过深临时目录时可能触发 .NET Framework 路径长度限制。验收在较短路径下通过；未修改 Windows 系统设置。
- 作者管理搜索是当前游戏的本地收藏／访问记录搜索；作品文字与安装状态筛选只作用于当前页。
- 不支持字节断点续传、作者更新提醒、全站作者名称检索、旧库自动分配角色、更新差异预览或重复空间管理。
- 尚未验证真实游戏运行、XXMI／EFMI 加载与 UAC 行为；不保证第三方 Mod／加载器的账号安全。
