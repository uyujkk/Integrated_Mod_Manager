# v4.8.2 正式版验证 / Stable release verification

- 基线为 v4.8.1。主程序、启动器和更新器使用产品版本 4.8.2 和文件版本 4.8.2.0。
- 本地 `scripts\test-all.ps1` 全部通过：Core 1930、DataStore 24、UpdateAgent 33、EndfieldLaunch 47，覆盖率门槛均达到。同一构建上的界面测试 79/79 通过，代码风格检查无问题。`package-stable-release.ps1` 用这次的测试结果打包成功，`new-release-notes.ps1` 生成了发布说明正文。
- **浮窗（#134）**：
  - `OverlayLayoutPolicy` 的单元测试覆盖按显示器恢复位置、显示器拔掉后的回退、缩放换算、贴边和高度适配。
  - 界面测试覆盖以下内容：高度跟随内容，并且全尺寸和紧凑模式下都没有内容被裁掉；在浮窗里选择测试窗口，以及发送开关和状态圆点的变化；⋯ 菜单里的设置；重启后保持大小和位置；状态图标的名称和全文。
  - 发布包副本用真实鼠标操作过，以一个测试窗口为目标：快捷键开关、拖动、调整大小、贴边、从菜单开启鼠标穿透并用快捷键恢复、选择目标窗口。
  - 中英俄 × 浅色、深色的截图在 150% 缩放下拍摄。100% 缩放需要改系统设置，没有拍。
- **在线点赞（#132）**：`GameBananaWeb` 的单元测试覆盖允许的地址、端口、子域名、用户信息、相似域名和 IDN、非 Mod 路径，以及删除登录数据时的链接和占用文件。内嵌页面在离线样例模式下检查，所有请求都由样例应答。没有登录任何真实账号。
- **设置与切页（#135）**：
  - 界面测试覆盖以下内容：“新功能”和更新说明里的 Discord 按钮；展开卡片后分组留在原栏（在 4.8.1 的代码上会失败）；仪表盘的入门提示随页面隐藏和显示。
  - 切页耗时在 120 Hz 显示器上，用真实鼠标点击侧栏、在线页使用公开的真实数据测得，没有登录。
- **未在本地做**：从 v4.8.1 升级和回滚的演练（`test-preview-upgrade.ps1` 需要已发布的 v4.8.1 安装包）。GitHub Actions Release 会对最终标签执行测试、构建、界面测试、升级与回滚演练、打包和构建来源证明。
- 新浮窗和点赞尚未在真实游戏和真实账号中核对，见[已知问题](../releases/v4.8.2.md#已知问题)。

The v4.8.2 release is based on v4.8.1. Local `test-all` passed all four suites and the coverage gates; 79 UI tests passed on the same build; the style check found nothing; the stable package script and the release-body script ran on these results.
- Overlay: unit tests for per-display placement, UI tests, a real-mouse check of the package with a test window, and screenshots in three languages and both themes at 150%.
- Likes: rule tests for the embedded page, and checks in offline sample mode; no real account was used.
- Settings and page switching: UI tests, and switch timings with live public Online data on a 120 Hz display.

The upgrade and rollback rehearsal from v4.8.1 was not run locally; the tagged release workflow runs it. The overlay and likes are not yet checked in a real game or with a real account; see [Known issues](../releases/v4.8.2.md#known-issues).
