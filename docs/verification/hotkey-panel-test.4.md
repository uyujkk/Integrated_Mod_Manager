# 快捷键面板 test.4 验证

日期：2026-10-21（America/New_York）。基线 51e24db / test.3。未发布，不覆盖用户测试目录、正式版或游戏文件。

## 用户反馈（test.3）

以管理员身份运行后游戏内输入可用（诊断记录 sender/target 均为 0x3000，DownAccepted/UpAccepted=1，按下状态为真）。反馈三点问题：状态变化导致列表跳动、需要浮窗透明度、部分识别到的快捷键不能选。

## 修改

- 列表跳动：主窗口状态、角色跟随状态（约每 700 毫秒更新）以及浮窗的 Mod、目标、发送状态、提示文字原先为自动换行、高度可变，位于列表上方，行数变化会推动列表。现改为固定高度（单行或固定行数），超出部分显示省略号，悬停显示全文。
- 透明度：最初使用 WS_EX_LAYERED 整窗 alpha，但文字会一起变淡（用户反馈）。改为只调背景：透明 SystemBackdrop + 内容背景画刷 alpha + DwmEnableBlurBehindWindow（空区域，不模糊）。实测：仅透明 backdrop 时透明像素合成为黑色；DwmExtendFrameIntoClientArea 显示为系统浅灰边框色；分层窗口 alpha 255 仍为黑色；空区域 blur-behind 才真正显示桌面。10% 背景下桌面清晰可见，文字保持不透明。范围 10%–100%，主窗口与浮窗滑块同步，保存为 ShortcutOverlayOpacity。滑块仅在 Loaded 后响应 ValueChanged。
- 标题栏：原系统标题栏为白色。改为 ExtendsContentIntoTitleBar，自绘深色标题行并设为拖动区域，系统关闭按钮背景透明、前景浅色。
- 字体颜色：所有浮窗文字与按钮共用一个画刷，主窗口“浮窗字体颜色”提供 6 个常用色和取色器，保存为 ShortcutOverlayTextColor（#RRGGBB）。
- 默认尺寸：按 DPI 换算为 420×860 DIP，高度不超过工作区；此前 400×580 物理像素在高 DPI 下过小。
- 按键识别（按 3DMigoto 语义）：补全 `/`、`[`、`]`、`=`、`'`、`\`、反引号等标点键，以及 CAPITAL、NUMLOCK、SCROLL、OEM_102；最后一个键之前的普通键作为按住键（最多 3 个普通键）；`no_` 可排除任意键，发送前会检查这些键是否被按住。显示名称不再出现 `NO VK RETURN`。
- 新增 `ShortcutKeyPlan.Explain`，返回不可发送的原因（鼠标、手柄、未知键名、条件矛盾、键过多、系统组合键）；按钮上显示中文原因和原始 `key =` 写法，并可隐藏不可发送的绑定（ShortcutHideUnsupported）。
