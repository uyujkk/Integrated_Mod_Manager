# v4.6.0 正式版验证 / Stable release verification

基线：v4.5.2（af1792c）加 #32–#50（手册与软件结构文档，以及全部页面重新设计：页面基础、设置、总览、更新、命令面板与侧栏、快捷键、在线、Mod 仓库与详情、更新页列表）以及本地预览版不再改写软件更新设置的修复。主程序、启动器和更新器的文件版本与产品版本统一为 4.6.0.0 / 4.6.0。

## 发布要求

- 四组件完整测试与覆盖率门槛通过：合计 1470 项，0 失败、0 跳过；Release 构建 0 警告；代码风格检查无问题。
- 精确源码提交通过 GitHub Build and Test；最终包检查版本、源码指纹、运行程序集哈希、许可证、文件清单与用户状态排除。
- 隔离执行 4.5.2 公开包（SHA-256 与 GitHub 附件一致）自带的更新器覆盖升级到 4.6.0：仓库、在线偏好、本地标签、组合预设、状态槽位、备份与快照保留，新版启动；旧版目录副本回退后哈希一致。
- 公开附件重新下载并核对 SHA-256。

最终测试数量、CI 链接与运行程序集哈希见包内 `PACKAGE-INFO.json`。

## 本版功能的验证范围

- 新增的布局策略、视图模型与列表规则（总览、设置外观、命令面板搜索、在线排序与分页、Mod 列表与角色列表、详情摘要、仓库设置步骤、更新页列表与列高）均有单元测试。
- 各页面在中文界面、浅色主题下用演示数据在全屏和约 1400 DIP 窗口中检查；更新页用 24 个已追踪 Mod 和 22 条下载记录检查筛选、搜索和不整页滚动。演示数据检查后已删除。
- 预览版不改写更新设置：保存规则有单元测试（无自身更新的构建写回读取到的值，正式版写入当前值）；配置读写的接入经代码审查和构建验证，未用实际预览版包走一遍。

## 未验证 / 已知问题

- 真实游戏中的保存前 F10 与按键发送、真实导出的变体文件导入未验证。
- #15 在线详情页原生闪退仍未复现。
- 从 4.5.2 升级时运行的是 4.5.2 的更新器。
- 使用手册的截图和部分位置说明仍按 4.5.2 界面编写。

## English summary

Baseline: v4.5.2 (af1792c) plus #32–#50 (manuals and the software structure document, and every page redesigned) and the fix that stops local preview builds from rewriting the app update settings. File/product version 4.6.0.0 / 4.6.0. All 1470 tests pass with coverage gates and 0 build warnings; the style check has no findings. Release requirements are CI for the exact commit, package checks, an isolated upgrade by the 4.5.2 public package's updater (data kept, hash-matched rollback copy), and SHA-256 checks of the public assets. New layout policies and view models are unit-tested; pages were checked in the Chinese UI with the light theme on demo data. The preview settings fix is unit-tested at the policy level and code-reviewed in the config wiring, not run with an actual preview package. Not checked: some pages in English or dark theme, the stacked Updates layout below 900 px, the Updates badge, the dashboard character jump, real-game F10 and key sending, real variant files; #15 is still unreproduced; the user guides still show the 4.5.2 layout.
