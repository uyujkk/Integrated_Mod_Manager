# v4.6.0 release verification / 正式版验证

Baseline: main `bdf3a61` plus the reviewed local v4.6.0-preview.1 preparation. Version policy is stable (4.6.0 / 4.6.0.0), with application self-update enabled and saved preferences honored. Source, tests and tools retain the existing layout.

基线：main `bdf3a61` 加本地 v4.6.0-preview.1 的整理。版本策略为正式版（4.6.0 / 4.6.0.0），启用软件更新并遵循已保存的偏好；源码、测试和工具保留现有目录结构。

## Release gates / 发布门槛

- Run all four test suites and their coverage gates, the code-style check and Release/x64 build. The preview had 1,468 passing tests; the stable version must run its own checks.
- Run GitHub Build and Test for the exact release commit. Its URL, commit, runtime hash, source fingerprint and actual test totals are recorded in the final package's PACKAGE-INFO.json.
- Use the public v4.5.2 package's own updater in an isolated fixture. Verify active-library tags and filters, repository settings, online preferences, combination presets, nonempty persistent slots, backups and snapshots. Confirm the new runtime starts and matches the package. Restore the complete old copy and compare its version, runtime hash and configuration.
- Check package contents, user-state exclusion, MIT/AGPL/NOTICE material and SHA-256. Publish only after local, CI and upgrade checks pass; download the public attachments again and compare bytes and hashes.

- 四组完整测试、组件覆盖率、代码风格和 Release/x64 构建均须通过。预览版通过 1,468 项；正式版独立重跑。
- 对精确发布提交运行 GitHub Build and Test。最终包 PACKAGE-INFO.json 记录 CI 链接、提交、运行程序集哈希、源码指纹和实际测试数量。
- 在隔离副本中使用公开 v4.5.2 自带更新器，验证活动库标签与过滤器、仓库设置、在线偏好、组合预设、非空状态槽位、备份和快照；验证新版启动并与包一致，恢复完整旧版副本后核对版本、运行文件及配置。
- 检查包内容、用户状态排除、MIT／AGPL／NOTICE 和 SHA-256；本地、CI、升级门槛通过后发布，重新下载公开附件核对大小及哈希。

## UI and real-environment scope / 界面与真实环境范围

The local preview was exercised through Windows UI automation in a synthetic repository: dashboard, repository workspace, online list loading, updates, shortcuts and settings, Ctrl+K search/navigation, the stable local-update prompt, and visible tags after an upgrade. Stable packaging changes version/channel metadata and release copy; its startup and upgrade paths are checked again.

本地预览通过 Windows 界面自动化检查合成仓库下的首页、仓库工作区、在线列表加载、更新、快捷键、设置、Ctrl+K 搜索跳转、正式版本地更新提示和升级后标签显示。正式版主要调整版本通道与发布文案，并再次检查启动及升级路径。

These checks do not establish real-game input behavior, the XXMI/EFMI launch chain, real Mod-library deployment/import behavior or account safety. F10 hot apply and online automatic translation remain experimental; real exported variant files remain unverified. Issue #15 remains unconfirmed fixed.

以上检查不代表真实游戏按键、XXMI／EFMI 完整启动链、真实 Mod 库部署导入或账号安全已验证。F10 热应用和在线自动翻译仍为实验功能，真实导出变体文件仍待验证；#15 未确认修复。
