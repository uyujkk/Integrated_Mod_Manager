The v4.8.6 release is based on v4.8.5. The app, launcher, updater and Developer Tools use version 4.8.6 (`4.8.6.0`); a unit test checks that the tools match the app.

- Local `test-all` passed all four suites (Core 1988, DataStore 24, UpdateAgent 33, EndfieldLaunch 47) and the coverage gates with no warnings. The style check found nothing. `new-release-notes.ps1 -Version 4.8.6` builds the release body, and every link in it points at the v4.8.6 tag.
- UI tests: one full run of all 129 on this build; all passed.
- Easier-to-find features (#157):
  - `DiscoverabilityTests` cover:
    - the detailed style's start screen of tiles (group headings, the first tile saying where it is, no Settings group, arrow keys and the line saying where a tile is, typing on a tile turning into a search);
    - the brief style listing no features before anything is typed; features found by another word (such as d3dx_user);
    - picking a feature opening its page and outlining the place: Organize existing mods in Repositories, Undo in Updates › Install and recovery, Search style in Settings, and the deployment option inside the dashboard's paths group;
    - the search style setting being saved;
    - the First steps card: done tasks have no button, opening the search and the Shortcuts page tick their tasks off, a task's button takes you to its place, Hide is saved, and the search shows the card again;
    - page tips showing only the first time and staying closed after a restart; the title bar's help button.
  - `VisibleEntryPointTests` cover the character heading's buttons, save for later on Online cards and in the details, save author in the details, and the open-folder button on each Updates row; `StateSlotTests` cover the Rename button beside the slot list.
  - The first-install smoke test and the page-switching test now check the First steps card (it does not pop up or take the focus, and it shows and hides with the dashboard).
  - The start screen, wide tiles, the frame around the selected tile and the First steps card were checked by hand in screenshots (Chinese, dark). The README's search screenshot was taken from this build with the synthetic samples (see the [screenshot notes](../assets/screenshots/README.md)).

The upgrade and rollback rehearsal from v4.8.5 was not run locally; the tagged release workflow runs it.

Not yet checked:
- the new interface in a high-contrast theme (that needs a system setting changed);
- screenshots of the Russian interface, and a native speaker's review of the Russian texts;
- the checks listed for 4.8.5, 4.8.4 and 4.8.3.
