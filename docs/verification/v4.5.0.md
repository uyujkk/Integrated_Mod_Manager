# v4.5.0 正式版验证 / Stable release verification

基线：v4.4.0 之上合并的 #20–#25（角色头像、多选、状态槽位变体、F10 热应用、窗口与快捷键改进、新功能入口）。v4.5.0-preview 测试包只在本地分发、关闭了软件自身更新，未公开发布。主程序、启动器和更新器的文件版本与产品版本统一为 4.5.0.0 / 4.5.0。

## 发布要求

- 四组件完整测试与覆盖率门槛通过：Core 1204、数据存储 24、更新器 32、终末地启动 47，合计 1307 项，0 失败、0 跳过；Core 行覆盖 94.0%、分支 87.6%。WinUI x64 Release、启动器与更新器构建 0 警告；代码风格检查（IDE0005）无问题。
- 精确源码提交通过 GitHub Build and Test；最终包检查版本、源码指纹、运行程序集哈希、许可证、文件清单（使用 `\` 分隔）与用户状态排除（含 `WinUI3\snapshots\`）。
- 隔离执行 4.4.0 公开包自带的旧更新器覆盖升级到 4.5.0：配置、仓库与备份保留，新版启动；旧版目录副本回退后哈希一致。
- 公开附件重新下载并核对 SHA-256，发布说明中英文分开编排。

最终测试数量、CI 链接与运行程序集哈希见包内 `PACKAGE-INFO.json`；隔离升级和公开附件证据留在发布产物目录。

## 本版功能的验证范围

- 角色头像、多选开关、状态槽位（保存、更新、重命名、写入 Mod 默认值及回滚、变体文件导入（待验证）、整份 `d3dx_user.ini` 快照）：核心逻辑有单元测试；用户在真实仓库（终末地 EFMI，4 个角色文件夹）中以管理员身份运行测试包，确认功能正常、达到预定目标。
- F10 热应用：用 `scripts/fake-3dmigoto-loader.ps1` 模拟加载器在 F10 时先保存、再读取 `d3dx_user.ini`，确认只读窗口内写入的值被读取、属性随后恢复；测试方法见 [状态槽位与 F10 热应用测试](../development/State-Slots-Hot-Apply-Testing.zh-CN.md)。
- 测试包中发现并在发布前修复：置顶浮窗打开时空引用闪退（#24）；列表标题被重建导致头像和多选按钮不显示（#25）；新功能提示按构建版本显示成“v4.4.0”（#25）；CI 上较新的 SDK 以 C# 14 编译导致 `Reverse()` 绑定变化，`LangVersion` 固定为 12。
- 游戏窗口自动识别与最大化还原比例有单元测试，并在本机 150% 缩放下实测窗口尺寸。
- 移除启动时的终末地启动升级引导；手动打开启动设置时仍会静默导入旧独立桥接器的设置。

## 未验证 / 已知问题

- F10 热应用未在真实 3DMigoto／XXMI 加载器下做自动化验证，依赖其默认的 F10 保存再读取行为；独占全屏和其他游戏下的按键送达未逐一验证。
- #15 在线详情页原生闪退仍未复现。
- 从 4.4.0 升级时运行的是 4.4.0 的更新器。
- 真实游戏下 XXMI／EFMI 完整启动链及 UAC 未完整验证。

## English summary

Baseline: #20–#25 merged on top of v4.4.0 (character avatars, multi-select, state slot variants, F10 hot apply, window and shortcut improvements, more visible entry points). The v4.5.0-preview test builds were shared locally only, with app self-update off. The app, launcher and updater use file/product version 4.5.0.0 / 4.5.0.

- All four suites pass with coverage gates: 1307 tests (Core 1204, data store 24, updater 32, Endfield launch 47), 0 failures, 0 skips; Core line coverage 94.0%, branch 87.6%. Release builds have 0 warnings and the IDE0005 style check is clean.
- Release requirements: CI for the exact commit, package checks (version, source fingerprint, runtime hash, licenses, managed-file list with `\` separators, user-state exclusion including `WinUI3\snapshots\`), an isolated upgrade by the 4.4.0 public package's updater with configuration, repositories and backups preserved and a hash-matched rollback copy, and SHA-256 checks of the public assets. Final numbers, the CI link and hashes are in `PACKAGE-INFO.json`.
- Features: core logic is unit tested; a user ran the test build as administrator against a real Endfield EFMI repository and confirmed the features work as intended. F10 hot apply was checked with the simulated loader in `scripts/fake-3dmigoto-loader.ps1`. Fixed during testing: an overlay crash (#24), header buttons hidden by the rebuilt list header (#25), what's new titled by build version (#25), and a C# 14 binding change on CI (`LangVersion` pinned to 12).
- Not verified / known issues: F10 hot apply under a real 3DMigoto/XXMI loader is not automated, and key delivery in exclusive full screen and other games is not checked one by one; #15 is still unreproduced; upgrades from 4.4.0 run the 4.4.0 updater; the full XXMI/EFMI launch chain and UAC in a live game remain unverified.
