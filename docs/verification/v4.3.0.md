# v4.3.0 正式版验证 / Stable release verification

基线：v4.3.0-preview.1（fc26d8f）。本次转正式版统一版本为 4.3.0 / 4.3.0.0，恢复遵循用户偏好的软件更新检查，同步正式版打包和双语发布说明；保留预览版功能及验证边界。

发布要求：完整运行 scripts/test-all.ps1；Core、Data、Updater、EndfieldLaunch 四组测试和覆盖率门槛全部通过；主程序、启动器、更新器版本一致。精确提交必须通过 GitHub Build and Test。

scripts/package-stable-release.ps1 检查四组件结果、运行文件版本、源码清单与指纹，包含 AGPL/MIT 许可证及组件 NOTICE，排除用户配置、日志、缓存与 PDB。发布前在隔离副本验证旧版覆盖升级、配置保留和回退；上传后重新下载公开 ZIP 核对 SHA-256。最终结果与 CI 链接见包内 PACKAGE-INFO.json、验证状态.md 及 GitHub Release。

本次不启动真实游戏，不适配用户实际 XXMI/EFMI 配置。真实游戏、UAC、真实 Mod 库联接清理及压缩包导入界面流程仍未验证。Microsoft.UI.Xaml.dll / 0xc000027b 根因与旧更新器深路径限制仍存在。正式发布不代表游戏运营方认可或账号安全保证。
