# v4.5.2 正式版验证 / Stable release verification

基线：v4.5.1（56b9b58）加 #29（浮窗保存前发送 F10、浮窗刷新、多按键提速、中性名称与功能标记、`src/`/`tests/`/`tools/` 结构）和 #30（根目录文档整理、主页与截图）。主程序、启动器和更新器的文件版本与产品版本统一为 4.5.2.0 / 4.5.2。

## 发布要求

- 四组件完整测试与覆盖率门槛通过：合计 1312 项，0 失败、0 跳过；Release 构建 0 警告；代码风格检查无问题。
- 精确源码提交通过 GitHub Build and Test；最终包检查版本、源码指纹、运行程序集哈希、许可证、文件清单与用户状态排除。目录调整后，安装包的文件结构与 4.5.1 相同（仅新增文档）。
- 隔离执行 4.5.1 公开包自带的更新器覆盖升级到 4.5.2：配置、仓库与备份保留，新版启动；旧版目录副本回退后哈希一致。
- 公开附件重新下载并核对 SHA-256。

最终测试数量、CI 链接与运行程序集哈希见包内 `PACKAGE-INFO.json`。

## 本版功能的验证范围

- 保存前发送 F10：核心等待逻辑有单元测试（写入稳定才返回、超时不保存、从不设置只读、发送失败直接报错）；用模拟加载器接收器验证实际发送 F10、捕获最新参数、接收器忽略 F10 时超时不保存、热应用结束后才保存，以及缺少参数时的本地化提示。未在真实游戏中验证。
- 浮窗刷新与多按键提速：用合成 Mod 验证链接替换后跟随新 Mod、停用后清空旧按键、手动刷新发现新 Mod；在 100／200／300 个绑定下测量扫描缓存和按钮复用。代码审查后修复两处回归（未设置 `d3dx_user.ini` 时组合预设被拒绝；刷新会改掉主窗口里从未启用过的 Mod 的选择），这两处修复以代码审查和构建验证，未做界面操作验证。
- 名称与功能标记、目录结构和文档链接：全部 Markdown 相对链接检查无失效；打包后的根目录文件与链接已核对。
- CI 中一个等待写入的测试在高负载机器上偶发超时，已放宽时限并让模拟写入在文件被短暂占用时重试，检查内容不变。

## 未验证 / 已知问题

- 真实游戏中的保存前 F10 和真实导出的变体文件导入未验证。
- #15 在线详情页原生闪退仍未复现。
- 从 4.5.1 升级时运行的是 4.5.1 的更新器。

## English summary

Baseline: v4.5.1 (56b9b58) plus #29 (F10 before overlay saves, overlay refresh, faster many-binding Mods, neutral names and labels, `src/`/`tests/`/`tools/` layout) and #30 (root documents moved, homepage and screenshots). File/product version 4.5.2.0 / 4.5.2. All 1312 tests pass with coverage gates and 0 build warnings. Release requirements are CI for the exact commit, package checks (the package layout matches 4.5.1 apart from added documents), an isolated upgrade by the 4.5.1 public package's updater with a hash-matched rollback copy, and SHA-256 checks of the public assets. F10-before-save was checked with unit tests and a simulated loader receiver, not in a real game; two review fixes were verified by code review and build only; real exported variant files remain unverified; #15 is still unreproduced.
