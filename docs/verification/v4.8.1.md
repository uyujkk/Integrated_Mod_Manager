# v4.8.1 正式版验证 / Stable release verification

- 基线为 v4.8.0。主程序、启动器和更新器使用产品版本 4.8.1 和文件版本 4.8.1.0。
- #129 的基础测试覆盖分类树、请求排序参数和分类文件夹规划。在线页回归使用离线样例验证一级分类和子分类切换，包括「武器 → 全部 → 角色」。独立仓库连接真实 GameBanana 后，已检查首次加载和重启后的窗口响应。
- 在 Windows 11 25H2 用同一动作对照拖拽最大化的修复前后画面，并检查按钮最大化和还原。用 300 个模拟 Mod 的仓库对照了侧栏切页耗时。
- GitHub Actions Release 对最终标签执行测试、WinUI x64 构建、UI 测试、从 v4.8.0 升级和回滚、打包与构建来源证明。发布包内的 `PACKAGE-INFO.json` 记录最终测试结果和构建来源。

The v4.8.1 release is based on v4.8.0. Local checks covered category requests and folder planning, offline Online-page navigation, live GameBanana loading in an isolated repository, Windows 11 drag-to-maximize, and sidebar navigation in a synthetic 300-Mod repository. The tagged release workflow builds and tests the exact source, rehearses an upgrade from v4.8.0 and rollback, and attests the package. See [Known issues](../releases/v4.8.1.md#known-issues) for the validation limits.
