# v4.5.1 正式版验证 / Stable release verification

基线：v4.5.0（fa672e8）加 #27（浮窗命名并保存单 Mod 预设）。主程序、启动器和更新器的文件版本与产品版本统一为 4.5.1.0 / 4.5.1。

## 发布要求

- 四组件完整测试与覆盖率门槛通过：合计 1307 项，0 失败、0 跳过；Release 构建 0 警告；代码风格检查无问题。
- 精确源码提交通过 GitHub Build and Test；最终包检查版本、源码指纹、运行程序集哈希、许可证、文件清单与用户状态排除。
- 隔离执行 4.5.0 公开包自带的更新器覆盖升级到 4.5.1：配置、仓库与备份保留，新版启动；旧版目录副本回退后哈希一致。
- 公开附件重新下载并核对 SHA-256。

最终测试数量、CI 链接与运行程序集哈希见包内 `PACKAGE-INFO.json`。

## 本版功能的验证范围

- 浮窗保存单 Mod 预设：在合成数据的隔离副本中，通过 UI 自动化和真实键盘输入验证：保存的槽位只含该 Mod 已保存的持久参数；同名（不区分大小写）被拒绝；取消不保存；缺少参数时不保存并提示；对话框关闭后浮窗恢复不抢焦点。未在真实游戏中验证。
- 其余功能的验证范围与已知问题同 [v4.5.0](v4.5.0.md)。

## English summary

Baseline: v4.5.0 (fa672e8) plus #27 (name and save a single-Mod preset from the overlay); file/product version 4.5.1.0 / 4.5.1. All 1307 tests pass with coverage gates and 0 build warnings. Release requirements are CI for the exact commit, package checks, an isolated upgrade by the 4.5.0 public package's updater with a hash-matched rollback copy, and SHA-256 checks of the public assets. The overlay preset flow was checked in an isolated copy with synthetic data through UI Automation and real keystrokes, not in a real game. Other scope and known issues are as in [v4.5.0](v4.5.0.md).
