# 快捷键面板 test.6 验证

日期：2026-10-22（America/New_York）。基线 b95ba85 / test.5。未发布，不覆盖用户测试目录、正式版或游戏文件。

## 功能取舍

浮窗不激活、不抢焦点，适合点击，不适合输入文字或多步确认。按“游戏运行中是否安全”筛选：

- 加入浮窗：切换 Mod、开启／暂停发送、保存组合预设（只读捕获）。
- 不加入：恢复组合预设与状态槽位（需关闭游戏和加载器后写入）、仓库与路径、在线浏览下载、导入、冲突检测、启动设置。

## 修改

- 浮窗头部：Mod 下拉框（与主窗口双向同步）、目标窗口一行、“发送：开／关｜保存预设｜隐藏”三等分按钮、不透明度一行、两行状态。所有行固定高度。
- 发送开关：浮窗可开启，但没有在主窗口选择目标窗口时拒绝并提示。
- 保存预设：抽出 CaptureCombinationProfileAsync 共用核心；浮窗版无对话框，空组合直接拒绝，结果和错误写入状态行。
- 联接部署：ModDeploymentLinks.IsLinkTo 判断部署目录是否为指向自身源 Mod 的联接；是则跳过副本 INI 校验（同一文件），指向其他位置仍拒绝。主窗口保存同样受益。
- 终末地启动设置：内容 Grid 固定高度（原为 MaxHeight，超出对话框可用高度后下方内容被裁且无滚动条）；风险确认移到启动方式下；结果区移到底部并可关闭；开关文字缩短、说明另起可换行文字；路径标签最大 150 并换行；操作按钮文字可换行。

## 实测（临时副本，用户配置与仓库只读）

- 修改前复现：内容在“游戏与加载器”后被裁，检查／许可证／风险确认不可见；点击“检测配置”后结果插入顶部，风险提示被截半。
- 修改后：中文与英文下风险确认可见；滚动到底部可见检查按钮与“许可证与源码”，滚动条显示；检测结果固定在底部“运行结果”区，设置区不移动；英文长标签换行。
- 浮窗（界面自动化）：在浮窗选择 Arcane Azure Sea 后主窗口同步；未选目标时开启发送被拒绝并提示；保存预设成功：4 个 Mod、211 个参数（写入临时副本配置）。修复前同一操作报联接错误。
