## Publication gates and boundaries

Release procedure requires the exact source commit on main to pass GitHub Build and Test before publication,
then uploads only the main ZIP and exact matching sidecar. The release is intended as stable/Latest,
using the existing user-controlled update channel. Public download bytes and checksum must be checked after publication.

No real-game rendering, EFMI adaptation/recovery, UAC or account-safety outcome was verified.
Successful tests, startup and checksums do not establish game-operator approval or protection against account penalties.
