# v4.2.0 正式版验证记录

日期：2026-10-18。正式版统一版本与更新通道，保留 4.2 的现有功能和旧发布附件。

## 发布检查

- 完整本地测试、Core／数据存储／更新器覆盖率门槛，以及 WinUI Release/x64、启动器和更新器构建必须通过。
- 更新策略测试验证正式版检查能力可用，用户保存的开启／关闭偏好保持生效。
- 对应源码先通过合并请求 CI，合并 main 后再验证 main 推送的 CI；正式标签指向通过检查的精确 main 提交。
- 用 4.1.1 原更新器升级最终 ZIP，核对仓库、浏览记录、作者收藏、标签、筛选、下载历史、备份和原 Mod 保留，并验证升级后的原生窗口和更新入口。
- 包含版本、源码提交、CI 链接、文件指纹、运行文件哈希和测试结果；排除用户配置、缓存、备份、日志、诊断、转储和 PDB。
- 上传正式 ZIP 与同名 SHA-256 后，从公开链接重新下载核对字节和校验值，并确认 Latest 为 v4.2.0。

最终检查状态以该标签的 Release 和 GitHub Actions 为准。4.2 功能验收背景见 [preview.3 验证记录](v4.2.0-preview.3.md)。

## 验证边界

原 `Microsoft.UI.Xaml.dll / 0xc000027b` 闪退根因仍未确认，旧更新器深路径限制仍保留，真实游戏／加载器和 UAC 行为未验证。发布为正式版不会将上述问题改写为已解决，也不表示获得游戏运营方认可或账号安全保证。
