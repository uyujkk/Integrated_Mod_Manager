# v4.3.1 正式版验证 / Stable release verification

基线：本地修复提交 4371c3e（4.3.1-test.1）；正式版恢复软件自身更新，文件版本与产品版本统一为 4.3.1.0 / 4.3.1。Mod 更新修复的独立复现及实测记录见 [问题与修复](v4.3.1-update-fix.md)。

发布要求：四组件完整测试与覆盖率门槛通过，WinUI、启动器与更新器构建通过，精确源码提交通过 GitHub Build and Test。最终包检查版本、源码指纹、运行哈希、许可证、文件清单与用户状态排除。隔离执行旧版更新器覆盖升级、配置与备份保留、回退检查；公开附件重新下载核对 SHA-256。

v4.3.0 因频率切换崩溃撤出正式更新通道，标记为 prerelease，保留标签和附件并添加警告，旧附件改名加 WITHDRAWN- 前缀使标准 ZIP 地址返回 404；准备期间 latest 回到 v4.2.0，v4.3.1 发布完成后 latest 应唯一指向 v4.3.1。已安装程序、缓存信息和已下载的旧包无法远程撤回。

v4.3.1 发布说明按“中文”“English”两个独立部分编排，均包含 4.3.0 问题、4.3.1 修复、完整 4.3 功能、许可证、升级与已知问题。发布后逐字比对远端说明，检查标签、Latest 与两个附件摘要。

最终测试数量、CI 链接与运行程序集哈希见包内 PACKAGE-INFO.json；隔离升级和公开附件证据留在发布产物目录。真实游戏、完整 XXMI/EFMI/UAC 链路仍未验证。
