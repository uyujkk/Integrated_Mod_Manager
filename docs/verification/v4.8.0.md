# v4.8.0 正式版验证 / Stable release verification

基线：v4.7.3（a93d6e7）加 #93（ZIP 条目路径检查）、#94–#104 和 #110–#112、#117–#125（界面拆分 J0–J8、外观改进和收尾第 1–3 步）、#102（返回仪表盘时闪退）、#113–#116（数据安全修复，对应 #105–#109）和本次版本号更新。主程序、启动器和更新器的文件版本与产品版本统一为 4.8.0.0 / 4.8.0。

## 发布要求

- 由 GitHub Actions 的 Release 工作流对版本标签的精确提交完成：四组件完整测试与覆盖率门槛、Release 构建、打包检查（版本、源码指纹、运行程序集哈希、许可证、文件清单与用户状态排除）。
- 从最新的已发布版本（4.7.3）隔离执行覆盖升级与回退。
- 生成构建来源证明，创建草稿发布；发布前由维护者审阅，公开附件重新下载并核对 SHA-256。

最终测试数量、CI 链接与运行程序集哈希见包内 `PACKAGE-INFO.json`。

## 本版改动的验证范围

- **数据安全修复**：#105–#109 的复现测试改为检查修复后的结果（`Reproduce_SingleToggleCanRemoveItsOwnSource`、`Reproduce_StartupPreviewCleanupDeletesThroughAJunction`、`Reproduce_CopyPresetRemovesUnrelatedSameNamedFolder`、`Reproduce_RenameCharacterLeavesDeployedJunctionAndProfileAtOldPath`，后者包括重启后再检查和复制模式记录）。核心库新增的测试覆盖路径重叠（含目录联接）、预设图片清理不进入链接、四种链接扫描结果、复制记录的认领与外部文件夹、重命名的撤销日志与失败回滚。
- **界面拆分**：每一步都先补测试再移动代码，部署、移除、复制记录、重命名迁移、删除检查、组合预设恢复、状态槽位保存、F10 时机、在线请求内容与缓存、下载安装结果和角色目录结果由单元测试和界面测试核对不变。界面测试从 20 个增加到 66 个，包括在各页面之间往返切换、语言和主题切换、设置在关闭前保存、在线页样例模式下的列表、详情、筛选和角色目录结果。
- **外观**：每一步在相同会话中与改动前的构建对比整窗截图（中文、英文、俄语 × 浅色、深色 × 1400×900、1000×800，部分步骤另含最大化和 670×530），差异只出现在有意修改的地方。
- **真实鼠标操作**：每一步的发布包副本都用真实鼠标切换页面、语言和主题；在线页切换角色、打开详情、按下载并在第一个对话框取消（不实际下载）；Mod 工作区部署、移除、预设预览和重命名。
- **速度**：启动时间（`startup.log`，每种起始页 7 次取中位数）在收尾第 1 步降低约 80–120 毫秒，第 2、3 步没有变慢；页面切换和在线页切换角色的耗时在各步骤记录。
- **“新功能”对话框**：`WhatsNewPolicyTests` 覆盖全新安装不显示、从 4.7 升级只显示一次。

## 未验证 / 已知问题

- 发布说明“尚未在真实游戏中核对的功能”所列 9 项（权限提示、按键发送、全局快捷键、无边框窗口下的浮窗、自动对比度、F10 热切换、从浮窗保存预设、角色跟随、自动保存间隔）只在模拟环境中验证。
- 高对比度主题、讲述人和键盘 Tab 顺序没有逐页手动检查；新增俄语文字未经母语者审校。
- 在线详情页偶发闪退（#15）仍未复现。

## English summary

Baseline: v4.7.3 (a93d6e7) plus #93 (ZIP entry path check), #94–#104, #110–#112 and #117–#125 (UI split J0–J8, appearance work and finishing steps 1–3), #102 (crash returning to the Dashboard), #113–#116 (data-safety fixes for #105–#109) and this version bump; file/product version 4.8.0.0 / 4.8.0. Release requirements: the GitHub Actions Release workflow builds the exact tagged commit with all four test suites and coverage gates, package checks, an isolated upgrade from 4.7.3 with rollback and a provenance attestation, and creates a draft that the maintainer reviews; public assets are re-downloaded and checked against SHA-256. Change scope: the #105–#109 reproduction tests now check the fixed behaviour, with new Core tests for each fix; every UI-split step added tests before moving code and kept deploy, remove, copy records, rename migration, delete checks, preset restore, state-slot saves, F10 timing, online requests, downloads and the character catalogue unchanged (UI tests 20 → 66); full-window screenshots were compared with the previous build in all three languages and both themes at each step; each step's package was driven with the real mouse (the Online download stopped at its first dialog); startup is about 80–120 ms faster and not slower after steps 2 and 3; `WhatsNewPolicyTests` covers first installs and the 4.7 to 4.8 upgrade. Not covered: the nine real-game checks listed in the release notes, a page-by-page pass with high contrast, Narrator and Tab order, a native-speaker review of the new Russian text, and the unreproduced Online details crash (#15).
