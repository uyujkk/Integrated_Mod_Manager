# v4.4.0 正式版验证 / Stable release verification

基线：v4.3.1（f071d45）之上的快捷键面板分支，test.3–test.9 的逐版记录见 `hotkey-panel-test.3.md` 至 `hotkey-panel-test.9.md`。正式版恢复软件自身更新，主程序、启动器和更新器的文件版本与产品版本统一为 4.4.0.0 / 4.4.0。

## 发布要求

- 四组件完整测试与覆盖率门槛通过：Core 1009、数据存储 24、更新器 30、终末地启动 47，合计 1110 项，0 失败、0 跳过；Core 行覆盖 96.1%、分支 88.5%。WinUI x64 Release、启动器与更新器构建通过。
- 精确源码提交通过 GitHub Build and Test；最终包检查版本、源码指纹、运行程序集哈希、许可证、文件清单（使用 `\` 分隔）与用户状态排除。
- 隔离执行 4.3.1 旧更新器覆盖升级到 4.4.0：配置、仓库与备份保留，新版启动；旧版目录副本回退后哈希一致。
- 公开附件重新下载并核对 SHA-256，发布说明中英文分开编排并逐字比对。

最终测试数量、CI 链接与运行程序集哈希见包内 `PACKAGE-INFO.json`；隔离升级和公开附件证据留在发布产物目录。

## 本版功能的验证范围

- 快捷键面板：用户在终末地中确认，管理器以管理员身份运行时按键可被游戏接收；普通权限下的拦截提示与“以管理员身份重启”已实测。浮窗透明度、字体颜色、Mod 切换、预设保存、中英文界面在隔离副本中实测。发布前修正：默认 420 DIP 宽度下浮窗按钮的英文文字（“Input: off”“Save preset”）被截断。
- #14、#16、#6 的复现与修复验证见 `hotkey-panel-test.9.md`：预览图保留新增 6 项测试；更新器在 182～185 个字符的安装目录完成升级与强制回滚；按需创建角色文件夹新增 21 项测试并在界面实测单项下载。
- 首次 CI 运行中终末地启动测试偶发失败：一个测试类故意持有全局“启动运行中”互斥体，另一个类并行保存设置时被拒绝。测试程序集改为不并行运行，产品代码不变。
- 主页截图来自独立 4.4.0 Release 副本和模拟仓库，说明见 `docs/assets/screenshots/README.md`。

## 未验证 / 已知问题

- #15 在线详情页原生闪退仍未复现（20 轮 ProcDump 监视下的自动化操作未触发）。
- 其他游戏、独占全屏和各类 Mod 对模拟按键的处理未逐一验证；批量下载的新建角色文件夹流程未单独界面实测。
- 从 4.3.1 升级时运行旧更新器，深路径限制仍在；本版更新器之后的升级才支持超长路径。
- 真实游戏下 XXMI／EFMI 完整启动链及 UAC 未完整验证。

## English summary

Baseline: the shortcut-panel branch on top of v4.3.1 (f071d45); per-build records are in `hotkey-panel-test.3.md` through `hotkey-panel-test.9.md`. The stable build re-enables app self-update, and the app, launcher and updater use file/product version 4.4.0.0 / 4.4.0.

- All four suites pass with coverage gates: 1110 tests (Core 1009, data store 24, updater 30, Endfield launch 47), 0 failures, 0 skips. Release builds succeed.
- Release requirements: CI for the exact commit, package checks (version, source fingerprint, runtime hash, licenses, managed-file list with `\` separators, user-state exclusion), an isolated upgrade from the 4.3.1 updater with configuration, repositories and backups preserved and a hash-matched rollback copy, and SHA-256 checks of the public assets. Final numbers, the CI link and hashes are in `PACKAGE-INFO.json`.
- Shortcut panel: a user confirmed in Endfield that keys arrive when the manager runs as administrator; the non-elevated warning and elevated restart were exercised. Overlay opacity, text colour, Mod switching, preset saving and both UI languages were exercised in an isolated copy. Fixed before release: English overlay button labels were cut off at the default 420 DIP width.
- Not verified / known issues: #15 is still unreproduced; other games, exclusive full screen and individual Mods are not checked one by one; batch-download folder creation wasn't UI-tested separately; upgrades from 4.3.1 still run the old updater with its deep-path limit; the full XXMI/EFMI launch chain and UAC in a live game remain unverified.
