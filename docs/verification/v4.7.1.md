# v4.7.1 正式版验证 / Stable release verification

基线：v4.7.0（017247b）加 #81（4.7 文档）、#82（更新器改用 .NET 8 构建）和本次版本号更新。主程序、启动器和更新器的文件版本与产品版本统一为 4.7.1.0 / 4.7.1。

## 发布要求

- 四组件完整测试与覆盖率门槛通过，Release 构建无警告，代码风格检查无问题。
- 精确源码提交通过 GitHub Build and Test；最终包检查版本、源码指纹、运行程序集哈希、许可证、文件清单与用户状态排除。
- 隔离执行 4.7.0 公开包自带的更新器覆盖升级到 4.7.1：仓库、在线偏好、本地标签、组合预设、状态槽位、备份与快照保留，新版启动；旧版目录副本回退后哈希一致。
- 用 4.7.1 包自带的新更新器（改名复制后运行）再做一次同样的升级与回退。
- 公开附件重新下载并核对 SHA-256。

最终测试数量、CI 链接与运行程序集哈希见包内 `PACKAGE-INFO.json`。

## 本版改动的验证范围

- 更新器：同一份源码的几种构建在 VirusTotal 上的结果——4.7.0 的 csc 构建 5/71；补信息、清单和优化 5/63；.NET 8 单文件含 Windows Forms 1/64（但需要桌面运行时）；不含 Windows Forms 1/71；最终版本 1/70（只有 DeepInstinct）。
- 新更新器只依赖 `Microsoft.NETCore.App`，与主程序相同；32 项更新器单元测试通过。
- #82 合并前已用含新更新器的试打包验证：新更新器改名复制后完成升级与回退；4.6.1 公开包的更新器也能安装含新更新器的包。

## 未验证 / 已知问题

- DeepInstinct 仍判为可疑；其他杀毒软件和 GameBanana 自己的扫描结果以实际上传为准。
- 4.7.0 已知问题不变：真实游戏中的 XXMI 启动、全屏鼠标穿透、自动对比度、恢复“默认”槽位、批量操作、自动保存间隔、分享方案导入、保存前 F10 与按键发送未验证；移到核心库的在线请求未对真实服务器逐项检查；#15 仍未复现。

## English summary

Baseline: v4.7.0 (017247b) plus #81 (4.7 docs), #82 (the updater built with .NET 8) and this version bump; file/product version 4.7.1.0 / 4.7.1. Release requirements: all four test suites with coverage gates, 0 build warnings and a clean style check; CI for the exact commit; package checks; an isolated upgrade by the 4.7.0 public package's updater and another by the 4.7.1 package's own updater from a renamed copy, both keeping data with a hash-matched rollback; SHA-256 checks of the public assets. VirusTotal for the updater variants: 5/71 (4.7.0), 5/63 (metadata and manifest), 1/64 (.NET 8 with Windows Forms, needs the desktop runtime), 1/71 (without Windows Forms), 1/70 for the final build (DeepInstinct only). The new updater needs only `Microsoft.NETCore.App`. DeepInstinct still flags it; the 4.7.0 real-game limits are unchanged.
