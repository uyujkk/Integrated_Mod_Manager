# v4.6.1 正式版验证 / Stable release verification

基线：v4.6.0（814c168）加 #55（快捷操作文字与部署按钮）、#56（新 Mod 默认槽位、浮窗读取未变化的参数文件）、#57（排版与显示修复）以及设置页反馈 QQ 群。主程序、启动器和更新器的文件版本与产品版本统一为 4.6.1.0 / 4.6.1。

## 发布要求

- 四组件完整测试与覆盖率门槛通过：合计 1478 项，0 失败、0 跳过；Release 构建 0 警告；代码风格检查无问题。
- 精确源码提交通过 GitHub Build and Test；最终包检查版本、源码指纹、运行程序集哈希、许可证、文件清单与用户状态排除。
- 隔离执行 4.6.0 公开包（SHA-256 与 GitHub 附件一致）自带的更新器覆盖升级到 4.6.1：仓库、在线偏好、本地标签、组合预设、状态槽位、备份与快照保留，新版启动；旧版目录副本回退后哈希一致。
- 公开附件重新下载并核对 SHA-256。

最终测试数量、CI 链接与运行程序集哈希见包内 `PACKAGE-INFO.json`。

## 本版功能的验证范围

- 默认槽位：默认值读取、新 Mod 判断和语言改名规则有单元测试。演示副本中，首次扫描只记录已有的 10 个 Mod；新加入的 Mod 得到“Default · 2”（`$outfit = 1`、`$hat = 0`）；切换到中文后显示“默认”。
- 浮窗读取现有文件：以不处理按键的测试窗口作为 F10 目标。5 秒后出现新的对话框；“只读取现有文件”保存成功，“取消”不保存并提示未保存。
- 排版修复：在演示副本中检查中文和英文、深色和浅色主题、1600 DIP 和 860 DIP 宽窗口，以及运行中切换语言。
- 反馈 QQ 群：设置页显示群号 1041384622，复制按钮写入剪贴板并在状态行提示。

## 未验证 / 已知问题

- 真实游戏中的浮窗保存（含读取现有文件）、保存前 F10 与按键发送、真实导出的变体文件导入未验证。
- 侧栏“更新”入口的可更新数量徽标需要联网检查出更新才会出现，未检查；快捷键页未选窗口时的通用权限说明未在界面上看到。
- #15 在线详情页原生闪退仍未复现。
- 从 4.6.0 升级时运行的是 4.6.0 的更新器。

## English summary

Baseline: v4.6.0 (814c168) plus #55 (quick-action labels and the deploy button), #56 (Default slot for new Mods; overlay saves from an unchanged parameter file), #57 (layout and display fixes) and the feedback QQ group in Settings. File/product version 4.6.1.0 / 4.6.1. All 1478 tests pass with coverage gates and 0 build warnings; the style check has no findings. Release requirements are CI for the exact commit, package checks, an isolated upgrade by the 4.6.0 public package's updater (data kept, hash-matched rollback copy), and SHA-256 checks of the public assets. The default slot and overlay flow were checked in a demo copy (the overlay with a key-ignoring test window as the F10 target); layout fixes in Chinese and English, dark and light themes, 1600 and 860 DIP and a runtime language switch; the QQ group row and its copy button. Not checked: real-game overlay saves, F10 and key sending, real variant files, the Updates badge and the game-neutral privilege note; #15 is still unreproduced.
