# v4.7.0 正式版验证 / Stable release verification

基线：v4.6.1（3a1bdfd）加 #61–#80，取代预览 v4.7.0-preview.1。主程序、启动器和更新器的文件版本与产品版本统一为 4.7.0.0 / 4.7.0。

## 发布要求

- 四组件完整测试与覆盖率门槛通过，Release 构建无警告，代码风格检查无问题；19 个界面自动化测试通过。
- 精确源码提交通过 GitHub Build and Test；最终包检查版本、源码指纹、运行程序集哈希、许可证、文件清单与用户状态排除。
- 隔离执行 4.6.1 公开包自带的更新器覆盖升级到 4.7.0：仓库、在线偏好、本地标签、组合预设、状态槽位（允许新增“默认”槽位，原有槽位不变）、备份与快照保留，新版启动；旧版目录副本回退后哈希一致。
- 公开附件重新下载并核对 SHA-256。

最终测试数量、CI 链接与运行程序集哈希见包内 `PACKAGE-INFO.json`。

## 本版功能的验证范围

- 预设图片、框选、浮窗外观与鼠标穿透、首次安装、XXMI 启动、“默认”槽位、批量操作：见 [v4.7.0-preview.1 的说明](../releases/v4.7.0-preview.1.md)，在演示环境和单元测试中验证；鼠标穿透有界面测试。
- 分享方案：格式、不可信输入检查、4 MB 上限（导出与导入一致）和预览匹配有单元测试；组合预设页的按钮有界面测试。
- 自动对比度：亮度判断与阈值间隔有单元测试。
- 审查修复 #74–#78：XXMI 配置、默认槽位重试、分享大小上限、图片大小上限有单元测试；删除 Mod 时无法确认链接的分支只经代码检查。
- 在线请求（角色目录、GameBanana、HoYoWiki、终末地官网、翻译、图片、下载数、软件更新）有模拟网络的单元测试。
- 界面：仓库页、设置页两种布局、在线页布局切换、更新页检查间隔、快捷键页输入方式有界面自动化测试。

## 未验证 / 已知问题

- 真实游戏中的 XXMI 启动、全屏下的鼠标穿透、恢复“默认”槽位、批量操作、自动保存间隔、自动对比度、分享方案导入、保存前 F10 与按键发送未验证；管理员权限下的文件选择未在真实环境确认。
- 移到核心库的在线请求未对真实服务器逐项检查。
- #15 在线详情页原生闪退仍未复现。
- 从 4.6.1 升级时运行的是 4.6.1 的更新器。

## English summary

Baseline: v4.6.1 (3a1bdfd) plus #61–#80, replacing the v4.7.0-preview.1 preview. File/product version 4.7.0.0 / 4.7.0. Release requirements: all four test suites with coverage gates, 0 build warnings, a clean style check and 19 UI automation tests; CI for the exact commit; package checks; an isolated upgrade by the 4.6.1 public package's updater with data kept (added Default slots allowed, existing slots unchanged) and a hash-matched rollback copy; SHA-256 checks of the public assets. The preview features are covered as described in the preview notes; preset sharing, auto contrast, the #74–#78 fixes (except the delete branch, checked by reading the code) and the moved online requests have unit tests; the repository, settings, online, updates and shortcuts pages have UI tests. Not checked in a real game: XXMI launches, click-through in full screen, restoring Default slots, batch actions, the auto-save interval, auto contrast, importing a shared preset, F10 and key sending; elevated file dialogs and the moved online requests against the real servers; #15 is still unreproduced.
