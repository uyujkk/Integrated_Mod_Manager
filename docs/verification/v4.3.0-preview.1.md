日期：2026-10-21。基线为 v4.2.0（`3071465`），包含合并请求 #12 和版本更新提交。

## 发布检查

- 在 Windows 上运行 `scripts/test-all.ps1`：全部测试、各组件覆盖率门槛，以及 WinUI Release/x64、启动器和更新器构建必须通过，且三者版本一致（文件版本 4.3.0.0，产品版本 4.3.0-preview.1）。
- 对应源码提交须先通过 GitHub Build and Test；`scripts/package-prerelease.ps1 -ForGitHubPrerelease` 只接受干净的工作区和该次 CI 链接。
- 发布包必须包含 `WinUI3/licenses` 中的 MIT、AGPL-3.0、组件 NOTICE 和 LICENSING，根目录附 `LICENSING.md` 与 `LICENSE-AGPL-3.0.txt`；必须排除用户配置、缓存、备份、日志、诊断和 PDB。
- 更新策略测试确认预览版关闭软件自身的自动更新；发布为 GitHub 预发布，不会成为 `releases/latest`，v4.2.0 用户不会被提示升级。
- 上传 ZIP 和同名 SHA-256 后，从公开链接重新下载，并核对字节和校验值。
