The v4.8.4 release is based on v4.8.3. The app, launcher, updater and Developer Tools use version 4.8.4 (`4.8.4.0`); a unit test checks that the tools match the app.

- Local `test-all` passed all four suites (Core 1991, DataStore 24, UpdateAgent 33, EndfieldLaunch 47) and the coverage gates with no warnings. The style check found nothing.
- UI tests: a full run of all 125 on the same build had 124 pass. `DeveloperToolsEntryTests.CommandPalette_OffersTheDeveloperTools` once did not find the title bar's search box. An earlier run stopped at its first failure, which was `PageHostTests.Pages_MadeLaterShowTheCurrentLanguageAndTheme(shortcuts)`. Both tests passed in two more runs on their own. This branch changes only version numbers, docs and the What's New text, none of which those tests exercise, so both failures are treated as timing flakes.
- Online page (#151):
  - The four `OnlineFilterTests` cover:
    - the chips and removing one chip;
    - Clear all, which also resets the category, sort and Show;
    - the buttons' accessible names and tooltips;
    - the narrow-window category drop-down.
  - The existing Online tests passed: category selection, character filter, details, narrow window and a failed load.
  - #151's before and after screenshots cover zh and en, light and dark, wide and narrow, with and without filters.
  - The README's Online screenshot was retaken from this build with the synthetic samples (see the [screenshot notes](../assets/screenshots/README.md)).

The upgrade and rollback rehearsal from v4.8.3 was not run locally; the tagged release workflow runs it.

Not yet checked:
- the new Online page in a high-contrast theme (that needs a system setting changed);
- screenshots of the Online page in Russian;
- the real-game and real-account checks listed for 4.8.3.
