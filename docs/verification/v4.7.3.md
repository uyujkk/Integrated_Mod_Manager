# v4.7.3 正式版验证 / Stable release verification

基线：v4.7.2（e8cc2f4）加 #86（界面语言改为文件）、#91（俄语界面与布局修复）、#87–#90（CI、测试与依赖更新）和本次版本号更新。主程序、启动器和更新器的文件版本与产品版本统一为 4.7.3.0 / 4.7.3。

## 发布要求

- 由 GitHub Actions 的 Release 工作流对版本标签的精确提交完成：四组件完整测试与覆盖率门槛、Release 构建、打包检查（版本、源码指纹、运行程序集哈希、许可证、文件清单与用户状态排除）。
- 从最新的已发布版本（4.7.2）隔离执行覆盖升级与回退。
- 生成构建来源证明，创建草稿发布；发布前由维护者审阅，公开附件重新下载并核对 SHA-256。

最终测试数量、CI 链接与运行程序集哈希见包内 `PACKAGE-INFO.json`。

## 本版改动的验证范围

- `UiTextResourceTests`：每个语言文件只使用英文已有的键，占位符不超出英文；`ru-RU.json` 覆盖全部 1625 个键。`UiLanguagePolicyTests`：系统语言为 `ru`/`ru-RU` 时选择俄语，配置值往返一致。
- 逐条脚本核对俄语译文与英文的占位符、带格式的占位符（如 `{0:MM-dd HH:mm}`）以及首尾空格和换行。
- 在应用的测试副本中切换到俄语，以 1400×900 和 1000×800 检查仪表盘、“新功能”对话框、Mod 工作区（文件、封面、预设）、在线、更新、快捷键和设置各分区；发现的截断已修复并重新检查。同尺寸下与英文界面对比。

## 未验证 / 已知问题

- 俄语译文未经母语者审校。
- 游戏内浮窗、只在操作过程中出现的对话框和带真实数据的在线列表未在俄语下逐一检查。
- 窗口很小时部分工具栏溢出，英文界面相同。
- 4.7.2 已知问题不变。

## English summary

Baseline: v4.7.2 (e8cc2f4) plus #86 (file-based UI languages), #91 (Russian interface and layout fixes), #87–#90 (CI, tests and dependency updates) and this version bump; file/product version 4.7.3.0 / 4.7.3. Release requirements: the GitHub Actions Release workflow builds the exact tagged commit with all four test suites and coverage gates, package checks, an isolated upgrade from 4.7.2 with rollback and a provenance attestation, and creates a draft that the maintainer reviews; public assets are re-downloaded and checked against SHA-256. Change scope: language-file and language-policy tests, a scripted placeholder and whitespace check of every Russian text, and a check of the main pages in Russian at 1400×900 and 1000×800 compared with English. Not covered: a native-speaker review, the in-game overlay, dialogs shown only during actions, and online lists with real data.
