# 集成化 Mod 管理器 v3.6.1 详细用户手册

> 适用于 Windows 10/11 x64。工具作者：uyujkk。
>
> 本项目是非官方同人工具，与 XXMI、游戏发行商或相关开发者没有隶属、授权、认可或赞助关系。

[English User Guide](./User-Guide.en.md) | [中文快速手册](../快速使用手册.md) | [完整更新日志](../CHANGELOG.md) | [最新发布版](https://github.com/uyujkk/Integrated_Mod_Manager/releases/latest)

## 1. 软件用途

集成化 Mod 管理器用于把分散保存的 Mod 整理成多个独立仓库，并把选中的完整 Mod 文件夹复制到游戏或加载器实际读取的目标文件夹。它还提供压缩包导入、图片与来源链接、快捷键说明、在线 Mod 浏览和下载、更新追踪、配置方案、冲突检查、安装回滚、下载任务中心、软件更新和诊断报告。

界面左侧依次是：

| 模块 | 用途 |
| --- | --- |
| 仪表板 | 查看仓库、Mod 数量和路径状态，创建或切换仓库 |
| 仓库 | 管理本地两层目录、复制切换、预览图、链接和快捷键说明 |
| 在线 | 按角色浏览 GameBanana Mod，查看详情、图片、要求并下载 |
| 更新 | 管理配置方案、冲突与回滚、下载任务、已追踪 Mod 更新 |
| 设置 | 调整语言、主题、动效、在线分类、更新、备份和诊断功能 |

## 2. 安装、启动与升级前准备

### 2.1 系统要求

- Windows 10 1809 或更高版本，推荐 Windows 11。
- 64 位 Windows（x64）。
- 在线浏览、翻译、更新检查和 GitHub 报告需要网络连接。
- 发布包为自包含 WinUI 3 应用，普通用户不需要安装 Visual Studio 或 .NET SDK。

### 2.2 安装与启动

1. 从 [GitHub Releases](https://github.com/uyujkk/Integrated_Mod_Manager/releases/latest) 下载 `Integrated_Mod_Manager-vX.X.X.zip`。
2. 完整解压到一个可写文件夹，不要直接在压缩包内运行。
3. 保留 `ModFolderCopier.exe`、`LocalUpdateAgent.exe` 和 `WinUI3` 目录的相对位置。
4. 双击 `ModFolderCopier.exe`。

当前程序未使用商业代码签名证书，SmartScreen 可能显示“发布者未知”。请只从本项目 Releases 下载，确认来源后使用“更多信息”决定是否运行；不要为此关闭 Microsoft Defender。

## 3. 仓库与目录结构

每个仓库保存一套独立设置：仓库名称、Mod 存储文件夹、目标文件夹、可选启动器、在线来源和分类 ID、Wiki 地址及备注。适合为不同游戏、加载器或测试环境分别建仓库。

推荐目录结构：

```text
Mod 存储文件夹
├─ 角色或分类 A                 <- 第一层
│  ├─ Mod A1                   <- 第二层，实际复制单位
│  └─ Mod A2
└─ 角色或分类 B
   └─ Mod B1
```

- 第一层是分类目录，例如角色、服装类型或游戏版本。
- 第二层是完整 Mod 文件夹，程序对它执行复制、移除、预览和信息记录。
- 目标文件夹通常是 XXMI 或游戏读取的 `Mods` 目录。
- 仪表板卡片可双击切换仓库；仓库编辑按钮用于修改路径和在线分类。

## 4. 本地 Mod 管理

### 4.1 首次配置

1. 在仪表板新建仓库，或编辑默认仓库。
2. 设置“Mod 仓库”为两层目录的根目录。
3. 设置“目标文件夹”为游戏或加载器实际读取的目录。
4. 可选选择启动器 EXE，例如 XXMI Launcher。
5. 点击“刷新目录”，然后依次选择第一层分类和第二层 Mod。

### 4.2 第一层文件夹

- 搜索框按名称过滤分类。
- 右上角“+”按钮创建新分类。
- 编辑按钮重命名当前分类。
- 分类列表显示包含的第二层 Mod 数量。

### 4.3 第二层 Mod 与复制切换

- 单击选择 Mod，右侧会刷新预览、链接、快捷键和复制状态。
- 双击 Mod 或点击顶部复制按钮执行切换。
- 目标文件夹没有同名目录时，复制完整第二层文件夹。
- 目标文件夹已有同名目录时，再次操作会移除目标中的同名 Mod。
- 垃圾桶按钮删除源仓库中的选中 Mod；这是独立操作，执行前会要求确认。
- 复制、移除及配置方案切换前会建立事务备份；失败时自动回滚。

### 4.4 压缩包导入

支持以下常用格式：

```text
.zip  .zipx  .7z  .rar  .cab
.tar  .tar.gz  .tar.bz2  .tar.xz  .tar.zst
.gz   .tgz     .bz2      .xz      .zst
```

导入方法：

- 先选择第一层分类，再点击“导入到当前选中文件夹”。
- 也可以把压缩包拖到第二层区域。
- 在线下载完成后，程序会创建独立 Mod 目录并自动解压。

`.zip` 使用内置解压；`.7z`、`.rar`、`.zipx`、`.cab` 使用发布包内的 7-Zip；`tar` 系列使用 Windows `tar.exe`。加密、损坏或非常规分卷压缩包可能无法处理。

### 4.5 预览图与来源链接

程序优先查找 `preview.*`、`cover.*`、`thumbnail.*`、`image.*`，找不到时尝试显示 Mod 文件夹中的第一张支持图片。支持 PNG、JPG、JPEG、BMP、GIF 和 WebP。

选择第二层 Mod 后，可将图片拖到预览区设为该 Mod 的预览图。预览区下方的链接字段为每个 Mod 单独保存来源地址，“打开链接”会调用系统默认浏览器。

### 4.6 快捷键与功能描述

- 每个 Mod 最多保存 10 行“快捷键 + 功能描述”。
- 点击快捷键框后直接按键，程序会读取单键、组合键、功能键和符号键。
- 示例：`Q`、`1`、`F1`、`Ctrl+1`、`Shift+F2`、`Alt+Q`、`/`、`;`、`[`、`]`、`\`。
- 这些内容只是 Mod 使用说明，不会注册 Windows 全局热键。
- 在线下载时会尽力从介绍文本提取快捷键；中文界面尝试翻译描述，英文界面保留原文。

### 4.7 外部启动器

选择启动器 EXE 后，点击“运行启动器”即可启动。程序使用启动器所在目录作为工作目录，适合 XXMI Launcher 或其他外部管理器。

## 5. 在线 Mod 浏览与下载

### 5.1 在线分类配置

在线模块主要读取 GameBanana。每个仓库可在设置中独立配置目标游戏、皮肤分类 ID、来源站点和 Wiki 地址。预设包含终末地、绝区零、原神和崩坏：星穹铁道；自定义游戏可填写自己的分类。

程序接受分类名中包含 `Skins` 的条目，而不是只接受完全等于 `Skins` 的名称。Wiki 角色目录与 GameBanana 列表分开缓存和更新，用于补充头像、中英文名和角色顺序。

### 5.2 角色、收藏与筛选

- 左侧按角色浏览，可显示头像和与当前语言对应的角色名。
- 星形按钮收藏角色；收藏按仓库保存并置顶。
- “全部”显示当前分类的所有 Mod。
- 搜索框同时匹配角色名和 Mod 名。
- 支持按热度、下载量、点赞量、查看量和更新时间排序。
- 列表模式适合查看信息，方块模式适合快速浏览图片。
- 上一页、下一页切换完整分页数据。

热度最高 10 分，使用下载量、点赞量和查看量的对数加权结果：

```text
min(10, 2 x (
    0.55 x log10(下载量 + 1)
  + 0.30 x log10(点赞量 + 1)
  + 0.15 x log10(查看量 + 1)
))
```

### 5.3 详情、图片和访问要求

点击“查看详情”后，右侧独立面板显示作者、角色、分类、更新时间、图片、介绍和固定操作区。点击主图可打开居中的高清浏览器，使用左右按钮或方向键切图，按 `Esc` 或点击图片外区域关闭。

程序会尝试识别 Patreon、付费订阅、点赞解锁、限时免费、依赖组件等额外访问要求并显示提示。这是尽力识别，不能保证覆盖作者的所有说明；下载和使用前仍应阅读原页面。

### 5.4 下载与解压

1. 打开详情并确认作者说明和访问要求。
2. 点击“下载并解压”。
3. 选择目标第一层分类或本地目录。
4. 在下载任务中心查看下载、解压、完成或失败状态。
5. 可取消进行中的任务、打开输出目录或清理已完成记录。

程序不会绕过登录、验证码、付费、订阅、权限验证或作者限制。GameBanana 限流、网络超时或页面结构变化时，会优先保留和显示可用缓存，并允许稍后刷新。

## 6. 更新模块：配置方案、安全与任务

### 6.1 配置方案

配置方案按仓库记录一组已启用 Mod，可创建、更新、应用和删除。应用方案会把目标目录调整到记录状态，适合在不同角色、游戏版本或组合之间切换。

### 6.2 冲突检测

安装或应用方案前，程序会检查目标路径和文件冲突。发现冲突时应先确认来源与优先级，避免不同 Mod 覆盖同一文件。

### 6.3 安装备份与回滚

- 复制、移除和方案切换会创建事务备份。
- 操作失败时自动恢复；也可手动撤销最近变更。
- 备份列表显示创建时间、涉及 Mod 和占用空间，并提供手动恢复按钮。
- 设置中可把备份磁盘上限设为 0.5 至 100 GB；超过上限时按时间清理旧备份。

### 6.4 已追踪 Mod 更新

在线安装成功后会记录远程 ID、来源链接、预览图和上次更新时间。更新页支持手动检查、每天/每 3 天/每周检查、打开页面或本地目录、去重及删除追踪记录。删除追踪记录不会删除本地 Mod 文件。

## 7. 软件更新

- 可在设置中开启或关闭“启动时检查软件更新”。
- 发现新版本后，程序先询问用户，不会静默安装。
- 确认后自动下载 Release ZIP、显示进度、校验并调用独立更新组件。
- 主程序退出后替换文件并自动重启；用户仓库、路径、语言、主题、快捷键、链接和 SQLite 数据会保留。
- 更新前保留旧版本；新版本启动失败时自动回滚。
- 也可把规范命名的新版发布 ZIP 放到现有程序根目录，重启后让程序识别并询问更新。

## 8. 设置、数据与隐私

### 8.1 界面与辅助功能

- 中文/English 切换。
- 深色/浅色主题和 Windows 高对比度适配。
- 舒适/紧凑界面密度。
- 可减少页面切换、详情展开和列表切换动效。
- 支持 Tab 导航、清晰焦点提示、屏幕阅读器名称和 Windows 缩放。

### 8.2 本地数据

主要数据位于 `WinUI3` 目录：

| 文件或目录 | 内容 |
| --- | --- |
| `config.ini` | 主题、语言、快捷键、Mod 链接和在线安装来源 |
| `beta-shell.json` | 仓库、当前页面、在线分类和更新选项 |
| SQLite 数据库 | 在线分页、角色目录、详情、指标、收藏、版本和文件索引 |
| `cache/online-images` | 在线图片缓存，可删除并重新生成 |
| `backups` | 配置备份、安装事务备份和软件更新备份 |
| `startup.log` | 启动器发生问题时的启动记录 |

配置写入采用临时文件替换和轮换备份；主配置损坏时会尝试恢复最近有效备份。

### 8.3 诊断报告

“一键导出诊断报告”会收集程序版本、系统摘要、错误日志和脱敏配置摘要，排除本机隐私路径和访问凭据。也可打开预填的 GitHub Issue；报告不会代替用户自动提交，上传前请自行检查内容并决定是否附加文件。

## 10. 常见问题

### 在线列表为空或加载失败

确认仓库分类 ID 正确、分类名称包含 `Skins`，并检查网络是否可访问 GameBanana。出现 429 表示站点限流，请等待缓存冷却后再刷新；切换仓库或角色会取消过期请求。

### 下载量暂时显示为 0

部分 GameBanana 列表接口不直接返回下载量，程序会使用统一的详情回填和 SQLite 缓存流程。网络受限时先显示缓存或 0，后续刷新成功后更新。

### RAR、7Z 或 ZIPX 无法解压

确认 `WinUI3/Tools/7z.exe`、`7z.dll` 和许可证文件未被删除或安全软件隔离，并检查压缩包是否损坏、加密或为缺失分卷的文件。

### 复制后状态变为“未复制”

复制操作是开关行为。目标目录已有同名 Mod 时，再次双击会移除目标中的 Mod。

### 预览图不显示

把图片命名为 `preview.png` 或 `cover.jpg`，也可以选择 Mod 后把图片拖入预览区。

### 更新失败

确认程序目录可写、压缩包下载完整且没有在压缩包内运行。更新代理会尝试回滚；仍无法启动时，从 Releases 完整解压新版，并把旧目录中的配置文件复制到新版前先备份。

## 11. 安全与使用边界

- 本工具不包含游戏文件或 Mod 内容。
- 不绕过支付、订阅、登录、权限验证、作者限制或平台规则。
- 在线识别、翻译和自动解压属于辅助功能，重要说明以原作者页面为准。
- 安装来源不明的 Mod 前，应检查文件内容并使用安全软件扫描。
- 分享截图、配置或诊断信息前，确认没有暴露个人路径、账号或访问凭据。
