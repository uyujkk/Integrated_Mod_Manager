# 跨 Mod 内部状态实验说明

当前实验版为 `v3.8.1 Persistent State Lab`，基于正式版 3.8 的独立分支。它不替换正式版，不修改 Mod 自身 INI，只处理由 `global persist` 声明、并以单个数值写入 `d3dx_user.ini` 的状态。

## 已确认的 EFMI 环境

- XXMI 启动器：`<XXMI Launcher>\Resources\Bin\XXMI Launcher.exe`
- EFMI Mods：`<XXMI Launcher>\EFMI\Mods`
- EFMI 用户状态：`<XXMI Launcher>\EFMI\d3dx_user.ini`
- 游戏进程：`Endfield.exe`
- EFMI 重载键：`reload_config = no_modifiers VK_F10`

庄方仪旗袍 Mod 已确认存在 14 个可记忆变量，包括部件开关以及 `mx`/`my`。

## 为什么旧的单次 F10 方案失效

3DMigoto 在重载时先保存当前内存中的持久值，再读取配置。因此，如果管理器在游戏运行时直接覆盖 `d3dx_user.ini` 后立即按 F10，新写入的目标值可能先被旧内存值覆盖。

另一方面，当前 EFMI 会在游戏快捷键或命令改变 `global persist` 时实时重写 `d3dx_user.ini`。这是“内存状态写到文件”，不代表它会实时读取外部修改。

## 保存状态（无 F10）

1. 在游戏中调整好服装、颜色和部件。
2. 等待 EFMI 自动更新 `d3dx_user.ini`。
3. 在管理器点击“记住选中 Mod（无 F10）”或“保存当前方案状态（无 F10）”。
4. 管理器每 350ms 采样文件长度和修改时间，连续两次一致后再读取，避免读到重写中的半个文件。

保存流程不模拟键盘，也不要求游戏保持前台。

## 方法一：离线恢复并启动（无 F10）

这是默认推荐方式。

1. 完全退出 `Endfield.exe`。
2. 先使用 3.8 原有的文件夹或配置方案功能恢复需要启用的 Mod。
3. 点击“离线恢复选中 Mod 并启动”或“离线恢复方案并启动”。
4. 管理器从目标 Mods 同级的 `d3dx.ini` 读取 `target` 进程名，并额外检查 `Endfield.exe`。发现游戏在运行时拒绝写入。
5. 管理器在 `IntegratedModManager.StateBackups` 中创建带毫秒时间戳的备份。
6. 只更新预设中的变量，保留 EFMI 自身状态、RabbitFX 和其他 Mod 的值；缺失的目标变量会添加到 `[Constants]`。
7. 使用同目录临时文件原子替换，然后逐个验证数值。
8. 验证成功后启动仓库中设置的 XXMI Launcher。

整个过程不按 F10。

## 方法二：运行中热恢复（手动两次 F10）

1. 点击“运行中热恢复选中 Mod”或“运行中热恢复方案”。
2. 管理器在目标 Mods 根目录生成带固定标记的 `ZZZ_IntegratedModManager_StateBridge.ini`。
3. 第一个提示出现后，切到游戏手动按 F10，等待重载，回到管理器点击确定。
4. 管理器删除桥接文件。
5. 第二个提示出现后，切到游戏再手动按 F10，等待重载，回到管理器点击确定。
6. 管理器在 6 秒内反复读取 `d3dx_user.ini` 并验证全部目标值。

管理器不再调用 Windows 键盘模拟接口。

## 安全边界

- 只捕获当前已启用 Mod INI 中明确声明为 `global persist` 的变量。
- 只接受合法变量名和有限数值，拒绝命令、字符串、换行和伪造 INI 节。
- 离线恢复不覆盖整个用户配置，只合并目标变量。
- 临时桥接带固定生成标记；遇到无标记的同名文件时拒绝覆盖。
- 组合恢复会跳过当前目标 Mods 目录中未启用的 Mod。
- 本功能不直接读写游戏进程内存，但 XXMI/3DMigoto 本身仍属于第三方 Mod 运行环境，不能承诺账号零风险。

## 已知限制

- 纯内存且未声明为 `global persist` 的状态无法从文件恢复。
- 字符串、向量和命令型状态不处理。
- 运行中热恢复依赖 F10 仍是当前 EFMI 的 `reload_config` 键。
- Mod 自身若在更晚的 `post` 命令中覆盖同一变量，最终值可能与预设不同。
- 离线恢复按钮只恢复当前已启用的 Mod 状态；组合方案应先应用 3.8 原有的 Mod 启用组合。

## 真实游戏验收

1. 将庄方仪 Mod 调成状态 A，等待文件更新，使用无 F10 捕获，确认显示 14 个变量。
2. 调成明显不同的状态 B。
3. 退出游戏，离线恢复 A 并启动 XXMI，确认进入游戏后为 A。
4. 再调成 B，使用运行中热恢复，按提示手动两次 F10，确认立即回到 A。
5. 确认 `d3dx_user.ini` 目标值为 A，并确认 Mods 根目录没有残留桥接文件。
6. 重启游戏确认 A 仍保留，再用两个以上 Mod 的组合方案重复测试。
