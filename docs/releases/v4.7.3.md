# v4.7.3

基于 v4.7.2 的 Windows x64 版本，包含 #86 和 #91。Windows x64 release based on v4.7.2, covering #86 and #91.

## 中文

4.7.3 新增俄语界面，其余功能与 4.7.2 相同。4.7 的全部新功能见 [v4.7.0 发布说明](v4.7.0.md)。

### 新增

- **俄语界面**：在“设置 → 语言”中选择“Русский”。系统语言为俄语的电脑第一次安装时会默认使用俄语。
- **界面语言改为文件**：每种语言是 `Strings` 里的一个文件，添加新语言不用改代码；某条文字没有翻译时显示英文。

### 改进

- 窄导航栏里放不下的标签会换成两行，单个长词会略微缩小，不再被截断。
- Mod 工作区工具栏的统计文字在空间不够时以省略号结尾，不再挡住最后一个按钮。
- “检查更新间隔”下拉框的提示文字跟随界面语言。

### 升级

- 4.7.2 及更早的正式版可以在软件内更新，也可以下载完整 ZIP；旧配置可以直接使用，原来的中文、英文设置不变。
- 4.7.3 不会再显示“4.7 新增”的说明。
- 改用俄语后再降级到 4.7.2 或更早版本，界面会显示为中文，需要在设置里重新选择语言。

### 已知问题与验证边界

- 俄语译文尚未经过母语者审校。角色名、Wiki 名称等在线内容在俄语界面中显示英文；终末地启动器的出错提示只有中文和英文。
- 已在应用中切换到俄语检查仪表盘、Mod 工作区、在线、更新、快捷键和设置页面；游戏内浮窗、只在下载、恢复、导入过程中出现的对话框，以及带真实数据的在线列表尚未逐一检查。
- 窗口缩得很小时部分工具栏会溢出，这与英文界面相同。
- 其余已知问题与 4.7.2 相同，见 [v4.7.2 发布说明](v4.7.2.md#已知问题与验证边界)。
- 第三方 Mod 与加载器可能导致账号处罚。发布包按 AGPL-3.0-only 分发，见 [许可证说明](../LICENSING.md)；验证结果见 [验证记录](../verification/v4.7.3.md)。

## English

4.7.3 adds a Russian interface; everything else is the same as 4.7.2. For everything new in 4.7 see the [v4.7.0 notes](v4.7.0.md).

### New

- **Russian interface:** choose "Русский" under Settings → Language. A first install on a Russian system uses Russian.
- **UI languages as files:** each language is one file in `Strings`, so adding a language needs no code changes; any text a language leaves out is shown in English.

### Improvements

- Labels that don't fit the narrow navigation rail wrap onto two lines, and a single long word is scaled down slightly instead of being cut off.
- The counts on the Mod workspace toolbar end with an ellipsis when space runs out instead of covering the last button.
- The placeholder of the update-interval box follows the interface language.

### Upgrade

- 4.7.2 and earlier stable releases can update in the app, or download the full ZIP. Existing configuration works as is; Chinese and English settings are unchanged.
- 4.7.3 does not show the "New in 4.7" dialog again.
- After choosing Russian, going back to 4.7.2 or earlier shows the interface in Chinese; choose the language again in Settings.

### Known issues and verification limits

- The Russian translation has not been reviewed by a native speaker yet. Online content such as character and wiki names stays in English in the Russian interface, and the Endfield launcher's error dialogs are Chinese or English only.
- The dashboard, Mod workspace, Online, Updates, Shortcuts and Settings pages were checked in the app in Russian; the in-game overlay, dialogs that only appear while downloading, restoring or importing, and online lists with real data were not checked one by one.
- At very small window sizes some toolbars overflow, as in English.
- The other known issues are the same as in 4.7.2; see the [v4.7.2 notes](v4.7.2.md#known-issues-and-verification-limits).
- Third-party Mods and loaders may lead to account penalties. The package is AGPL-3.0-only; see [LICENSING](../LICENSING.md). Results are in the [verification record](../verification/v4.7.3.md).
