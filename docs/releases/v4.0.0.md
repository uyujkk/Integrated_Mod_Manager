# v4.0.0 — 仓库工作台 / Repository Workspace

正式版 / Stable release · 2026-10-05 · [下载 / Download](https://github.com/uyujkk/Integrated_Mod_Manager/releases/tag/v4.0.0)

## 中文

- 仓库默认使用文件列表，支持一键切换封面视图。
- 新增组合预设工作区，集中保存、查看和恢复 Mod 组合及持久状态。
- 调整角色、Mod、详情和部署按钮的位置，改善宽屏及窄窗口排版。
- 列表与预设成员在模块内滚动，切换视图保留当前 Mod 选择。
- 底部状态栏改为单行，区分任务与操作提示；空闲时不显示进度条，长路径可悬停查看完整内容。
- 恢复状态只回写对应的 `d3dx_user.ini` 参数，不修改 Mod 原始 INI。
- 统一主程序、启动器和更新器的 4.0.0 版本号，打包时校验 ZIP 与 SHA-256 文件，保留旧配置兼容。
- 正式版重新接入软件更新；4.0-beta 保留为独立历史测试包。

感谢 [CaramelizedCUDA](https://github.com/CaramelizedCUDA) 之前贡献的 Bandizip 备用解压，本版继续保留。

## English

- Files is now the default repository view, with a switchable cover gallery.
- A dedicated preset workspace brings Mod combinations and persistent-state capture and restoration together.
- Character navigation, Mod browsing, details, and deployment actions have a clearer layout on wide and narrow windows.
- Lists scroll within their panels; switching views keeps the selected Mod.
- A compact, single-line status bar separates task state from operation messages. Idle progress bars are hidden; hover over truncated paths to read them in full.
- State restoration updates matching `d3dx_user.ini` values without rewriting the original Mod INIs.
- The app, launcher, and updater share version 4.0.0. Packages are checked against their SHA-256 files; existing configurations remain supported.
- Stable-channel app updates are enabled again; 4.0-beta remains a separate historical prerelease.

Thanks to [CaramelizedCUDA](https://github.com/CaramelizedCUDA) for the previously contributed Bandizip fallback, retained in this version.

## 使用提示 / Before Restoring

保存参数前在游戏中按 F10 并等待保存完成；恢复前退出游戏和加载器。升级前备份现有应用目录及实际加载器状态。支持可识别的数值型 `global persist`，不保证所有 Mod 兼容。详细步骤见[组合预设](../guides/Combination-Presets.zh-CN.md)与[升级指南](../guides/Upgrade-v4.0.zh-CN.md)。

Before capturing state, press F10 in game and wait for saving to finish. Close the game and loader before restoring. Back up the app and active loader state before upgrading. Recognized numeric `global persist` values are supported, not every possible Mod. See the [preset guide](../guides/Combination-Presets.en.md) and [upgrade guide](../guides/Upgrade-v4.0.en.md).
