## 中文

4.5.2 改进置顶浮窗的保存、刷新和多按键 Mod 的响应速度，并调整功能名称与标记。4.5 系列的其他功能见 [v4.5.1 发布说明](v4.5.1.md)。

### 新增与改进

- **保存前自动发送 F10**：浮窗的“保存预设”和“保存单 Mod 预设”会先向游戏窗口发送 F10，等参数文件写入、且连续两次读取一致后再保存；5 秒内没有检测到写入就不保存，避免存到旧参数。发送不了 F10 时（未选游戏窗口、发送未开启或权限不足），可以取消，或明确选择只读取现有文件。没有设置 `d3dx_user.ini` 时，组合预设只保存 Mod 组合。
- **浮窗刷新**：新增“刷新”按钮；启用、停用、切换链接或恢复组合成功后也会自动刷新。当前 Mod 被替换时跟随新的 Mod，停用且没有替代时清空旧按键。
- **多按键 Mod 更快**：缓存 INI 扫描结果、复用按钮，浮窗或页面隐藏时不重绘，状态变化只更新文字。
- 缺少参数时的提示改为中英文语言文件中的文字。

### 名称与功能标记

- 变体导入改为中性名称，并标注“待验证”。
- 目录联接部署、恢复到加载器和 Mod 组合预设去掉“实验”标记，作为已验证的稳定功能。F10 热应用和在线自动翻译仍为实验功能。

### 其他

- 源码整理为 `src/`、`tests/`、`tools/`，文档移入 `docs/` 和 `.github/`；安装包的目录结构不变。
- 主页更新 4.5 的说明和截图。

### 升级

- 4.5.1 及更早版本可以在软件内更新，也可以下载完整 ZIP；旧配置可以直接使用。
- 保存预设时会发送 F10，游戏画面会短暂重载。终末地需要以管理员身份运行管理器才能接收按键。

### 已知问题与验证边界

- 保存前发送 F10 已用模拟加载器验证，尚未在真实游戏中自动化验证；导入变体文件尚未用真实导出的文件验证。
- 在线详情页偶发闪退（#15）仍未复现。第三方 Mod 与加载器可能导致账号处罚。发布包按 AGPL-3.0-only 分发，见 [许可证说明](../LICENSING.md)；验证结果见 [验证记录](../verification/v4.5.2.md)。

## English

4.5.2 improves saving and refreshing in the overlay and the response of Mods with many bindings, and adjusts feature names and labels. For the rest of the 4.5 series see the [v4.5.1 notes](v4.5.1.md).

### New and improved

- **F10 before saving:** the overlay's Save preset and Save single-Mod preset first send F10 to the game window and save only after the loader file has changed and two reads match. If no write is detected within 5 seconds nothing is saved, so stale values are never stored. If F10 can't be sent (no game window selected, input off, or not enough permission), you can cancel or explicitly read the existing file. Without a `d3dx_user.ini`, a combination preset saves the Mod combination alone.
- **Overlay refresh:** a new Refresh button; successful enable, disable, link switch or combination restore also refreshes the overlay. A replaced Mod is followed by its replacement; a disabled Mod with no replacement has its old buttons cleared.
- **Faster Mods with many bindings:** INI scan results are cached, buttons are reused, nothing is redrawn while the overlay or page is hidden, and status changes only update text.
- The missing-value message now comes from the Chinese and English language files.

### Names and labels

- Variant import uses a neutral name and is marked unverified.
- Directory-link deployment, loader state restore and Mod combination presets drop the experimental label and are treated as verified, stable features. F10 hot apply and online auto-translation remain experimental.

### Other

- Source moves to `src/`, `tests/` and `tools/`; documents move into `docs/` and `.github/`. The package layout is unchanged.
- The homepage has updated 4.5 text and screenshots.

### Upgrade

- 4.5.1 and earlier can update in the app, or download the full ZIP. Existing configuration works as is.
- Saving a preset sends F10, which briefly reloads the game scene. Endfield needs the manager to run as administrator to receive keys.

### Known issues and verification limits

- Sending F10 before saving was verified with a simulated loader, not yet automatically in a real game; variant import has not been checked with a real exported file.
- The occasional crash on the online details page (#15) is still unreproduced. Third-party Mods and loaders may lead to account penalties. The package is AGPL-3.0-only; see [LICENSING](../LICENSING.md). Results are in the [verification record](../verification/v4.5.2.md).
