## 中文

### 新增：Mod 快捷键面板与置顶浮窗

- 左侧新增“快捷键”模块：读取 Mod INI 中的 `[Key…]` 绑定，列出按键、动作说明、来源节和条件，点击即可向所选游戏窗口发送按键。不需要记快捷键，也不需要实体小键盘。
- 置顶浮窗（默认 Ctrl + Alt + K）：不抢焦点，可拖动、调整大小；背景不透明度可调，文字始终清晰；字体颜色可自定义。浮窗内可切换已启用的 Mod、开关发送，以及把当前组合和参数保存为组合预设（只读取，不改动游戏）。
- 跟随当前出场角色：框选只随出场角色变化的 HUD 区域并为每个角色保存参考图后，面板会自动切换到对应 Mod。参考图只保存在本地，不上传。
- 按 3DMigoto 规则解析按键：支持组合键、按住前置键、`no_` 排除条件和常用标点键。鼠标、手柄和系统组合键等无法发送的绑定会显示原因，也可以隐藏。
- **终末地需要以管理员身份运行管理器。** 游戏始终以管理员权限运行，Windows 会静默丢弃普通权限程序发来的按键。管理器会提前识别并提示，可一键以管理员身份重启。
- 中文与英文界面完整支持，切换语言后立即生效。

详见 [快捷键面板使用说明](../guides/Mod-Shortcut-Panel.zh-CN.md)。

### 问题修复与改进

- **Mod 更新后保留预览图（#14）**：“下载并替换”会把旧版本根目录的预览图带到新版本；同名但内容不同时保留新包图片，旧图另存为 `名称.before-update.扩展名`。
- **更新器支持超长路径（#16）**：新版更新器在路径超过 260 个字符时也能升级和回滚，不需要修改 Windows 设置。同时修复：文件清单使用 `/` 分隔时，更新器可能误删子目录中的程序文件。
- **下载时按需创建角色文件夹（#6）**：仓库里没有对应角色文件夹时，按仓库现有命名语言建议新建，确认后才创建；匹配不明确时交给用户选择。单个下载和批量下载都支持。
- 在线浏览：下载量分批获取，不再为补充下载量刷新整个列表；预取下一页，翻页和角色筛选更快。
- Mod 更新页：更新卡片改为更紧凑的布局，状态用标签显示，次要操作收进“更多”菜单。
- 终末地启动设置：内容区固定高度并可滚动，检查结果单独显示，长文字自动换行，内容较多时不再错乱。
- 组合预设：复制部署的仓库中，部署目录里存在指向仓库自身的联接时，保存预设不再报错。

### 升级与使用

- 4.3.1 用户可通过软件内更新升级，或下载完整 ZIP 解压到新目录使用。手动迁移时，在新旧程序都退出后复制 `WinUI3/config.ini` 和 `WinUI3/beta-shell.json`。
- 本版的超长路径修复属于新版更新器。从 4.3.1 升级时运行的仍是旧更新器：如果程序装在很深的目录里，请先把完整包解压到较短的目录。之后的升级使用新版更新器。
- 快捷键测试版（hotkeys-test）用户请改用本正式版；测试版关闭了软件自身更新，需要手动下载。

## English

### New: Mod shortcut panel and overlay

- A new Shortcuts page reads the `[Key…]` bindings in a Mod's INI files and lists each key, action, source section and condition. Click a binding to send the key to the selected game window. No need to remember shortcuts or own a numeric keypad.
- Always-on-top overlay (Ctrl + Alt + K by default): never takes focus and can be moved and resized. Background opacity is adjustable while text stays opaque, and the font colour can be customised. From the overlay you can switch between enabled Mods, turn sending on or off, and save the current combination and values as a preset (read-only; the game is not changed).
- Follow the active character: select a HUD area that changes only with the active character and save a reference for each character, and the panel switches to that character's Mod. References stay on your computer and are never uploaded.
- Keys are parsed with 3DMigoto rules, including combinations, held keys, `no_` exclusions and common punctuation keys. Mouse, controller and system bindings that can't be sent show the reason and can be hidden.
- **Endfield requires running the manager as administrator.** The game always runs elevated, and Windows silently drops keys sent from a non-elevated program. The manager detects this in advance and can restart itself as administrator.
- Fully available in Chinese and English; switching language applies immediately.

See the [shortcut panel guide](../guides/Mod-Shortcut-Panel.en.md).

### Fixes and improvements

- **Keep preview images after Mod updates (#14):** Download and replace now carries root-level preview images from the old version into the new one. When the new package has a different image with the same name, the new one is kept and the old one is saved as `name.before-update.ext`.
- **Long paths in the updater (#16):** the new updater can upgrade and roll back with paths longer than 260 characters, without changing Windows settings. Also fixed: when the managed-file list used `/` separators, the updater could delete program files in subfolders.
- **Create character folders on download (#6):** when the repository has no folder for the character, a new folder is proposed in the repository's naming language and created only after you confirm. Ambiguous matches are left to you. Works for single and batch downloads.
- Online browsing: download counts are fetched in batches without refreshing the whole list, and the next page is prefetched, so paging and character filters are faster.
- Mod updates page: more compact update cards, status shown as badges, and secondary actions moved into a More menu.
- Endfield launch settings: the content area has a fixed height and scrolls, check results have their own area, and long text wraps, so the dialog no longer breaks when it holds a lot of content.
- Combination presets: saving a preset no longer fails in a copy-deployment repository when the deployment folder contains a link to the repository's own Mod folder.

### Upgrade and use

- Users of 4.3.1 can upgrade from inside the app, or extract the complete ZIP into a new folder. For a manual migration, copy `WinUI3/config.ini` and `WinUI3/beta-shell.json` after both versions have exited.
- The long-path fix is part of the new updater. An upgrade from 4.3.1 still runs the old updater, so if the app is installed in a very deep folder, extract the complete package into a shorter folder first. Later upgrades use the new updater.
- Users of the shortcut test builds (hotkeys-test) should switch to this release. Test builds have app self-update turned off and need a manual download.

### Known issues and validation limits

- The occasional native crash on the online details page (#15, `Microsoft.UI.Xaml.dll / 0xc000027b`) has still not been reproduced, and its root cause is unknown.
- Sending shortcuts was confirmed by a user in Endfield with the manager running as administrator. Other games, exclusive full screen and individual Mods have not been checked one by one. Windows accepting a key doesn't guarantee the game runs the Mod action.
- The full XXMI/EFMI launch chain and UAC flow have not been fully validated in a live game. Third-party Mods and launchers may lead to account penalties or bans; account safety is not guaranteed.
- This version includes the AGPL-3.0-only Endfield launch component, and the release package is distributed as a whole under AGPL-3.0-only; see [licensing](../LICENSING.md). Test and verification results are in the [verification record](../verification/v4.4.0.md) and the included `PACKAGE-INFO.json`.
