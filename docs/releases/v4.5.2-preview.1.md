# v4.5.2-preview.1

Local Windows x64 development preview based on v4.5.1 / 基于 v4.5.1 的本地 Windows x64 开发预览版。

## What's new / 更新内容

- Overlay combination and single-Mod saves send F10 before capture and wait for a changed file with two stable reads. A five-second timeout stops the save. Input uses the selected window, enabled input and existing privilege checks. When input is unavailable, explicitly choose to read existing disk state or cancel. F10 briefly reloads the scene.
  浮窗保存组合预设和单 Mod 预设前会发送 F10，检测文件变化并连续两次读取稳定后再保存；5 秒超时则停止保存。沿用窗口选择、发送开关与权限检查；无法发送时可明确选择读取磁盘现有值，或取消。F10 会短暂重载画面。
- Refresh the overlay manually, or automatically after a successful deployment or combination restore. A replaced current Mod follows its replacement; disabling it without a replacement clears its old shortcuts. Manual refresh also discovers new source Mods.
  浮窗新增刷新按钮，成功部署或恢复组合后自动刷新。当前 Mod 被替换时选择替代 Mod；停用且无替代项时清空旧按键。手动刷新也会发现新增的源 Mod。
- INI scans use a bounded metadata cache. Buttons are reused, hidden pages defer rendering, and status-only updates leave binding controls intact. The scanner supports up to 512 bindings by default.
  INI 扫描增加有限容量的元数据缓存；复用按钮、推迟隐藏页面渲染，状态更新不重建按键列表。默认最多读取 512 个绑定。
- Variant-file import uses neutral wording and is marked unverified. Link deployment, loader-state restoration and combination presets no longer carry the experimental label, within the existing validation scope. F10 hot apply and online automatic translation remain experimental.
  变体文件导入改用中性名称并标为待验证；链接部署、加载器状态恢复和组合预设在既有验证范围内移除实验标记。F10 热应用及在线自动翻译仍为实验功能。
- Source projects move under `src/`, tests under `tests/` with Core cases grouped by domain, and developer tools under `tools/`. Project references, build/package scripts and workflow paths follow the move. Runtime ZIP layout remains compatible with previous updaters. No existing test cases were removed.
  应用源码整理到 `src/`，测试整理到 `tests/` 且 Core 用例按领域分组，开发工具整理到 `tools/`；同步项目引用、构建打包脚本和工作流路径。运行包布局继续兼容旧更新器，保留原有测试用例。

## Known issues / 已知问题

- This is a local preview with app self-update disabled. Extract into a separate directory. Exact verification results are in the packaged verification record and `PACKAGE-INFO.json`.
  这是关闭软件自身更新的本地预览版，请解压到独立目录；精确验证结果见包内验证记录及 `PACKAGE-INFO.json`。
- Real-game F10 delivery, exclusive fullscreen and elevated game compatibility still require user testing. A synthetic loader write or Windows accepting an input event does not establish a real game response.
  真实游戏的 F10 送达、独占全屏及管理员游戏兼容性仍需实测；模拟加载器写入或 Windows 接收输入事件不能证明游戏响应。
- Variant import still needs a real export and in-game confirmation. The interoperability filename remains supported internally.
  变体导入仍待真实导出文件和游戏内效果验证，内部继续识别既有兼容文件名。
- Initial overlay creation still incurs window/layout cost. No automatic filesystem watcher is included; use Refresh after external changes.
  浮窗首次打开仍有窗口和布局开销；本版未加入文件系统监视器，外部改动后请点刷新。
