# v4.7.1

基于 v4.7.0 的 Windows x64 修复版，包含 #81–#83。Windows x64 fix release based on v4.7.0, covering #81–#83.

## 中文

4.7.1 只改了软件自带的更新器，功能与 4.7.0 相同。4.7 的全部新功能见 [v4.7.0 发布说明](v4.7.0.md)。

### 修复

- **更新器被误报为病毒**：4.7.0 的 `LocalUpdateAgent.exe` 是用 `csc.exe` 编译的 .NET Framework 小程序，几家依靠机器学习的杀毒引擎把它判为可疑（VirusTotal 5/71），GameBanana 因此暂扣了 4.7.0 的上传。4.7.1 用 .NET 8 SDK 把同一份源码发布成单个程序，不再依赖 Windows Forms，VirusTotal 上只剩 1/70。更新器做的事没有变：在你确认更新后，等软件退出，校验并解压下载好的新版本，备份后替换文件，再启动新版；失败时回滚。
- 更新器现在和主程序一样只需要 .NET 8 x64 运行时，不需要另外安装 .NET Framework 或 .NET 桌面运行时。

### 其他

- 用户手册、快速上手、专题手册和开发文档已更新到 4.7（#81）。

### 升级

- 4.7.0 及更早的正式版可以在软件内更新，也可以下载完整 ZIP；旧配置可以直接使用。从 4.7.0 升级时，运行的仍是 4.7.0 的更新器。
- 4.7.1 没有新功能，不会再显示“4.7 新增”的说明；没看过 4.7 说明的用户仍会看到一次。

### 已知问题与验证边界

- VirusTotal 上仍有一家（DeepInstinct）把新更新器判为可疑，也是机器学习判断；已知误报，不影响使用。
- 其余已知问题与 4.7.0 相同，见 [v4.7.0 发布说明](v4.7.0.md#已知问题与验证边界)。
- 第三方 Mod 与加载器可能导致账号处罚。发布包按 AGPL-3.0-only 分发，见 [许可证说明](../LICENSING.md)；验证结果见 [验证记录](../verification/v4.7.1.md)。

## English

4.7.1 changes only the app's own updater; features are the same as 4.7.0. For everything new in 4.7 see the [v4.7.0 notes](v4.7.0.md).

### Fixes

- **The updater was flagged as malware:** in 4.7.0, `LocalUpdateAgent.exe` was a small .NET Framework program compiled with `csc.exe`, and several machine-learning antivirus engines marked it as suspicious (5/71 on VirusTotal), so GameBanana withheld the 4.7.0 upload. 4.7.1 publishes the same source with the .NET 8 SDK as one file without Windows Forms, and VirusTotal shows 1/70. What the updater does is unchanged: after you confirm an update, it waits for the app to exit, checks and extracts the downloaded release, backs up and replaces the files, and starts the new version, rolling back on failure.
- Like the app, the updater now needs only the .NET 8 x64 runtime, not .NET Framework or the .NET desktop runtime.

### Other

- The user guide, quick start, topic guides and development docs were updated for 4.7 (#81).

### Upgrade

- 4.7.0 and earlier stable releases can update in the app, or download the full ZIP. Existing configuration works as is. Upgrading from 4.7.0 still runs 4.7.0's updater.
- 4.7.1 has no new features, so the "New in 4.7" dialog is not shown again; users who haven't seen it yet still see it once.

### Known issues and verification limits

- One VirusTotal engine (DeepInstinct) still marks the new updater as suspicious, also a machine-learning verdict; it is a known false positive.
- The other known issues are the same as in 4.7.0; see the [v4.7.0 notes](v4.7.0.md#known-issues-and-verification-limits).
- Third-party Mods and loaders may lead to account penalties. The package is AGPL-3.0-only; see [LICENSING](../LICENSING.md). Results are in the [verification record](../verification/v4.7.1.md).
