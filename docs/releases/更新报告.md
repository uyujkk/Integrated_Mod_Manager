## 中文

### 版本定位

v3.9.0 是一次完整的桌面交互升级。它保留 v3.8.5 的多仓库、复制部署、可选目录联接、压缩包安全校验、在线浏览、配置方案、备份回滚和自动更新能力，同时重新组织日常工作流，让仓库、路径、Mod、快捷键、在线内容和更新状态更容易发现与操作。

### 现代化响应式界面

- 仪表板、仓库工作台、在线浏览、更新和设置页面全部重新排版。
- 宽屏模式充分使用水平空间；半屏与紧凑模式自动重排，避免大块留白或横向溢出。
- 仪表板的仓库选择与统计卡共享高度，路径设置与游戏预设共享顶线和底线。
- 仓库工作台使用“分类 → Mod → 预览/快捷键详情”层级，并把内部列表滚动限制在各自区域，不再让整页无意义上下漂移。
- 设置页按界面、更新、在线分类和诊断分组；宽屏双列底部对齐，紧凑窗口显示聚焦分区。
- 应用图标更换为透明背景、多尺寸的 Windows 11 Fluent 风格资源，并同步到窗口标题栏和 EXE。

### 每仓库路径与系统托盘

- Mod 仓库、目标文件夹和可选游戏启动器由每个仓库独立保存。
- 当前仓库配置直接显示在仪表板，切换仓库时同步切换对应路径、在线来源、分类 ID、Wiki 和备注。
- 支持最小化到系统托盘。托盘提示和菜单提供当前仓库、Mod 数量/就绪状态、在线来源、版本、恢复和退出等基础信息。

### 快捷键自动识别

- 下载或本地导入 Mod 后，只读扫描其 `.ini` 文件中的 `[Key...]` 段。
- 识别 `key`、组合键、循环/切换变量和常见部件名称，将 `hairacc`、`img_x` 等原始标识整理为更可读的文本。
- 自动说明跟随当前应用语言切换为中文或 English；手工填写的说明不会被覆盖。
- 快捷键编辑器不再限制 10 行，可显示和编辑拥有更多快捷键的 Mod。
- 扫描器仍保留 256 条防御上限，避免损坏或恶意 INI 无限占用资源。

### 在线游戏预设

- 增加《明日方舟：终末地》的 GameBanana 分类 `42770`、Wiki 入口和在线干员目录更新。
- 保留原神、绝区零与崩坏：星穹铁道的现有预设。
- 在线角色/干员列表可以从对应 Wiki 来源刷新；网络失败时继续使用内置回退列表，不阻止本地 Mod 管理。

### 稳定性修复

- 修复点击“导入 Mod”后文件选择器异常可能使程序退出的问题。
- 下载任务改为原位更新，不再反复销毁和重建任务卡。
- 下载百分比与阶段单调前进，旧回调不能把“解压中”“取消中”或完成状态覆盖回“下载中”。
- 保留 RAR/7Z 链接安全检查、路径边界校验、目录联接安全切换和失败更新回滚。

### 应用文件名与升级兼容

用户应从 v3.9.0 起运行 `IntegratedModManager.exe`。为了让已经安装 v3.8.5 的用户能够使用旧版自动更新器原位升级，v3.9.0 发布包暂时保留同内容的 `ModFolderCopier.exe` 兼容入口，并继续保留内部运行文件 `WinUI3/ModFolderCopier.WinUI.exe`。这是有意的单代迁移设计，不是重复安装。

更新代理同时接受新旧入口结构；本次发布验证会检查 GitHub 最新 Release API、ZIP 文件名、SHA-256、文件版本、托管文件清单以及从旧命名安装目录升级后的启动结果。

### 明确不包含的实验

v3.8.1/v3.8.2 的跨 Mod `$变量` 热覆盖、双 F10 桥接和 EFMI 常驻控制器仍然没有进入正式版。目录联接只能让加载器对 Mod 文件夹内部文件的写入直接回到仓库；它不等同于恢复 EFMI 根目录的 `d3dx_user.ini` 或只存在于游戏内存中的状态。

## English

### Release scope

v3.9.0 is a complete desktop interaction update. It retains the v3.8.5 multi-repository model, copy deployment, optional directory junctions, safe archive validation, online browser, configuration profiles, backup rollback, and automatic updates while reorganizing daily work around repositories, paths, Mods, shortcuts, online content, and update state.

### Modern responsive interface

- Rebuilt the Dashboard, repository workspace, online browser, update, and settings pages.
- Wide layouts use available horizontal space; split and compact windows reflow without large empty regions or horizontal overflow.
- Repository selection and metric cards share height, while path settings and game presets share a common top and bottom baseline.
- The workspace presents a clear Category → Mod → Preview/Shortcut hierarchy and confines scrolling to its internal lists.
- Settings are grouped into appearance, updates, online classification, and diagnostics. Wide columns align at the bottom, while compact windows expose focused sections.
- A transparent, multi-resolution Windows 11 Fluent-style icon is applied to the title bar and executable files.

### Per-repository paths and system tray

- Each repository independently stores its Mod library, target folder, and optional game launcher.
- The Dashboard displays the active repository configuration and switches its paths, online source, category ID, Wiki, and notes together.
- Optional minimize-to-tray behavior keeps repository, Mod count/readiness, online source, version, restore, and exit information available.

### Automatic shortcut discovery

- Downloaded and locally imported Mods are scanned read-only for `[Key...]` sections in `.ini` files.
- The scanner recognizes keys, modifiers, cycle/toggle variables, and common component names, formatting raw targets such as `hairacc` and `img_x` into readable text.
- Generated descriptions follow the active Chinese or English interface language; manual descriptions are never overwritten.
- The shortcut editor no longer has a ten-row product limit.
- A 256-entry defensive scan ceiling remains to prevent malformed or hostile INI files from exhausting UI resources.

### Online game presets

- Added Arknights: Endfield GameBanana category `42770`, Wiki entry, and refreshable online operator catalog.
- Existing presets for Genshin Impact, Zenless Zone Zero, and Honkai: Star Rail remain available.
- A built-in fallback catalog preserves local use if the remote Wiki cannot be reached.

### Stability fixes

- File-picker failures after selecting Import Mod no longer terminate the application.
- Download task cards update in place instead of being destroyed and rebuilt.
- Percentages and phases move monotonically; stale callbacks cannot overwrite extracting, canceling, or completed states.
- Existing RAR/7Z link validation, path-boundary protection, safe junction switching, and failed-update rollback remain intact.

### Application filename and update compatibility

Users should launch `IntegratedModManager.exe` starting with v3.9.0. To let existing v3.8.5 installations update in place through their old updater, the v3.9.0 package temporarily retains an identical `ModFolderCopier.exe` compatibility entry point and the internal `WinUI3/ModFolderCopier.WinUI.exe` runtime. This is an intentional one-generation migration design, not a duplicate installation.

The new updater accepts both entry-point layouts. Release verification checks the GitHub latest-release API, ZIP filename, SHA-256, file version, managed-file manifest, and startup after upgrading an old-name installation.

### Experiments not included

The v3.8.1/v3.8.2 cross-Mod `$variable` hot replacement, two-F10 bridge, and EFMI resident-controller prototypes remain excluded. Directory junctions only share writes made inside a Mod folder; they do not restore EFMI-root `d3dx_user.ini` state or values that exist only in game memory.
