# v4.1.1 — Optional Launch Bridge / 可选启动桥接

## English

- Optional EndfieldBridge download after upgrading, with explicit risk consent and SHA-256 verification.
- Save the launch method per Endfield repository. Declining keeps your existing loader; an empty path checks standard XXMI locations.
- First use opens bridge configuration, not the game. Improved launch-method controls in narrow windows.

The bridge is a separate download, not bundled. Third-party launching and Mods may lead to account penalties or bans. If previously adapted, restore EFMI in the bridge before switching back to the original loader.

## 中文

- 升级后可选下载终末地桥接器，需要明确确认风险，并校验 SHA-256。
- 按终末地仓库保存启动方式；不下载则使用原有加载器，未配置路径时查找 XXMI 标准安装位置。
- 首次打开桥接配置，不自动启动游戏；改善窄窗口中的启动方式按钮显示。

桥接器独立下载，不捆绑。第三方启动与 Mod 可能导致账号处罚或封禁。曾适配 EFMI 时，切回原有加载器前先在桥接器内恢复 EFMI。
