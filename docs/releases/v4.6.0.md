## 中文

4.6 重新设计了全部页面，并修复本地预览版关闭软件更新检查后无法恢复的问题。4.5 系列的功能见 [v4.5.2 发布说明](v4.5.2.md)。

### 导航

- 侧栏可以折叠成图标栏，选择会保存。
- **命令面板（Ctrl+K）**：一个搜索框覆盖六个页面、导入 Mod 与刷新仓库两个命令，以及当前仓库的角色和 Mod；方向键选择，Enter 打开，Esc 关闭。侧栏顶部的搜索框也会打开它。
- 下载入口固定在侧栏底部、设置上方，显示进行中的数量和进度，点击打开任务列表。
- 窗口较矮时导航按钮变紧凑，所有入口都能显示。

### 各页面

- **总览**：当前仓库一栏显示状态、角色和 Mod 数量；下方是路径（显示是否存在）、角色概览、仓库卡片和快捷操作（在线浏览、检查 Mod 更新、运行启动器）。点击角色直接打开它的 Mod。
- **Mod 仓库**：
  - Mod 列表显示缩略图、标签、按键数量、大小和部署状态，可以按“全部、已部署、未部署”筛选。
  - 详情信息表显示来源、位置、标签和大小：来源和标签可以直接编辑，位置可以复制。预览图按 16:9 显示，不再占满整栏。
  - 新仓库显示三步设置：选择游戏预设、设置 Mod 仓库目录、设置部署目标。
  - Mod 列表为空时说明原因（未选角色、还没有 Mod、搜索无结果），并给出导入和在线浏览入口。
  - 部署提示会写出将被替换的 Mod。
- **在线**：标题、状态和视图切换在一行，搜索、排序和筛选在一行，翻页在底部。列表和网格使用同一种卡片。详情在右侧抽屉中打开，可以切换上一个、下一个。
- **快捷键**：顶部工具栏；按键以键帽样式显示；右侧功能分成可折叠的模块，折叠时显示当前状态。
- **更新**：两栏或三栏并排时页面不再整体滚动，各列表在卡片内滚动。
  - 已追踪 Mod 改为紧凑行，可以按“全部、有更新、检查失败、已是最新”筛选并搜索；有更新的排在最前。
  - 下载历史改为紧凑行，可以按“全部、已完成、失败、已取消”筛选。
  - 两个列表只创建屏幕上的行，条目很多时也流畅。
  - 侧栏的更新入口显示可更新数量。
- **设置**：两栏总览；语言、主题和密度改为下拉框，主题新增“跟随系统”。

### 修复

- 本地预览版不再把“启动时检查软件更新”和“软件更新频率”保存为关闭。以后从预览版换回正式版时，会恢复原来的设置。
- 在线详情：Mod 简介里出现单独的“Key”或“Arrow”时，详情加载失败的问题。
- 在线翻页按钮误显示为“下一步”。
- 选中旧仓库的 Mod 时切换仓库会报错；从卡片删除其他仓库时会切换当前仓库。

### 从本地预览版恢复更新检查

本地预览版（例如 4.5.0-preview、4.5.2-preview.1）关闭了软件自身更新，不能在软件内升级。它们还把更新设置保存成了关闭，所以换回正式版后也要手动打开一次：

1. 下载 4.6.0 完整 ZIP。
2. 完全退出管理器（包括托盘图标）。
3. 把 ZIP 解压到预览版所在的文件夹并覆盖。安装包不含配置、仓库和备份，这些都会保留。
4. 启动 4.6.0，打开“设置”→“项目链接与软件版本”：打开“启动时检查软件更新”，选择“软件更新频率”，或者直接点“检查软件更新”。

此后可以正常在软件内更新。4.6.0 起，即使再用预览版，也不会改写这两项设置。

### 升级

- 4.5.2 及更早的正式版可以在软件内更新，也可以下载完整 ZIP；旧配置可以直接使用。
- 使用手册中的截图和部分位置说明仍按 4.5.2 的界面编写，后续更新。

### 已知问题与验证边界

- 已在中文界面、浅色主题下检查各页面；英文界面、深色主题下的部分新页面，以及窄于 900 像素时的更新页堆叠布局尚未逐一检查。
- 真实游戏中的保存前 F10 和真实导出的变体文件导入仍未验证；在线详情页偶发闪退（#15）仍未复现。
- 第三方 Mod 与加载器可能导致账号处罚。发布包按 AGPL-3.0-only 分发，见 [许可证说明](../LICENSING.md)；验证结果见 [验证记录](../verification/v4.6.0.md)。

## English

4.6 redesigns every page and fixes update checks staying off after a local preview build. For the 4.5 series see the [v4.5.2 notes](v4.5.2.md).

### Navigation

- The navigation collapses to an icon rail, and the choice is saved.
- **Command palette (Ctrl+K):** one search over the six pages, two commands (import Mod, refresh repository), and the current repository's characters and Mods. Arrow keys choose, Enter opens, Esc closes. The search box at the top of the navigation opens it too.
- Downloads sit at the foot of the navigation above Settings, with the running count and progress; clicking opens the task list.
- On short windows the navigation buttons get more compact, so every entry stays visible.

### Pages

- **Dashboard:** one strip for the current repository's status, character and Mod counts, then paths (showing whether each exists), a character overview, repository cards and quick actions (browse online, check Mod updates, run the launcher). Clicking a character opens its Mods.
- **Mod repository:**
  - Mod rows show a thumbnail, tags, the number of key bindings, size and deploy state, with All Mods, Deployed only and Not deployed filters.
  - The details table shows source, location, tags and size: edit the source and tags in place, copy the location. The preview keeps 16:9 instead of filling the column.
  - A new repository shows three setup steps: choose the game, set the Mod repository folder, set the deploy target.
  - An empty Mod list says why (no character selected, no Mods yet, no search match) and offers import and browse online.
  - The deploy hint names the Mod that will be replaced.
- **Online:** title, states and view switch share a row, search, sort and filters share another, paging sits at the bottom. List and grid use one card style. Details open in a drawer on the right with previous and next.
- **Shortcuts:** a toolbar at the top, key-cap bindings, and the right-hand features in collapsible modules that show their state when collapsed.
- **Updates:** with two or three columns the page no longer scrolls as a whole; each list scrolls inside its card.
  - Tracked Mods are compact rows with All, Updates, Check failed and Up to date filters and a search box; updates come first.
  - Download history is compact rows with All, Completed, Failed and Canceled filters.
  - Both lists only build the rows on screen, so they stay smooth with many entries.
  - The Updates entry in the navigation shows how many updates there are.
- **Settings:** a two-column overview; language, theme and density are drop-downs, and the theme can follow Windows.

### Fixes

- Local preview builds no longer save "Check for app updates at startup" and "App update interval" as off. Moving from a preview back to a stable build keeps your earlier choice.
- Online details failed to load when a Mod description contained a bare "Key" or "Arrow".
- The online next-page button read "Next step" in Chinese.
- Switching repositories while a Mod of the old one was selected threw an error; deleting another repository from its card switched the current one.

### Getting update checks back after a local preview

Local preview builds (for example 4.5.0-preview and 4.5.2-preview.1) have app self-update off, so they can't update in the app. They also saved the update settings as off, so turn them on once after moving back to a stable build:

1. Download the full 4.6.0 ZIP.
2. Quit the manager completely, including the tray icon.
3. Extract the ZIP over the preview's folder. The package has no configuration, repositories or backups, so those are kept.
4. Start 4.6.0 and open Settings → Project Links and App Version. Turn on "Check for app updates at startup" and pick an "App update interval", or click "Check App Updates".

In-app updates then work as usual. From 4.6.0 on, running a preview build no longer changes these two settings.

### Upgrade

- 4.5.2 and earlier stable releases can update in the app, or download the full ZIP. Existing configuration works as is.
- The user guides' screenshots and some directions still describe the 4.5.2 layout and will be updated later.

### Known issues and verification limits

- The pages were checked in the Chinese UI with the light theme; some new pages in English or the dark theme, and the stacked Updates layout below 900 px, have not each been checked.
- Real-game F10 before saving and real exported variant files remain unverified; the occasional crash on the online details page (#15) is still unreproduced.
- Third-party Mods and loaders may lead to account penalties. The package is AGPL-3.0-only; see [LICENSING](../LICENSING.md). Results are in the [verification record](../verification/v4.6.0.md).
