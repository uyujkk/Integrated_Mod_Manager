## English

4.6 reorganizes the main pages to make repositories, Mods, downloads and common actions easier to reach. It includes the features and fixes from 4.5.2.

### What's new

- **Dashboard:** a current-repository summary, repository cards, character shortcuts and quick actions.
- **Mod workspace:** a clearer character list, Mod list and details panel, with compact rows, tags, deployment status and guidance when a repository is empty.
- **Online browsing:** consistent list and grid cards, a details drawer and a layout that uses the available window width.
- **Search and navigation:** press **Ctrl+K** to find pages, commands, characters and Mods. The side navigation can collapse, with search and downloads kept within reach.
- **Shortcuts and settings:** reorganized shortcut controls and key-cap bindings, a two-column settings overview and appearance controls.
- **Updates and downloads:** compact update lists, download history and clearer empty states, with running downloads accessible from the side navigation.
- Reorganized Chinese and English manuals and added a software structure guide.

### Upgrade

- Update from the app, or download the full `Integrated_Mod_Manager-v4.6.0.zip`. For a local update, keep that ZIP intact beside `IntegratedModManager.exe` and start the existing stable app.
- The application, launcher and updater use product version **4.6.0** and file version **4.6.0.0**. Application update checks follow the saved preference.
- Back up the complete installation before upgrading. Local acceptance checks cover the 4.5.2 updater, preserved repository settings, tags and filters, combination presets, state slots, backups and snapshots, and restoring the old installation copy. See the [verification record](../verification/v4.6.0.md).
- Users of the local 4.6.0-preview.1 have application self-update disabled and the same numeric file version. Close the preview and use a fresh 4.6.0 extraction, copying their configuration and user data from a complete backup, or restore the earlier stable installation and update from there. Keep the preview backup until the new installation is checked.

### Known issues

- Real-game input and the full XXMI/EFMI launch chain have not been validated for this release. F10 hot apply and online automatic translation remain experimental; variant import still needs validation with real exported files.
- The intermittent online-details crash reported in #15 is not confirmed fixed. Changes to deployed Mods made outside the manager require a manual refresh.
- Third-party Mods and loaders can lead to account penalties. This is an unofficial tool; review the [launch and risk guide](../guides/en/Endfield-Launch.md).

## 中文

4.6 重新整理主要页面，方便访问仓库、Mod、下载和常用操作，完整保留 4.5.2 的功能与修复。

### 更新内容

- **首页**：新增当前仓库摘要、仓库卡片、角色入口和快捷操作。
- **Mod 工作区**：整理角色列表、Mod 列表和详情面板，紧凑显示标签、部署状态，并补充空仓库的操作引导。
- **在线浏览**：统一列表与网格卡片，使用详情抽屉，并根据窗口宽度安排内容。
- **搜索与导航**：按 **Ctrl+K** 搜索页面、命令、角色和 Mod。侧栏支持折叠，搜索与下载入口集中保留。
- **快捷键与设置**：整理快捷键操作区和按键样式，设置页采用双栏总览并集中外观选项。
- **更新与下载**：采用紧凑更新列表，整理下载历史和空状态，进行中的下载可以从侧栏打开。
- 重整中英文手册，并补充软件结构文档。

### 升级

- 可以在软件内更新，或下载完整 `Integrated_Mod_Manager-v4.6.0.zip`。本地更新时，把 ZIP 原样放到 `IntegratedModManager.exe` 同级，再启动现有正式版。
- 主程序、启动器和更新器的产品版本统一为 **4.6.0**，文件版本为 **4.6.0.0**。软件更新检查遵循已保存的偏好。
- 升级前请备份完整安装目录。本地验收检查 4.5.2 自带更新器，以及仓库设置、标签与过滤器、组合预设、状态槽位、备份和快照保留，并验证恢复完整旧版副本。见[验证记录](../verification/v4.6.0.md)。
- 本地 4.6.0-preview.1 关闭了软件自更新，且数字文件版本与正式版相同。请关闭预览，使用全新解压的 4.6.0，并从完整备份迁入配置和用户数据；也可以恢复此前正式版后再更新。核对新安装前请保留预览备份。

### 已知问题

- 本版尚未验证真实游戏输入及 XXMI／EFMI 完整启动链。F10 热应用和在线自动翻译仍为实验功能；变体导入仍需用真实导出文件验证。
- #15 报告的在线详情偶发闪退尚未确认修复；在管理器外修改已部署 Mod 后需要手动刷新。
- 第三方 Mod 和加载器可能导致账号处罚。本工具为非官方工具，请阅读[启动与风险说明](../guides/zh-CN/终末地启动.md)。
