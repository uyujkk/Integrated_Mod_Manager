# Integrated Mod Manager v4.0-beta

## 中文

这次测试版主要解决“切换其他 Mod 后，回来还要重新调整外观”的问题。

- 保存当前启用的 Mod 组合，并同时保存各 Mod 的持久参数。
- 一键恢复组合后，再恢复 `d3dx_user.ini` 中对应的状态；支持保存多套组合和单个 Mod 的多个状态槽位。
- 不再回写 Mod INI 默认值；保留其他 Mod 的参数，写入前自动备份，遇到路径或参数不匹配时停止。
- 修正 Alt+Tab 切换窗口时可能改变 Mod 选择的问题，游戏快捷键只作为说明，不再触发管理器部署。

当前测试环境已由用户确认：Mod 组合与状态均可恢复。不同游戏、加载器和 Mod 仍需验证，因此先发布为 **Beta**。

**使用前请注意：**完整解压到新的目录，运行 `IntegratedModManager-Beta.exe`，不要覆盖稳定版。先让加载器保存最新状态；恢复前完全退出游戏和加载器，恢复后重新启动。只支持可识别的数值型 `global persist` 参数，不是把一套参数强行移植给任意 Mod。

本版不接入软件自动更新，不替换稳定版的最新发布。在线 Mod 下载和更新仍可使用。详细步骤见包内 `TEST-GUIDE.zh-CN.md`。

## English

This beta focuses on keeping your mod setup and appearance settings when switching away and back.

- Save the enabled mod combination together with each mod's persistent values.
- Restore the combination first, then its matching values in `d3dx_user.ini`. Keep multiple combinations or individual mod state slots.
- Leave Mod INI defaults and unrelated mod values unchanged. Back up before writing and stop on mismatched paths or values.
- Fix mod selection changing during Alt+Tab. Recorded game shortcuts remain notes and no longer trigger manager deployment actions.

The user has confirmed successful combination and state restoration in their test setup. Other games, loaders, and mods still need testing, so this is a **Beta**, not a stable release.

**Before using:** fully extract into a new folder and run `IntegratedModManager-Beta.exe`. Do not overwrite the stable app. Have the loader save the current state first; fully exit the game and loader before restoring, then restart them. Only recognized numeric `global persist` values are supported; this does not transfer arbitrary settings between unrelated mods.

App self-updates are disabled and the stable latest release is unchanged. Online mod downloads and updates remain available. See the included `TEST-GUIDE.en.md`.
