# v4.1.0 — Portable Preset Bundles / 组合包与体验优化

## English

- Export saved Mod combinations with their files and persistent settings, then preview and install them in another repository.
- Reuse identical existing Mods; conflicting files are not overwritten. Restore after installation, or keep the preset for later.
- Improved large-library scanning, download cancellation and installed-state refresh.
- Fixed online previews and character avatars, with better short-window layouts.
- Settings switches to sections when the full overview cannot fit, avoiding clipped controls in restored windows.

Close the game and loader before restoring state. Bundles are not encrypted; check private files and Mod authors' permissions before sharing. Existing repositories and presets remain supported.

Maintained by **uyujkk**. Thanks to **[CaramelizedCUDA](https://github.com/CaramelizedCUDA)** for the retained Bandizip fallback contribution.

## 中文

- 新增组合包导出与安装，打包保存好的 Mod 组合、文件和状态参数，在其他仓库预览安装。
- 文件相同的 Mod 可复用，冲突文件不覆盖；安装后可恢复组合，也可先保存稍后使用。
- 优化大型仓库扫描、在线下载取消和安装状态刷新。
- 修复在线预览图与角色头像，改善短窗口排版。
- 设置总览放不下时自动分区显示，修复非最大化窗口中按钮和内容被裁切的问题。

恢复状态前请退出游戏和加载器。组合包不加密，分享前检查私人文件及作者许可。兼容现有仓库与预设。

维护者：**uyujkk**。感谢 **[CaramelizedCUDA](https://github.com/CaramelizedCUDA)** 此前贡献的 Bandizip 备用解压支持。
