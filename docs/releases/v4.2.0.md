# v4.2.0：浏览、下载与本地整理正式版

本次将 4.2 预览阶段的功能整合为正式发行版。统一程序、启动器和更新器版本为 4.2.0，恢复正式版更新检查，沿用用户保存的检查偏好。旧版和预览版附件保留。

## 主要更新

- 下载状态直接在原卡片更新，列表／方块视图保留位置。按仓库保存作者、角色、页码、搜索、排序、布局和可见条目，切换仓库或重启后继续浏览。
- 点击作者进入跨页作品；集中管理当前游戏的收藏和最近访问作者。支持搜索本地作者记录，以及本页已安装／稍后下载筛选。
- 稍后下载支持搜索、多选和集中预检，逐项选择文件版本与角色目录，再统一加入现有下载队列。已有相同文件、其他变体和旧安装记录会明确提示。
- 本地 Mod 支持批量添加、移除和替换标签，文字搜索包含标签；可保存角色、搜索和标签条件并重新应用。标签不改写 Mod 文件。
- 支持 1–4 个并发下载、取消和原位置重试。下载任务与历史持久化，重启后由用户确认中断任务，不自动开始下载。
- 旧库整理在预览后复制已有 Mod 子目录，保留原文件；增加导入前登记、所有权核对与中断恢复，修改过或无法确认的内容保留。
- 修正独立复现的图片缓存竞争，增加关闭窗口后的回调检查、本地操作上下文和下载结束后的进度清理。

## 升级与使用

建议先退出应用并备份旧程序目录和配置。下载并完整解压 ZIP，运行根目录 `IntegratedModManager.exe`。也可使用旧版更新器处理本地 ZIP；保留原始目录以便回退。使用较短的可写目录，避免旧更新器的深路径限制。

正式版恢复“检查更新”和启动检查设置，保存的关闭／手动检查偏好继续生效，不强制打开启动检查。预览版期间关闭的检查选项可以在设置中自行调整。

在线页星形按钮打开“作者与稍后下载”；本地仓库搜索框旁的“标签／筛选”管理标签和保存的条件。组合预设、持久状态、配置方案、安装备份和可选终末地桥接器能力保留。桥接器独立下载，需要明确确认和 SHA-256 校验，不包含在主 ZIP 中。

## 已知问题

- 曾发生 `Microsoft.UI.Xaml.dll / 0xc000027b` 原生闪退，原始转储不足，根因未确认。图片缓存竞争的修正不代表这一闪退已根治。
- 旧更新器在临时目录过深时可能触发 Windows 路径长度限制；使用较短路径验收升级，未修改系统设置。
- 作者名称搜索针对本地收藏／访问记录；文字和安装状态筛选仅作用于当前页。
- 不支持字节断点续传、作者更新提醒、全站作者名称检索、旧库自动分配角色、更新差异预览和重复空间管理。
- 真实游戏、XXMI／EFMI 加载与 UAC 行为尚未验证；第三方启动与 Mod 可能带来账号处罚或封禁风险，不保证账号安全。
