## 中文

### 更新工作区排版

- 宽屏下已追踪 Mod 自动使用双列卡片，减少长列表造成的单侧页面高度。
- 窄窗口继续使用单列卡片，避免路径、时间和操作按钮被压缩。
- 配置方案的新建、更新、应用和删除操作合并到同一工具行，按钮顺序与操作优先级更清楚。
- 下载任务、配置方案、安装备份和安装安全继续保持独立区域，不改变已有操作逻辑。

### 在线下载与安装

- 多文件条目默认选择最新可用压缩包，并保留完整的手动文件选择接口。
- 下载前保留角色上下文，结合分类 ID、中英文角色名、Wiki 数据和别名自动推荐角色文件夹。
- 歧义或低置信度匹配不自动选择，继续提供仓库根目录与系统文件夹选择器。
- 自动预览从详情截图中按真实像素尺寸选择清晰图片，列表缩略图仅作为最终回退。
- 已缓存图片直接复用；损坏、过小、比例异常或无法解码的图片会被跳过。
- Mod 自带预览不会被覆盖，预览失败也不会阻断下载、解压、来源记录或安装。

### 独立开发者工具

- 提供单独的 `IntegratedModManager.DeveloperTools.exe` 图形化应用和独立 ZIP。
- 可检查主程序版本、仓库配置、Mod 路径、目标路径、启动器与目录联接状态。
- 可浏览和搜索配置与日志、校验 JSON、创建配置快照并导出脱敏诊断。
- 不执行任意命令，不访问游戏进程内存，不注入游戏，也不会自动上传数据。
- 不包含在主程序 ZIP 或 `.managed-files.txt` 中，因此不会被主程序更新器安装、覆盖或删除。

## English

### Updates Workspace Layout

- Tracked Mods automatically use two columns on wide screens, reducing the one-sided height of longer lists.
- Narrow windows retain a single column so paths, timestamps, and actions remain readable.
- Profile create, update, apply, and delete actions now share one toolbar with clearer order and priority.
- Downloads, profiles, backups, and installation safety remain separate regions without changing existing behavior.

### Online Download and Installation

- Multi-file items default to the newest usable archive while retaining full manual file selection.
- Character context is preserved before download, and category IDs, localized names, Wiki data, and aliases recommend the target character folder.
- Ambiguous or low-confidence matches are not selected automatically; repository-root and system folder-picker fallbacks remain available.
- Automatic previews choose a clear detail screenshot by decoded pixel dimensions and use the list thumbnail only as the final fallback.
- Cached images are reused, while corrupt, undersized, unusually proportioned, or undecodable images are skipped.
- Mod-provided previews are preserved, and preview failure never blocks download, extraction, source tracking, or installation.

### Standalone Developer Tools

- Provides a separate graphical `IntegratedModManager.DeveloperTools.exe` application and ZIP.
- Checks app versions, repository configuration, Mod paths, target paths, launchers, and directory-junction state.
- Browses and searches configuration and logs, validates JSON, creates configuration snapshots, and exports sanitized diagnostics.
- It does not execute arbitrary commands, access game-process memory, inject into games, or upload data automatically.
- It is excluded from the main ZIP and `.managed-files.txt`, so the main updater does not install, overwrite, or remove it.
