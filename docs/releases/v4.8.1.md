# v4.8.1

基于 v4.8.0 的 Windows x64 正式版。Windows x64 stable release based on v4.8.0.

## 更新内容

- **在线分类（[#129](https://github.com/uyujkk/Integrated_Mod_Manager/issues/129)）**：在线页会按当前游戏显示 GameBanana 的一级分类和子分类。进入「皮肤」后，选「全部」可以看到未归到角色的 Mod，选「武器」等子分类可单独浏览，选角色子分类会保留角色栏。非角色 Mod 下载时可选择对应的分类文件夹。
- **跨页排序**：「按点赞」「按下载量」「按更新时间」由 GameBanana 在所选分类内排序，翻页时保持同一排序。热度和浏览量仍按当前页排序。
- **在线页稳定性**：修复列表载入后不断触发重新加载、导致窗口无响应的问题。
- **窗口与导航**：修复 Windows 11 把窗口拖到屏幕顶部最大化时的大面积黑屏。切换侧栏页面时只刷新目标页，减少界面线程的工作。主程序使用 Windows App SDK 1.7。

## 已知问题

- GameBanana 的「按更新时间」结果可能省略从未更新过的 Mod。可切换排序查看这些条目。
- 在线分类和切换已在离线样例中验证，并在独立仓库验证了连接真实 GameBanana 时的加载。真实 Mod 下载并安装到分类文件夹的完整流程仍待验证。真实游戏与加载器的验证范围见 [v4.8.0 发布说明](v4.8.0.md#尚未在真实游戏中核对的功能)。

## What's new

- **Online categories ([#129](https://github.com/uyujkk/Integrated_Mod_Manager/issues/129))**: Browse GameBanana's top-level categories and subcategories for the current game. Under Skins, choose All to include Mods that are not filed under a character, or select a subcategory such as Weapons. The character subcategory keeps the character rail. Downloads outside that subcategory can use a category folder.
- **Sorting across pages**: GameBanana sorts the selected category by likes, downloads, or last updated. Hotness and views still sort the current page.
- **Online stability**: Fixed a reload loop that could make the window stop responding after the list loaded.
- **Window and navigation**: Fixed the black area when dragging the window to the top of the screen to maximize on Windows 11. Page switches refresh the destination page only. The main app uses Windows App SDK 1.7.

## Known issues

- GameBanana's last-updated sort may omit Mods that have never been updated. Change the sort to see those entries.
- Category navigation was verified with offline samples, and loading from GameBanana was checked with an isolated repository. Downloading and installing a real Mod into a category folder still needs end-to-end verification. See the [v4.8.0 notes](v4.8.0.md#not-yet-confirmed-in-a-real-game) for the scope of game and loader verification.
