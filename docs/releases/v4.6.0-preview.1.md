Based on main `bdf3a61ab3d225b85b2d0c63d06843c90d208fd2` (2026-10-27), after stable v4.5.2. This package collects the merged interface work for local upgrade testing.

基于 2026-10-27 的 main `bdf3a61ab3d225b85b2d0c63d06843c90d208fd2`，汇总 v4.5.2 正式版之后已合并的界面改进，供本地升级测试。

## What's new / 更新内容

- Reworked the dashboard with a current-repository summary, repository cards, characters and quick actions.
  首页改为当前仓库摘要、仓库卡片、角色和快捷操作。
- Reorganized the Mod workspace, character and Mod lists, detail summary and first-run empty states; shared view models drive list selection and visible state.
  整理 Mod 工作区、角色和 Mod 列表、详情摘要以及首次使用空状态；列表选择和显示状态由共享视图模型管理。
- Refined online browsing with consistent list/grid cards, a details drawer and page-driven layout.
  在线浏览统一列表和网格卡片，使用详情抽屉，并按页面宽度调整布局。
- Added Ctrl+K search across pages, commands, characters and Mods; collapsible navigation includes search and downloads.
  新增 Ctrl+K 搜索页面、命令、角色和 Mod；侧栏支持折叠，并提供搜索和下载入口。
- Updated the shortcuts toolbar, key-cap bindings, settings overview and appearance controls; compact update/download lists use the available window width.
  更新快捷键工具栏、按键样式、设置总览和外观选项；更新与下载列表采用紧凑布局并利用窗口宽度。
- Reorganized bilingual manuals and documented the software structure. Kept source in src/, tests/ and tools/.
  重整双语手册，补充软件结构文档；源码继续使用 src/、tests/、tools/ 结构。

## Upgrade / 升级

The stable app recognizes numeric local-update filenames only. The supplied `Integrated_Mod_Manager-v4.6.0.zip` contains **4.6.0-preview.1**, file version **4.6.0.0**. It is a local preview, with application self-update disabled.

正式版只识别纯数字文件名的本地更新包。本次提供的 `Integrated_Mod_Manager-v4.6.0.zip` 内部产品版本为 **4.6.0-preview.1**，文件版本为 **4.6.0.0**。这是本地预览，软件自更新关闭。

Close the stable app and game/Endfield launch session, copy the ZIP beside `IntegratedModManager.exe` in the existing installation, then start the stable app and confirm the detected local update. Keep the ZIP intact. Back up the complete installation before upgrading; retain that backup to return to stable after closing the preview. An isolated extracted copy can also be used for trying the UI.

关闭正式版和游戏／终末地启动会话，把 ZIP 原样放到现有安装目录，与 `IntegratedModManager.exe` 同级，再启动正式版，确认检测到的本地更新。升级前备份完整安装目录；需要回到正式版时，关闭预览并恢复完整备份。也可以单独解压到新目录试用界面。

## Known issues / 已知问题

- This preview has local verification only. Its exact preview commit has not run remote CI and no GitHub Release is published. See the accompanying verification record for measured results.
  本预览仅完成本地验证；预览提交未运行远端 CI，未发布 GitHub Release。实际结果见随包验证记录。
- Real-game input, the XXMI/EFMI launch chain and live Mod-library import/deployment are outside this package's acceptance scope. F10 hot apply and online automatic translation remain experimental; variant import remains unverified with real exported files.
  本次验收不包含真实游戏输入、XXMI／EFMI 完整启动链，以及真实 Mod 库导入和部署。F10 热应用和在线自动翻译仍为实验功能；变体导入仍未用真实导出文件验证。
- Online detail crashes reported in #15 remain unconfirmed. External changes to deployed Mods require a manual refresh.
  #15 报告的在线详情偶发闪退仍未确认修复；外部修改已部署 Mod 后需要手动刷新。
