# v4.8.6

基于 v4.8.5 的 Windows x64 正式版。Windows x64 stable release based on v4.8.5.

## 更新内容

用户反馈引导不够清楚，很多功能的入口藏在二级菜单或右键菜单里，不容易找到。这个版本据此调整（[#157](https://github.com/uyujkk/Integrated_Mod_Manager/pull/157)），不加开场的分步弹窗。

- **原来只能右键的操作有了看得见的按钮**（右键菜单保留，作为快捷方式）：
  - 仓库：选中角色后，Mod 卡片标题旁有头像、重命名、打开文件夹和“可同时启用多个”开关；状态槽位列表旁有“更新”和“重命名”。
  - 在线：每张卡片上有“加入稍后下载”按钮（时钟图标），详情抽屉底部也有；详情里作者下方可以“收藏作者”和查看“X 的全部作品”。
  - 更新：每一行都有“打开文件夹”；下载记录为空时可以直接去在线页。
- **搜索能找到全部功能**：
  - 按 Ctrl+K 或点标题栏的搜索框。82 个功能都写明在哪里、有什么快捷键，可以用名字、位置或别的说法搜到（例如“回滚”“d3dx_user”）。
  - 选中一个功能会切到对应页面，展开它所在的分组，滚动过去，并用强调色框出它；需要先选中角色或 Mod 的功能会在底部说明位置。
  - “设置 › 界面与语言 › 搜索显示方式”：
    - **详细**（默认）：像 Windows 8 的开始屏幕，铺满窗口，每个功能一块磁贴，按页面分组、左右滚动；常用功能是宽磁贴并直接写出位置。指向或用方向键移到磁贴时，底部显示它在哪里；直接打字就变成搜索结果。设置项没有磁贴，打字可以搜到。
    - **简略**：和以前一样只列出页面和命令，输入文字时才显示功能。
- **不打断的引导**：
  - 新安装后，仪表板顶部有“上手清单”：设置游戏和路径、添加第一个 Mod、启用一个 Mod、用搜索找功能、看看快捷键和浮窗。在任何地方做完都会自动打勾，每项的按钮会带你到对应位置。点“隐藏”就不再出现，可以在搜索里找“显示上手清单”再打开。它取代了以前的三步引导弹窗，升级的用户不会看到。
  - 仓库、在线、更新、快捷键四页第一次打开时各有一条提示，点 ✕ 后不再出现。
  - 标题栏搜索框旁的 ? 按钮打开当前页的使用说明。
  - “新功能”对话框里可以直接打开全部功能。
- **其他**：新文字有中文、英文和俄文。主程序、启动器、更新器和开发者工具使用 4.8.6。“新功能”对话框更新为 4.8.6 的内容，升级后显示一次。快速上手和用户手册已更新。

## 已知问题

- 新的磁贴搜索、上手清单和页面提示没有在高对比度主题下截图检查（检查需要更改系统设置）；高对比度时磁贴改用系统颜色。
- 俄语界面只核对了文字，没有截图检查；俄语文字没有请母语者审校。
- 窗口不高时磁贴只排两三行，较长的功能名会截断；完整位置在底部那行和鼠标悬停提示里。
- 4.8.5 列出的已知问题仍然有效：联接部署的修复还没有在真实游戏和 EFMI 加载器里核对，以及 4.8.4、4.8.3 列出的核对项。见 [v4.8.5 发布说明](v4.8.5.md#已知问题)。
- 真实游戏与加载器的其他验证范围见 [v4.8.0 发布说明](v4.8.0.md#尚未在真实游戏中核对的功能)。

## What's new

Users said guidance was unclear and many features were hard to find because they sat in second-level or right-click menus. This release addresses that ([#157](https://github.com/uyujkk/Integrated_Mod_Manager/pull/157)) without a step-by-step popup at first start.

- **Visible buttons for actions that were only in right-click menus** (the menus stay as shortcuts):
  - Repositories: select a character and the Mod card heading has its avatar, rename, open folder and a **Several at once** toggle; the state slot list has **Update** and **Rename** beside it.
  - Online: every card has a save-for-later button (a clock), and so does the bottom of the details drawer; under the author in the details, **Save author** and **All works by …**.
  - Updates: every row has an open-folder button, and the empty download history leads to the Online page.
- **A search that finds every feature**:
  - Press Ctrl+K or click the search box in the title bar. All 82 features say where they are and their shortcut, and are found by their name, their place or another word for them (for example "rollback" or "d3dx_user").
  - Picking one opens its page, unfolds the group it is in, scrolls to it and outlines it in the accent colour; a feature that needs a selected character or Mod first says where it is at the bottom of the window.
  - Settings › Appearance and Language › **Search style**:
    - **Detailed** (the default): like the Windows 8 start screen, it fills the window with a tile for every feature, grouped by page and scrolling sideways; the main features are wide tiles that also say where they are. Pointing at a tile or moving to it with the arrow keys shows where it is at the bottom; typing turns it into search results. Settings have no tiles and are found by typing.
    - **Brief**: as before, pages and commands, with features shown as you type.
- **Guidance that does not interrupt**:
  - After a first install, the dashboard has a **First steps** card: set the game and paths, add a first Mod, turn a Mod on, find features with the search, and look at shortcuts and the overlay. Each one ticks itself off when you do it anywhere, and its button takes you to the place. **Hide** closes it; the search can show it again (**Show the first steps**). It replaces the three-step tips popup; upgrades do not get it.
  - Repositories, Online, Updates and Shortcuts each show one tip the first time; its ✕ closes it for good.
  - The **?** button beside the search box in the title bar opens the guide for the page on screen.
  - The What's New dialog links to the full feature list.
- **Other**: The new texts are in Chinese, English and Russian. The app, launcher, updater and Developer Tools use version 4.8.6. The What's New dialog describes 4.8.6 and shows once after upgrading. The Quick Start and User Guide are updated.

## Known issues

- The new tile search, First steps card and page tips were not checked with screenshots in a high-contrast theme, because that needs a system setting changed; in high contrast the tiles use system colours.
- The Russian interface was checked through its texts only, without screenshots, and has not been reviewed by a native speaker.
- In a short window the start screen fits only two or three rows of tiles, and long feature names are cut off; the full place is in the line at the bottom and in the tooltip.
- The known issues listed for 4.8.5 still apply: the junction fix has not been checked in a real game with the EFMI loader, and the checks listed for 4.8.4 and 4.8.3 remain open. See the [v4.8.5 notes](v4.8.5.md#known-issues).
- See the [v4.8.0 notes](v4.8.0.md#not-yet-confirmed-in-a-real-game) for the scope of other game and loader verification.
