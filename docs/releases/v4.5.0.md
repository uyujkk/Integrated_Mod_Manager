## 中文

### 新功能

#### 角色文件夹头像

- 仓库页左侧每个角色前显示头像，按以下顺序选择：
  1. 角色文件夹里的 `.imm_avatar.*` 或 `avatar.*` 图片；
  2. 手动绑定的角色；
  3. 与文件夹同名的角色。中文名、英文名、别名都可以，忽略大小写、全半角和空格。
- 角色名单与“在线”页共用同一份目录：终末地用官方干员列表（内置干员表补缺），其他游戏用 Wiki 加 GameBanana 角色分类。目录超过一天未更新时会在后台刷新，所以新出的角色一天内就会出现在列表里，并显示头像。内置干员表新增祀、明河、提弗洛斯、噗切娜。
- 选中角色后，点击列表上方的**头像按钮**（或右键角色 → “头像”），可以：
  - 选择图片：复制到角色文件夹，原图保留为 `.imm_avatar.previous.*`；
  - 绑定到角色：文件夹名对不上时手动指定；
  - 恢复上一张头像，或移除自定义头像。

#### 每个角色同时启用多个 Mod

- 以目录联接方式启用 Mod 时，默认每个角色只保留一个，启用新的会替换同角色其他 Mod 的链接。
- 选中角色后，点击头像按钮右边的**多选开关**（或右键 → “允许同时启用多个 Mod”），这个角色就可以同时启用多个 Mod。开关亮起表示允许。
- 编辑仓库时可以把默认值改为允许多个，再对个别角色关闭。
- 复制模式不会自动移除同角色的其他副本。
- 恢复组合预设时，如果某个只允许单选的角色下有多个 Mod，会先询问。

#### 单 Mod 状态槽位与变体

选中 Mod，打开右侧的**“状态槽位”**页：

- 保存当前的 `global persist` 参数为命名槽位，每个 Mod 可以保存多个。最近保存、更新或恢复的槽位标为“当前”。
- “更多…”菜单：
  - 用当前值更新所选槽位、重命名槽位；
  - **写入 Mod 默认值**：把槽位的值写进 Mod 自己 ini 的默认值，清空或删除 `d3dx_user.ini` 后也能保留。写入前逐个文件备份为 `.imm-persist-*.bak`，写完读回核对，失败自动还原；复制模式下会同步修改已部署的副本。
  - **导入 JASM 变体**：读取 JASM 的 `.JASM_Variants.json`，每个变体导入为一个槽位。
  - **整份 `d3dx_user.ini` 快照**：保存、恢复、打开快照文件夹，作为手动还原点。恢复前会备份当前文件。

#### F10 热应用（实验）

- 游戏运行时，加载器会在按 F10 和退出游戏时，把内存里的旧值写回 `d3dx_user.ini`，所以直接改文件没有用。热应用的做法是：写入后，在发送 F10 的几秒内把 `d3dx_user.ini` 设为只读，让加载器读到刚写入的值，之后恢复文件原来的属性。
- 恢复槽位或快照时，勾选“游戏正在运行：写入后发送 F10 热重载”，不用退出游戏。
- 在“快捷键”页打开“在置顶浮窗中热切换状态槽位”后，浮窗（Ctrl + Alt + K）会列出当前 Mod 的槽位，点一下即可切换。
- 按键通过快捷键模块发送到游戏窗口，权限检查与快捷键相同：终末地需要以管理员身份运行管理器。

#### 快捷键与窗口

- 游戏运行时，“快捷键”页和浮窗会自动选中游戏窗口（终末地 `Endfield.exe`，以及原神、星穹铁道、绝区零），先开管理器、后开游戏也能识别。发送开关仍需手动打开。
- 修复：测试版中置顶浮窗无法打开的问题。
- 最大化后还原，窗口会缩到屏幕工作区的 80% 并居中；最大化状态在下次启动时保留。以前存成全屏的窗口尺寸会自动修正。
- 首次启动时提示本版新功能，并说明入口位置。

### 改进与修复

- 界面文案移到 `WinUI3/Strings` 下的中英文语言文件，显示效果不变。
- 在线数据解析、角色匹配和部署规则移到核心库，并补充了测试。
- 原先静默忽略的缓存写入、Mod 更新检查等失败，现在会记录到日志。
- 热度分数在计数极大时不再变成 NaN。
- 不再在启动时弹出终末地启动的升级引导，启动方式仍可在仪表板的仓库路径卡片中设置。

### 升级与使用

- 4.4.0 及更早版本可以通过软件内更新升级到本版，也可以下载完整 ZIP 解压使用。手动迁移时，先退出新旧两个程序，再复制 `WinUI3/config.ini` 和 `WinUI3/beta-shell.json`。
- 新功能使用的设置都是新增字段，旧配置可以直接读取。
- 4.5.0-preview 测试包用户请改用本正式版；测试包关闭了软件自身更新。

### 已知问题与验证边界

- F10 热应用依赖加载器在 F10 时先保存、再读取 `d3dx_user.ini`（3DMigoto/XXMI 的默认行为），目前只用模拟加载器和用户实测验证过。如果 F10 没有送达，写入的值会在退出游戏时被覆盖，状态栏会提示。
- 在线详情页偶发原生闪退（#15）仍未复现，根因未确认。
- 第三方 Mod 与加载器可能导致账号处罚或封禁，不保证账号安全。本版发布包整体按 AGPL-3.0-only 分发，见 [许可证说明](../../LICENSING.md)。测试与验证结果见 [验证记录](../verification/v4.5.0.md) 及包内 `PACKAGE-INFO.json`。

## English

### New features

#### Character folder avatars

- Each character on the left of the repository page shows an avatar, chosen in this order:
  1. an `.imm_avatar.*` or `avatar.*` image in the character folder;
  2. a character you bound the folder to;
  3. the character whose Chinese name, English name or alias equals the folder name (case, width and spaces are ignored).
- The character list is the Online page's catalog: the official operator list for Endfield (the built-in list fills gaps), the wiki plus GameBanana character categories for other games. A catalog older than a day refreshes in the background, so newly released characters appear, with avatars, within a day. The built-in Endfield list adds Si, Argent Flow, Typhoeus and Purrchena.
- Select a character and click the **avatar button** above the list (or right-click → Avatar) to:
  - choose an image, which is copied into the folder while the old one is kept as `.imm_avatar.previous.*`;
  - bind the folder to a character when its name doesn't match;
  - restore the previous avatar, or remove the custom one.

#### Several Mods per character

- With directory-link deployment, each character keeps one enabled Mod by default: enabling another replaces the links of its other Mods.
- Select a character and click the **toggle** to the right of the avatar button (or right-click → Allow several enabled Mods) to keep several enabled for it. A highlighted toggle means several are allowed.
- The repository editor can make several Mods the default, with individual characters turned back to one.
- Copy mode never removes sibling copies automatically.
- Restoring a combination preset asks first when it enables several Mods of a single-selection character.

#### Single-Mod state slots and variants

Select a Mod and open the **State Slots** tab:

- Save the current `global persist` values as named slots, several per Mod. The slot saved, updated or restored last is marked current.
- The **More…** menu:
  - update the selected slot from the current values, or rename it;
  - **Write slot as Mod defaults**: writes the values into the Mod's own INI defaults, so they survive clearing or deleting `d3dx_user.ini`. Each file is backed up beside it as `.imm-persist-*.bak` first, the result is read back, and failures restore the originals. In copy mode the deployed copy changes too.
  - **Import JASM variants**: reads JASM's `.JASM_Variants.json` and adds one slot per variant.
  - **Whole `d3dx_user.ini` snapshots**: save, restore (the current file is backed up first) and open the snapshot folder, as manual restore points.

#### F10 hot apply (experimental)

- While the game runs, the loader writes its in-memory values back to `d3dx_user.ini` on F10 and on exit, so editing the file alone does nothing. Hot apply writes the file, keeps it read-only for a few seconds around F10 so the loader reads the new values, then restores the file's attributes.
- When restoring a slot or snapshot, check "The game is running: send F10 after writing" instead of closing the game.
- With "Switch state slots in the overlay" on (Shortcuts page), the overlay (Ctrl + Alt + K) lists the current Mod's slots and switches with one click.
- Keys go to the game window through the shortcut module with the same permission checks: Endfield needs the manager to run as administrator.

#### Shortcuts and window

- While a game runs, the Shortcuts page and the overlay select its window automatically (Endfield `Endfield.exe`, plus Genshin Impact, Star Rail and Zenless Zone Zero), even if the game starts after the manager. Turning input on stays manual.
- Fixed: the overlay could not open in the test builds.
- Restoring a maximized window shrinks it to 80% of the work area, centered; the maximized state is kept for the next start. Window sizes saved as full screen are corrected.
- The first start shows what's new and where to find it.

### Improvements and fixes

- UI text moved into Chinese and English language files under `WinUI3/Strings`; nothing changes on screen.
- Online data parsing, character matching and deployment rules moved into the core library with tests.
- Failures that used to be ignored silently, such as cache writes and the Mod update check, are now logged.
- The hotness score no longer becomes NaN for very large counts.
- The Endfield launch upgrade prompt no longer appears at startup; the launch method is still set from the repository path card on the dashboard.

### Upgrade and use

- 4.4.0 and earlier can update in the app, or download the full ZIP. To migrate by hand, close both versions and copy `WinUI3/config.ini` and `WinUI3/beta-shell.json`.
- New settings are new fields only; older configuration loads as is.
- 4.5.0-preview test build users should switch to this release; the test build had application self-update off.

### Known issues and verification limits

- F10 hot apply relies on the loader saving and then reading `d3dx_user.ini` on F10 (the 3DMigoto/XXMI default). It has been checked with a simulated loader and by a user. If F10 does not arrive, the written values are overwritten when the game exits, and the status line says so.
- The occasional native crash on the online details page (#15) is still unreproduced.
- Third-party Mods and loaders may lead to account penalties or bans; account safety is not guaranteed. The package as a whole is AGPL-3.0-only; see [LICENSING](../../LICENSING.md). Test and verification results are in the [verification record](../verification/v4.5.0.md) and the package's `PACKAGE-INFO.json`.
