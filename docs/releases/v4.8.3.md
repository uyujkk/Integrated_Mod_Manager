# v4.8.3

基于 v4.8.2 的 Windows x64 正式版。Windows x64 stable release based on v4.8.2.

## 更新内容

- **启动更快（[#141](https://github.com/uyujkk/Integrated_Mod_Manager/pull/141)–[#149](https://github.com/uyujkk/Integrated_Mod_Manager/pull/149)）**：
  - Mod 工作区和在线页改为第一次打开时才创建。上次关闭时停在仪表板、设置、更新或快捷键页的话，启动时不再创建这两页。
  - 在本机用合成测试数据测得（启动到主界面显示，7 次取中位数）：停在仪表板时 1,030 → 900 毫秒，停在在线页时 950 → 820 毫秒，停在 Mod 工作区时 970 → 940 毫秒。
  - 代价是第一次打开 Mod 工作区时要先创建页面，比 4.8.2 多等约 80 毫秒（210 → 290 毫秒）。之后再切换回来和以前一样快（约 30–40 毫秒）。在线页第一次打开时的创建约 20 毫秒。
  - 这两页没打开时，启动时的仓库扫描、默认槽位、命令面板、浮窗、仪表板上的路径和角色、下载和重试照常工作。
- **开发者工具单独下载（[#139](https://github.com/uyujkk/Integrated_Mod_Manager/pull/139)）**：
  - 从这个版本开始，每次发布除了主程序的 ZIP，还附带 `Integrated_Mod_Manager_Developer_Tools-v4.8.3.zip`。普通使用不需要它。
  - 解压到软件所在的文件夹，会生成 `DeveloperTools` 文件夹。之后可以从“设置 → 诊断与问题报告 → 开发者工具”或命令面板（Ctrl+K）的“打开开发者工具”打开。没有安装时，这两个入口会打开发布页面。
  - 开发者工具重新制作，使用和主程序一样的外观，有中文、英文和俄文。它只读取软件的数据，不做修改：复制记录、状态槽位和失效链接、日志、缓存大小、Mod 的按键、翻译对照，以及去除隐私信息的诊断报告。在线缓存和 GameBanana 登录可以在确认后清除，而且只能在主程序关闭时清除。
  - 软件自动更新只下载主程序的 ZIP，不会下载或更新开发者工具。开发者工具和主程序使用同一个版本号，升级主程序后如需新版工具，请重新下载。
- **内部结构整理（#141–#149）**：
  - 安装、下载、追踪的 Mod、状态槽位、预设图片、组合预设、Mod 工作区、配置文件、启动器、快捷键和浮窗、软件更新、托盘图标和命令面板，都从主窗口拆成了独立的部分。主窗口的代码从约 10,400 行减到约 3,600 行。
  - 这次整理不改变数据格式，也不打算改变任何行为。每一步拆分前，都先写了界面测试，把当时的行为固定下来，拆分后再全部运行一次。界面测试从 4.8.2 的 79 个增加到 121 个，Core 单元测试从 1,930 个增加到 1,991 个。
- **其他**：主程序、启动器、更新器和开发者工具使用 4.8.3。“新功能”对话框更新为 4.8.3 的内容，升级后显示一次。软件结构文档已更新，附带能在 GitHub 上直接显示的结构图（[#137](https://github.com/uyujkk/Integrated_Mod_Manager/pull/137)）。

## What's new

- **Faster startup ([#141](https://github.com/uyujkk/Integrated_Mod_Manager/pull/141)–[#149](https://github.com/uyujkk/Integrated_Mod_Manager/pull/149))**:
  - The Mod workspace and the Online page are now created the first time you open them. If the app was last closed on the Dashboard, Settings, Updates or Shortcuts, startup no longer creates those two pages.
  - Measured on one computer with synthetic test data (start to the main window shown, median of 7): 1,030 → 900 ms when opening on the Dashboard, 950 → 820 ms on the Online page, and 970 → 940 ms on the Mod workspace.
  - In exchange, the first visit to the Mod workspace creates the page and takes about 80 ms longer than in 4.8.2 (210 → 290 ms). Later visits are as fast as before (about 30–40 ms). Creating the Online page on its first visit takes about 20 ms.
  - While those pages are not open, the startup scan of the repository, Default slots, the command palette, the overlay, the paths and characters on the Dashboard, downloads and retries work as before.
- **Developer Tools as a separate download ([#139](https://github.com/uyujkk/Integrated_Mod_Manager/pull/139))**:
  - From this release on, every release has `Integrated_Mod_Manager_Developer_Tools-v4.8.3.zip` beside the app's ZIP. You do not need it for everyday use.
  - Extract it into the app's folder; it creates a `DeveloperTools` folder. Then open the tools from Settings → Diagnostics and Issue Report → **Developer Tools**, or with **Open Developer Tools** in the command palette (Ctrl+K). When they are not installed, both open the release page.
  - The tools are rebuilt with the app's look, in Chinese, English and Russian. They read the app's data without changing it: copy records, state slots and broken links, logs, cache sizes, a Mod's keys, translations, and a sanitized diagnostic report. Online caches and the GameBanana sign-in can be cleared after a confirmation, and only while the app is closed.
  - The app's own updater downloads only the app's ZIP; it never downloads or updates the Developer Tools. The tools carry the same version number as the app, so download them again after upgrading if you want the matching version.
- **Internal restructure (#141–#149)**:
  - Installing, downloads, tracked Mods, state slots, preset pictures, combination presets, the Mod workspace, the settings files, the launcher, shortcuts and the overlay, app updates, the tray icon and the command palette moved out of the main window into their own parts. The main window's code went from about 10,400 lines to about 3,600.
  - No data format changes, and no behaviour changes are intended. Before each move, new UI tests pinned what the app did; after it, the whole suite ran again. There are now 121 UI tests (79 in 4.8.2) and 1,991 Core unit tests (1,930 in 4.8.2).
- **Other**: The app, launcher, updater and Developer Tools use version 4.8.3. The What's New dialog describes 4.8.3 and shows once after upgrading. The software structure docs are up to date, with diagrams that display on GitHub ([#137](https://github.com/uyujkk/Integrated_Mod_Manager/pull/137)).

## Known issues

- These are still verified only with a test window, synthetic data or offline sample pages, not in a real setting:
  - The overlay sending F10 in a real game (saving a preset, switching state slots), and character follow. For the other open checks of the 4.8.2 overlay, see the [v4.8.2 notes](v4.8.2.md#known-issues).
  - The tray icon's own right-click menu and double-click (the automated tests only confirm that the window hides when minimized to the tray).
  - **Run launcher** with a real launcher (the automated tests cover only the case with no launcher set).
  - Signing in, liking and unliking on the GameBanana page with a real account.
- The startup and switching times were measured on one computer with synthetic test data. With many Mods and characters, the first visit to the Mod workspace takes noticeably longer.
- See the [v4.8.0 notes](v4.8.0.md#not-yet-confirmed-in-a-real-game) for the scope of other game and loader verification.
