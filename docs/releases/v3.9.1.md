## 中文

### 工作区与设置

- 进一步压缩“更新”页面的空白，将已追踪 Mod、下载任务、配置方案、安装安全和安装备份重组为更紧凑的操作区。
- 在线 Mod 卡片的角色、热度和统计信息改用更清晰的小圆角矩形、标线与文字层级，不再使用圆形内容框。
- 设置页补充调用的开源程序、项目仓库和作者 B 站主页入口，并维持固定视口布局，避免整个页面上下滚动。

### 独立开发者工具

- 新增单独构建的 `IntegratedModManager.DeveloperTools.exe`，不会出现在主程序导航或主程序发布目录中。
- 可选择并记忆主程序目录，查看版本、仓库数量、关键文件、缓存和备份占用。
- 可解析仓库配置并检查 Mod 仓库、目标目录、启动器和目录联接状态。
- 可浏览与搜索配置及日志、校验 JSON、复制或另存内容。
- 可在开发者工具自己的数据目录创建配置快照，并导出替换用户名和本地路径的脱敏诊断包。
- 工具不执行任意命令，不访问游戏进程内存，不注入游戏，也不会自动上传诊断数据。

### 发布边界

- 主程序继续使用既有的更新兼容结构：`IntegratedModManager.exe`、`ModFolderCopier.exe`、`LocalUpdateAgent.exe`、`WinUI3/ModFolderCopier.WinUI.exe` 与 `.managed-files.txt`。
- 开发者工具独立打包，不进入 `.managed-files.txt`，因此不会被主程序自动更新器安装、覆盖或删除。
- 本地候选包只用于验证；确认后再决定是否提交源码、推送分支并创建 GitHub Release。

## English

### Workspace and Settings

- Further reduced unused space on the Updates page by regrouping tracked Mods, downloads, profiles, installation safety, and backups into compact action regions.
- Replaced circular character, heat, and statistic containers on online Mod cards with clearer small-radius rectangles, edge markers, and typography.
- Added open-source dependency, project repository, and author Bilibili links to Settings while retaining a fixed viewport without whole-page vertical scrolling.

### Standalone Developer Tools

- Added the separately built `IntegratedModManager.DeveloperTools.exe`, which is absent from main-app navigation and the main release directory.
- It can remember a selected app directory and summarize versions, repositories, critical files, cache, and backup storage.
- It parses repository configuration and checks Mod library, target, launcher, and directory-junction state.
- It can browse and search configuration and log files, validate JSON, and copy or save content.
- It stores configuration snapshots in its own data directory and exports sanitized diagnostics with user and local path values replaced.
- It does not execute arbitrary commands, access game-process memory, inject into games, or upload diagnostics automatically.

### Release Boundary

- The main package preserves the existing updater-compatible layout: `IntegratedModManager.exe`, `ModFolderCopier.exe`, `LocalUpdateAgent.exe`, `WinUI3/ModFolderCopier.WinUI.exe`, and `.managed-files.txt`.
- Developer Tools is packaged separately and excluded from `.managed-files.txt`, so the main updater will not install, overwrite, or remove it.
- These local candidate packages are for verification only. Source commits, branch pushes, and a GitHub Release remain deferred until confirmation.
