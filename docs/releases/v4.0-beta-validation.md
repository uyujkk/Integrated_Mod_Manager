## Actual game result and remaining limits

The user reported successful restoration of the mod combination and state in their actual setup before requesting this release. That is user-confirmed evidence, not an independently observed game session. Other mods, namespaces, encodings, games, and loader versions still require real testing.

Restore only after the game and loader have exited. Parameters are patched in the selected `d3dx_user.ini`, not restored to source Mod INIs. A matching file value does not prove a matching rendered appearance. Deployment Undo does not undo parameter changes.

## Publication boundary

Publish to `beta/4.0` and tag `v4.0-beta`; GitHub Release must be a prerelease and not latest. Do not change main or stable assets. Verify the stable `/releases/latest` response remains v3.9.5 after publishing.

Beta application update checks, startup checks, online installer, and local update-package installer are all guarded off, including imported old configuration. Mod update checks remain separate. No app updater executable is shipped in this beta.
