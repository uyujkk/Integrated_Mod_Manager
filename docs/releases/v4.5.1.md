## 中文

4.5.1 在 4.5.0 基础上新增：可以在置顶浮窗里命名并保存单 Mod 预设。下面汇总 4.5 系列的全部新功能，详细说明见 [v4.5.0 发布说明](v4.5.0.md)。

### 本版新增

- **浮窗保存单 Mod 预设：** 先在游戏中按 F10，再在浮窗（Ctrl + Alt + K）点击“保存单 Mod 预设”，输入名称即可。预设保存为当前 Mod 的状态槽位。空名称或同名不能保存；缺少已保存的参数时会提示，不会用默认值补齐。输入完成后焦点交还游戏窗口。

### 4.5 系列功能

- **角色头像：** 仓库页每个角色显示头像，按文件夹名自动匹配，也可以自定义或手动绑定；新角色一天内进入角色列表。
- **每个角色启用多个 Mod：** 默认单选，可按角色打开多选开关。
- **单 Mod 状态槽位：** 保存多套参数变体，可写入 Mod 默认值（自动备份）、导入变体文件（待验证）、保存整份 `d3dx_user.ini` 快照。
- **F10 热应用（实验）：** 游戏运行时恢复槽位，浮窗里一键切换。
- **快捷键与窗口：** 自动识别游戏窗口；最大化后还原缩到屏幕的 80%。

### 升级

- 4.5.0 及更早版本可在软件内更新，也可以下载完整 ZIP。旧配置直接可用。
- 已知问题与 4.5.0 相同：F10 热应用尚未在真实加载器下自动化验证；在线详情页偶发闪退（#15）仍未复现。第三方 Mod 与加载器可能导致账号处罚。发布包按 AGPL-3.0-only 分发，见 [许可证说明](../../LICENSING.md)；验证结果见 [验证记录](../verification/v4.5.1.md)。

## English

4.5.1 adds naming and saving a single-Mod preset from the overlay on top of 4.5.0. Below is a summary of everything new in 4.5; see the [v4.5.0 notes](v4.5.0.md) for details.

### New in this release

- **Save a single-Mod preset from the overlay:** press F10 in the game, then click "Save single-Mod preset" in the overlay (Ctrl + Alt + K) and enter a name. The preset is saved as one of the current Mod's state slots. Blank and duplicate names are rejected; missing saved values are reported instead of filled with defaults. Focus returns to the game window afterwards.

### The 4.5 series

- **Character avatars:** each character on the repository page shows an avatar, matched from the folder name or set by hand; new characters appear within a day.
- **Several Mods per character:** single selection by default, with a per-character toggle.
- **Single-Mod state slots:** several value sets per Mod, written into Mod defaults (with backups), imported from variant files (unverified), or saved as whole `d3dx_user.ini` snapshots.
- **F10 hot apply (experimental):** restore slots while the game runs, or switch them with one click in the overlay.
- **Shortcuts and window:** the game window is detected automatically; restoring a maximized window shrinks it to 80% of the screen.

### Upgrade

- 4.5.0 and earlier can update in the app, or download the full ZIP. Existing configuration works as is.
- Known issues are the same as 4.5.0: F10 hot apply is not yet verified automatically under a real loader, and the occasional crash on the online details page (#15) is still unreproduced. Third-party Mods and loaders may lead to account penalties. The package is AGPL-3.0-only; see [LICENSING](../../LICENSING.md). Results are in the [verification record](../verification/v4.5.1.md).
