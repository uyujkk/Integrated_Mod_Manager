# 4.2.0-preview.3：批量下载、浏览记忆、作者管理与本地标签

在 preview.2 上增加本次确认的四项功能，旧版整合包保留。其他建议功能暂不纳入本次范围。

## 功能入口

1. 在线页的星形按钮打开“作者与稍后下载”。在“稍后下载”中搜索、勾选或全选可见项，然后选择“批量下载所选”。读取文件信息后，在清单内分别选择下载文件和目标角色目录，统一加入原有下载队列。读取失败、不支持自动解压或已有活动任务的条目不能入队。遇到已有安装时展示相同文件、其他变体或无法识别的旧记录；需要明确勾选“允许独立副本”才能继续。关闭准备窗口或取消清单不会开始下载。
2. 按仓库 ID、目录、来源和游戏分类保存在线页的作者、角色、页码、搜索、排序、列表／方块布局与浏览位置。切换仓库和重启后恢复；页面仍有原条目时优先定位条目，否则按滚动距离恢复。主动换页、切换筛选或排序从顶部开始。恢复浏览状态不会自动启动下载。
3. “作者管理”整合当前游戏的收藏和最近访问作者，可按名称搜索、切换记录范围、收藏作者并进入跨页作品。在线页可选择“本页全部／已安装／稍后下载”。此搜索是本地作者记录搜索，不是全站作者检索；作品文字和安装状态筛选仍只作用于当前页。
4. 本地仓库的 Mod 搜索框旁增加“标签”和“筛选”。可勾选当前列表中的多个 Mod，统一添加、移除或替换标签；右键单个 Mod 也可编辑。搜索同时匹配名称和标签。“筛选”支持按标签过滤，保存当前角色、搜索和标签条件，随后应用或删除。标签仅存于管理器配置，不写入 Mod 文件。

## 数据与边界

- 新字段增加到 `WinUI3/beta-shell.json`，沿用原配置备份机制。在线会话最多 64 个，最近作者和收藏作者各最多 100 个，保存的本地筛选每仓库最多 50 个。每个 Mod 最多 16 个标签，每个标签最多 32 字。
- 本地标签按仓库 ID、仓库路径和 Mod 相对目录隔离。同一仓库 ID 改指向另一个目录，不会套用原标签。通过管理器重命名角色目录时迁移其标签与保存的筛选；外部移动或重命名暂不自动追踪。
- 批量下载逐项使用现有并发、取消、历史记录和重启恢复机制。保存清单保留，下载失败不会阻止其他已经加入队列的任务。批量清单限制在原仓库根目录或其有效角色目录内。
- 全站作者名称搜索、作者更新提醒、断点续传、旧库自动归类、更新差异预览和重复空间管理均未在本次加入。
- 原生 XAML 闪退根因尚未确定，本包仍是开发预览，按 GitHub 预发布通道提供；软件自身自动更新继续关闭，v4.1.1 稳定通道保留。
