## 中文

### 在线文件下载

- 一个在线条目存在多个文件时，默认选择最新的活动压缩包；如果只有已归档压缩包或普通文件，则按安全优先级回退。
- 在线详情页提供“选择文件”按钮，可手动查看并选择其他版本或文件。
- 默认文件选择综合文件日期、数字文件 ID、压缩格式和归档状态，不依赖 GameBanana 接口返回顺序。
- 自动生成本地预览图时，读取最多五张详情截图及缩略图回退项的真实像素尺寸，优先选择清晰度较高、比例正常的图片。
- 已加载到在线图片缓存的候选图会直接复用，不重复下载；候选图全部无效时不会影响 Mod 解压和安装。

### 角色目录路由

- 下载前保留当前 Mod 的角色上下文，不再无条件将仓库根目录作为唯一默认位置。
- 使用 GameBanana 分类 ID、中英文角色名、Wiki 目录和角色别名匹配仓库一级目录。
- 可靠匹配会自动预选并标为“推荐”；并列匹配或无法确认时不会自动猜测。
- 手动选择其他位置的入口继续保留，下载解压后仍会在所选角色目录内创建独立 Mod 文件夹。

## English

### Online File Downloads

- Items with multiple files default to the newest active archive, with safe fallback to archived archives or loose files only when necessary.
- The online details pane offers a Select File action for reviewing and choosing another version or file.
- Default selection uses file date, numeric file ID, archive support, and archive state rather than GameBanana response order.
- Local preview generation decodes the real pixel dimensions of up to five detail screenshots plus the thumbnail fallback, preferring a clearer image with a usable aspect ratio.
- Candidates already present in the online image cache are reused without another download, and invalid preview candidates never prevent Mod extraction or installation.

### Character Folder Routing

- Character context is preserved before download instead of always treating the repository root as the only default destination.
- GameBanana category IDs, localized character names, Wiki entries, and aliases are matched against first-level repository folders.
- Confident matches are preselected and labeled Recommended; tied or uncertain matches are not guessed.
- Manual folder selection remains available, and extraction still creates an independent Mod folder inside the selected character directory.

### Package Boundary

- Includes `IntegratedModManager.exe`, compatibility entry `ModFolderCopier.exe`, `LocalUpdateAgent.exe`, the WinUI runtime directory, and `.managed-files.txt`.
- Excludes user configuration, caches, logs, backups, diagnostics, PDB files, and standalone Developer Tools.
- The local update package is not uploaded or published; GitHub actions remain deferred until separate confirmation.
