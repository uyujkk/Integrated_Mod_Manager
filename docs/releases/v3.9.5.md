### 发布后校验附件补充 / Post-release checksum compatibility

发布后发现旧更新器在 Release 包含多个 `.sha256` 文件时，会误选最后一个文件。已为 v3.9.5 补充包含两个 ZIP 校验值的 `SHA256SUMS.txt`，使旧更新器重新获取 Release 信息后可以正确校验主程序。若此前出现“checksum file does not contain a SHA-256 entry”错误，请先点击“检查软件更新”，再重试安装。源码中的附件配对逻辑也已另行修正，供下一次构建使用；原版 v3.9.5 ZIP 未被悄悄替换。

After publication, we found that the older updater selected the last `.sha256` asset when a release had multiple sidecars. A `SHA256SUMS.txt` containing entries for both ZIPs has been added to v3.9.5, so existing clients can verify the main package after refreshing release information. If you saw the checksum-entry error, click **Check for app updates** before retrying installation. Source asset-pairing logic has also been fixed for the next build; the original v3.9.5 ZIP was not silently replaced.

## 中文

### 压缩包导入：Bandizip 备用方案

感谢 CaramelizedCUDA 贡献的 Bandizip 备用解压实现。未找到可用 7-Zip 时，管理器会尝试从程序目录、Bandizip 注册安装位置、常见安装目录与 `PATH` 查找 `bz.exe`。这适用于在线下载和本地导入的 RAR、7Z、ZIPX、CAB 等需要外部解压器的格式；仍优先使用 7-Zip，原有 ZIP/TAR 处理路径保留，发布包不包含 Bandizip 程序。

备用路径会先锁定源文件并制作独立临时快照，再执行 Windows tar 路径和链接检查，以及受限的 RAR5 头部校验。不支持安全检查的分卷、加密头、异常头部或可执行 SFX 等格式会停止并提示使用 7-Zip；7-Zip 校验或解压失败后也不会再回退至 Bandizip。命令参数可处理 Unicode 和空格路径，关闭标准输入以避免交互式密码提示阻塞。tar/bz 每次调用最多等待 10 分钟，超时后尝试终止进程树。**这一超时也适用于原有 TAR 导入**，而 7-Zip 执行不变；特别大的 TAR 文件可能需要注意这一限制。

## English

### Archive imports: Bandizip fallback

Thanks to CaramelizedCUDA for contributing the Bandizip extraction fallback. If no usable 7-Zip is found, the manager discovers `bz.exe` in app folders, registered Bandizip installations, standard locations, and `PATH`. This supports online downloads and local imports of RAR, 7Z, ZIPX, CAB, and related formats that need an external extractor. 7-Zip remains first priority; existing ZIP/TAR paths are preserved. The release does not bundle Bandizip.

The fallback locks the source while making a unique temporary snapshot, then performs Windows tar path/link inspection and bounded RAR5 header validation. Split archives, encrypted headers, unsupported layouts, executable SFX, and other archives that cannot be inspected safely stop with an error requiring the existing 7-Zip path. Failed 7-Zip validation or extraction is never retried through Bandizip. Arguments handle Unicode and spaces, and stdin is closed to prevent an interactive password prompt from blocking. Each tar/bz invocation has a 10-minute limit and attempts process-tree termination on timeout. **This limit also applies to the existing TAR import path**, while 7-Zip execution is unchanged; particularly large TAR archives may be affected.

### Previously unreleased UI changes

- Online cards, lists, and details identify Mods installed in the selected repository using recorded source identity; re-download and manual file selection remain available.
- Tracked Mods scroll inside a bounded panel; Install Safety moves to the second column so the Updates workspace stays readable with many tracked entries.
- Restoring from the system tray attempts to foreground the window without leaving it permanently always-on-top.

Standalone Developer Tools follows the 3.9.5 file version but remains a separate ZIP outside the main app updater payload.
