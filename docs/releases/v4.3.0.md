## What's new / 更新内容

- Integrate Endfield launch into the manager, with a native settings page for path checks, launch logs, EFMI setup and restore, and migration from the old EndfieldBridge. A separate bridge download or window is no longer required.
  内置终末地启动，新增原生设置页，支持路径检测、启动日志、EFMI 适配与恢复，并迁移旧 EndfieldBridge 设置；无需再单独下载桥接器或打开桥接窗口。
- Save the configuration used by XXMI callbacks when applying settings. Preserve original EFMI restore points, prevent another XXMI installation from overwriting them, and check adapted fields before restoring to protect later edits.
  保存设置时同步 XXMI 回调配置；保留原始 EFMI 恢复点，防止另一套 XXMI 覆盖，并在恢复前核对适配字段，保护用户后续修改。
- Check INI resource hashes and shortcuts against enabled Mods before installation. Potential conflicts are shown for review, with the choice to cancel or continue.
  安装前检查与已启用 Mod 共用的 INI 资源哈希和快捷键，提示潜在冲突，由用户选择取消或继续。
- Remove associated loader links when deleting a Mod, and offer cleanup for broken links before deployment. Stale links no longer cause every installation to fail its directory check (#10).
  删除 Mod 时清理关联加载器联接，部署前可清理失效联接，避免残留联接导致所有安装目录检查失败（#10）。
- Import each archive as one Mod folder, handle loose root files and single top-level folders, and prevent silent merging or overwriting of existing folders. Fix direct extraction into character folders, extra nesting in online downloads, and drag-and-drop imports across drives (#11).
  每个压缩包导入为一个 Mod 文件夹，兼容根目录散文件和单顶层文件夹，不静默合并或覆盖已有目录；修复直接解压到角色目录、在线下载多套一层目录及跨盘拖放导入问题（#11）。
- Run one instance per installation directory, report and log unexpected exceptions in asynchronous UI actions, and rotate error logs.
  同一安装目录只运行一个实例；异步界面操作的意外异常会记录并提示，错误日志自动轮转。
- Restore stable application-update checks while honoring saved startup-check and manual-check preferences.
  恢复正式版软件更新检查，遵循已保存的启动检查开关与仅手动检查偏好。

## Upgrade / 升级说明

- Exit the manager and back up your configuration before updating. Extract the complete ZIP into a short, writable folder and run IntegratedModManager.exe. Keep the previous version for rollback; when migrating manually, copy WinUI3/config.ini and WinUI3/beta-shell.json only after both versions have exited.
  更新前退出管理器并备份配置。完整解压 ZIP 到较短的可写目录，运行 IntegratedModManager.exe；保留旧版用于回退。手动迁移时，先退出新旧程序，再复制 WinUI3/config.ini 和 WinUI3/beta-shell.json。
- If the old EndfieldBridge adapted EFMI, use “Back up and set up EFMI” once in the new settings page, then select “Keep” again in XXMI. The original restore point is retained.
  旧 EndfieldBridge 用户如曾适配 EFMI，请在新设置页点一次“备份并适配 EFMI”，随后在 XXMI 中再选择一次“保持”；原始恢复点会保留。
- v4.3.0-preview.1 has application self-update disabled. Preview users should download this stable package manually.
  v4.3.0-preview.1 已关闭软件自身自动更新，预览版用户请手动下载本正式包升级。

## Known issues / 已知问题

- The native crash involving Microsoft.UI.Xaml.dll / 0xc000027b remains unresolved. Exception reporting does not establish that this native crash is fixed.
  Microsoft.UI.Xaml.dll / 0xc000027b 原生闪退根因仍未确认；界面异常保护不代表该原生闪退已根治。
- Older updaters may hit Windows path-length limits when temporary paths are too deep. Use a short, writable folder.
  旧更新器在临时目录过深时可能触发 Windows 路径长度限制，请使用较短的可写目录。
- Live game, XXMI/EFMI and UAC behavior have not been verified. Broken-link cleanup and archive-import dialogs have not been exercised against a real Mod library. Third-party Mods and launchers may lead to account penalties or bans; account safety is not guaranteed.
  真实游戏、XXMI／EFMI 和 UAC 行为尚未验证；失效联接清理及压缩包导入对话框尚未在真实 Mod 库上完整操作验证。第三方 Mod 与加载器可能带来账号处罚或封禁风险，不保证账号安全。
