### 高清预览图自动选择

- 在线安装时检查最多五张详情截图，并将列表缩略图仅作为最终回退项。
- 解码候选图真实宽高，优先选择长边至少 720、短边至少 360、总像素不少于 30 万且比例正常的图片。
- 多张清晰图片可用时，优先选择短边和总像素更高的图片。
- 已缓存候选图直接复用；损坏、超限或无法解码的图片会被跳过。
- Mod 自带预览图不会被覆盖，预览处理失败也不会阻断安装。

## English

### Clear Preview Image Selection

- Online installation examines up to five detail screenshots and uses the list thumbnail only as the final fallback.
- Real candidate dimensions are decoded. Images with at least a 720-pixel long edge, 360-pixel short edge, 300,000 total pixels, and a usable aspect ratio are preferred.
- When several clear images are available, larger short-edge and total-pixel dimensions win.
- Cached candidates are reused, while corrupt, oversized, or undecodable images are skipped.
- Mod-provided preview images are not overwritten, and preview processing failures never block installation.

### Inherited Features

- Downloads the newest usable archive by default while retaining manual file selection.
- Routes online Mods into character folders by category ID, localized names, Wiki metadata, and aliases.
- Ambiguous matches are not guessed; repository-root and system folder-picker fallbacks remain available.

### Package Boundary

- Includes the main app, compatibility launcher, local update agent, WinUI runtime, and managed-file manifest.
- Excludes user configuration, caches, logs, backups, diagnostics, PDB files, and standalone Developer Tools.
