# 4.2.0-preview.1 开发预览整合包

基于本地 4.1.1 源码 `7d0ed62`，整合 `feature/browse-feedback` 已实现的浏览、下载、旧库整理和图片缓存修正。主程序、启动器和更新器文件版本统一为 `4.2.0.0`，显示版本为 `v4.2.0-preview.1`。

## 功能范围

| 模块 | 整合内容 |
| --- | --- |
| 既有能力 | 多仓库、本地 Mod 管理、组合与持久状态预设、组合包、配置方案、备份恢复、在线下载与来源追踪；保留可选终末地桥接入口 |
| 浏览体验 | 下载准备、进度和结果原地刷新；列表及方块视图保留浏览位置；固定已安装标识占位，减少行高变化 |
| 搜索与作者 | 当前页按名称、角色和作者搜索；`author:名字` 作者限定；点击作者按网站作者 ID 跨页浏览，沿用当前仓库分类与角色条件 |
| 收藏 | 收藏作者、稍后下载 Mod；各最多 100 项，分别按游戏分类和仓库保存 |
| 下载管理 | 默认 2 个、可设 1–4 个并发；等待/执行取消；失败或取消后重试沿用原仓库、目录与选定文件；区分同文件、其他变体和旧记录无法确定的重复安装提示 |
| 下载位置 | 可选记住已确认的仓库/角色目录；默认关闭，失效时重新选择 |
| 旧库整理 | 含 INI 的直接子目录预览；复制到选定角色目录；同名冲突拦截；记录内容哈希并仅撤销未修改副本 |
| 图片加载 | 同图缓存与解码协调，修正主图/缩略图并发发布缓存时的访问错误 |

## 使用入口

- 解压到独立新目录，运行根目录 `IntegratedModManager.exe`。`ModFolderCopier.exe` 是兼容启动入口；内部程序位于 `WinUI3/`。
- 在线页：搜索框下方查看匹配数、清空筛选、收藏星形按钮和下载设置齿轮；作者名可点击，卡片可右键。
- 更新页：查看下载队列、取消与重试。
- 仓库页：视图按钮旁的整理导入入口，先预览旧库，再复制到目标角色目录。
- 第一次使用旧库导入、组合恢复和撤销时，建议用独立副本验收；具体限制见随包使用说明。

## 已知问题与功能边界

- 曾发生一次 `Microsoft.UI.Xaml.dll / 0xc000027b` 原生闪退，缺少原始 stowed 回溯，根因尚未确认。图片缓存竞争已单独修正，不能因此宣称闪退已修复。
- 下载队列保存在内存，重启后不恢复，也不提供断点续传。并发限制作用于任务执行阶段，信息读取和目录确认在任务创建之前。
- 普通搜索仅作用于当前页；作者跨页浏览依赖站点作者 ID，不是全站作者名搜索。
- 旧库导入每批选择一个目标角色目录，不自动识别分配角色，不覆盖同名目录。撤销保留修改过或无法确认完整性的副本。
- 导入不提供跨进程文件锁和断电事务保证；发布副本后进程崩溃或记录写入失败可能留下未追踪的副本。
- 第三方启动桥接仍为独立可选下载，需要明确确认与校验；本包不包含桥接器或任何游戏 Mod，不代表游戏内兼容性或账号安全已获验证。
