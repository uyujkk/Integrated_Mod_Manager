## 中文

4.6.1 是 4.6 的修复版：新 Mod 自动获得默认槽位，浮窗保存不再因为加载器没有新写入而失败，并修复一批排版和显示问题。4.6 的全部新功能见 [v4.6.0 发布说明](v4.6.0.md)。

### 新增与改进

- **新 Mod 自动建默认槽位**：仓库扫描到新加入、并且声明了 `global persist` 参数的 Mod 时，会自动为它建一个名为“默认”（英文界面为 “Default”）的状态槽位，内容是 Mod 自己 INI 里的默认值，没写值的按 0。加载器还没写过参数的 Mod 也能直接得到一份可恢复的预设。
  - 升级后的第一次扫描只记录已有的 Mod，不会给它们补建；删除这个槽位后不会再自动建回；已有槽位的 Mod 不会再加。
  - 槽位名称随界面语言变化，重命名后保持不变。
- **浮窗保存更灵活**：保存预设前发送 F10 后，如果 5 秒内参数文件没有变化（通常是参数自上次保存后没有改动，新 Mod 常见），浮窗会询问是读取现有文件保存还是取消，而不是直接报错。缺少参数值时仍然不保存，也不会用默认值顶替。
- **反馈 QQ 群**：设置页“诊断与问题报告”里新增反馈渠道 QQ 群 1041384622，可以一键复制群号，用来反馈问题和日常交流。

### 修复

- 仪表板“常用操作”的文字被截断；三个按钮高度不一致。
- 详情里的部署按钮在 Mod 已部署时仍显示“部署 Mod”，现在显示“从目标文件夹移除”。
- 允许多个 Mod 的角色仍提示“部署会替换某个 Mod”，部署区说明也写成会替换；现在说明不会替换已启用的 Mod。
- Mod 列表只有部分 Mod 显示按键数量；现在每个 Mod 都显示，英文单数写作 “1 shortcut”。
- 设置页：按钮间距不均；说明文字被省略号截断；开源组件名称被截断；窄窗口中的分区标签被截断；在线分类表的标签折行。
- 快捷键页：模块摘要被截断；没选窗口时所有游戏都显示终末地专用的权限说明；发送开关没有读屏名称。
- 更新页：中文的日期标签使用半角冒号；下载历史最后一行被截掉一半；运行中切换语言后“打开组合预设工作区”按钮不跟着变。
- 英文界面仪表板的启动器占位文字过长。

### 升级

- 4.6.0 及更早的正式版可以在软件内更新，也可以下载完整 ZIP；旧配置可以直接使用。
- 首次启动会显示一次 4.6.1 新功能说明。

### 已知问题与验证边界

- 已在中文和英文、深色和浅色主题、1600 DIP 和 860 DIP 宽窗口中用演示数据检查；侧栏“更新”入口的可更新数量徽标需要联网检查出更新才会出现，未检查。
- 浮窗“读取现有文件”的流程已用不处理按键的测试窗口验证，尚未在真实游戏中验证；真实导出的变体文件仍未验证；在线详情页偶发闪退（#15）仍未复现。
- 第三方 Mod 与加载器可能导致账号处罚。发布包按 AGPL-3.0-only 分发，见 [许可证说明](../LICENSING.md)；验证结果见 [验证记录](../verification/v4.6.1.md)。

## English

4.6.1 is a fix release for 4.6: new Mods get a default slot automatically, overlay saves no longer fail when the loader writes nothing new, and a set of layout and display issues are fixed. For everything new in 4.6 see the [v4.6.0 notes](v4.6.0.md).

### New and improved

- **Default slot for new Mods:** when a repository scan finds a newly added Mod that declares `global persist` values, it creates a state slot named "Default" ("默认" in the Chinese UI) holding the defaults from the Mod's own INI files, with 0 where none is written. A Mod the loader has never written still gets a preset to return to.
  - The first scan after upgrading only records the Mods you already have; deleting the slot does not bring it back; a Mod that already has slots gets none.
  - The name follows the UI language until you rename it.
- **More flexible overlay saves:** if the parameter file doesn't change within 5 seconds after F10 (usually nothing changed since the loader last saved, common for a new Mod), the overlay asks whether to save from the existing file or cancel instead of failing. Missing values still stop the save, and defaults are never substituted.
- **Feedback QQ group:** Settings → Diagnostics and Issue Report now lists the feedback QQ group 1041384622, with a button to copy the number, for reporting problems and chat.

### Fixes

- Dashboard quick-action labels were cut off, and the three buttons had different heights.
- The details deploy button said "Deploy Mod" on a deployed Mod; it now says "Remove from target".
- For a character that keeps several Mods enabled, the hint said deploying would replace another Mod, and the link-mode note said so too; the note now says enabled Mods are not replaced.
- Only some Mod rows showed a key count; every row does now, and English says "1 shortcut" for one.
- Settings: uneven button spacing; descriptions cut off with an ellipsis; open-source component names cut off; section tabs cut off in narrow windows; a wrapping label in the online table.
- Shortcuts: module summaries cut off; without a selected window every game showed the Endfield privilege note; the send switch had no screen-reader name.
- Updates: half-width colons after Chinese date labels; the last download-history row cut in half; "Open Combination Workspace" kept the old language after a language switch.
- The English launcher placeholder on the dashboard was too long.

### Upgrade

- 4.6.0 and earlier stable releases can update in the app, or download the full ZIP. Existing configuration works as is.
- On first start a "New in 4.6.1" dialog appears once.

### Known issues and verification limits

- Checked on demo data in Chinese and English, dark and light themes, and 1600 DIP and 860 DIP windows. The Updates navigation badge needs an online check that finds updates and was not checked.
- The overlay's "read existing file" flow was verified with a test window that ignores keys, not yet in a real game. Real exported variant files remain unverified, and the occasional online-details crash (#15) is still unreproduced.
- Third-party Mods and loaders may lead to account penalties. The package is AGPL-3.0-only; see [LICENSING](../LICENSING.md). Results are in the [verification record](../verification/v4.6.1.md).
