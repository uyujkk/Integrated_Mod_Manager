# v4.7.0

基于 v4.6.1 的 Windows x64 正式版，包含 #61–#80，取代本地预览 v4.7.0-preview.1。Windows x64 stable release based on v4.6.1, covering #61–#80; it replaces the local preview v4.7.0-preview.1.

## 中文

### 新增

- **预设图片**：可选开启“在浮窗保存预设时截图”（默认关闭，开启时提示截图可能包含 UID、昵称和聊天）。主窗口的状态槽位和组合预设显示缩略图，可以从游戏截取、选择本地图片或清除；恢复确认框显示保存时的样子。
- **框选角色与图片切换**：浮窗可以变成透明取景框框住角色，图片归当前槽位，可锁定大小、设为默认区域；“图片切换”把浮窗移到屏幕中央，横向列出槽位图片，点图切换。
- **浮窗**：按钮和标签有独立底板，背景很透明时文字加阴影；新增紧凑布局、鼠标穿透（用显示/隐藏快捷键恢复）和清晰、平衡、极简三档外观。
- **浮窗自动对比度**：快捷键页可以开启（默认关闭）。浮窗背景低于 60% 时，每 1.5 秒看一次浮窗下方画面的亮度，自动换用深色或浅色文字；保存的仍是你选的颜色。需要 Windows 10 2004 或更高版本。
- **分享方案**：组合预设页的“分享方案”导出一个小文件，只记录用了哪些 Mod 和它们的参数，不含 Mod 文件。对方用“导入方案”时先看到匹配了多少、缺哪些 Mod、游戏是否一致，只为已有的 Mod 建同名槽位，不覆盖已有槽位。文件按不可信输入逐项检查，超过 4 MB 的方案不会导出。
- **其他游戏**：第一次安装按系统语言选择中文或英文，并询问要管理哪个游戏，不再默认终末地。原神、崩坏：星穹铁道、绝区零的仓库可以通过 XXMI 一键启动；任何仓库都可以在编辑对话框里指定 XXMI 导入器。
- **“默认”槽位**：每个 Mod 都会补上一个保存 Mod 原始默认值的“默认”槽位；恢复它时读取 Mod 当前声明的默认值，会跟随 Mod 更新。
- **保存槽位**：Mod 菜单的开关、页码和位置默认不保存，主窗口会列出这些变量让你选择保留；快捷键页可以调整加载器的自动保存间隔（修改前备份 d3dx.ini）。
- **批量操作**：Mod 列表的“批量”可以把多个 Mod 加入组合预设、复制到文件夹、导出成组合包或删除。
- **Discord**：设置页“诊断与问题报告”新增 Discord 入口。

### 改进与修复

- 切换到源目录为空的仓库会导致软件退出，已修复。
- 管理员权限下文件选择对话框打不开（例如终末地启动设置里的“浏览”），改用系统原生对话框。
- 删除 Mod 前如果无法确认它在加载器目录里的链接，现在不会删除它，并说明原因；批量删除只删除能确认的 Mod。以前会照常删除源文件夹，留下指向已删除文件夹的链接。
- 第一次扫描时读不到默认值的 Mod，之后会重新尝试补建“默认”槽位。
- XXMI 的配置文件内容不是对象（例如数组）时不再中断启动，交给 XXMI 自己报告。
- 没有声明大小的在线图片同样受 25 MB 上限限制。
- 槽位切换在发出 F10 后立即显示状态，不再等待 3 秒的只读保持；保持期间再次切换会提示，耗时写入 `startup.log`。
- 浮窗动画跟随屏幕刷新，内容淡入淡出。
- 热应用提示改为“已发送 F10，请到游戏里确认”；快捷键页说明 Mod 按键需要在 INI 里修改，并提供打开 INI 的按钮。
- 配置文件会保留不认识的字段，在新旧版本之间切换时不丢设置。
- 内部整理（不改变用法）：在线请求和软件更新的下载、校验移到核心库并有单元测试；仓库页、设置页的布局改为 XAML 声明；新增界面自动化测试。

### 升级

- 4.6.1 及更早的正式版可以在软件内更新，也可以下载完整 ZIP；旧配置可以直接使用。
- 4.7.0-preview.1 关闭了软件自身更新，请下载 ZIP 覆盖或解压到新目录。预览版保留了你原来的更新设置，换回正式版后自动恢复。
- 首次启动会显示一次 4.7 新功能说明。

### 已知问题与验证边界

- 以下内容只在演示环境或测试中验证过，尚未在真实游戏里确认：XXMI 启动三个游戏、鼠标穿透在全屏游戏里的表现、恢复“默认”槽位、批量操作、自动保存间隔的修改与卡顿影响、管理员权限下的文件选择、自动对比度、分享方案的导入、保存前 F10 与按键发送。
- 在线角色目录、在线页和检查更新的请求移到核心库后，用模拟网络测试过；联网行为请以实际使用为准，有问题欢迎反馈。
- 一次槽位切换中，管理器本身约占 0.25 秒；其余时间是加载器 F10 重载全部 Mod，启用的大型 Mod 越多越慢。
- 删除 Mod（含批量删除）是永久删除，不进回收站。在线详情页偶发闪退（#15）仍未复现。
- 第三方 Mod 与加载器可能导致账号处罚。发布包按 AGPL-3.0-only 分发，见 [许可证说明](../LICENSING.md)；验证结果见 [验证记录](../verification/v4.7.0.md)。

## English

### New

- **Preset pictures**: optional screenshots when saving presets from the overlay (off by default, with a privacy notice). State slots and combination presets show thumbnails in the main window; set a picture from the game or a file, or clear it; restore dialogs show the saved look.
- **Frame a character, pick by picture**: the overlay becomes a transparent frame around the character, with a size lock and a default area; "Pick by picture" moves it to the middle of the screen and switches slots by picture.
- **Overlay**: buttons and labels keep their own backing and text gets a shadow when the background is very transparent; compact view, click-through (restored with the show/hide hotkey) and Clear, Balanced and Minimal looks.
- **Overlay automatic contrast**: an option on the Shortcuts page (off by default). With a background under 60%, every 1.5 seconds the overlay looks at how bright the screen under it is and switches to dark or light text; the color you chose is still what is saved. Needs Windows 10 2004 or later.
- **Share a preset**: "Share preset" on the combination presets page writes a small file with the Mods it uses and their values, without Mod files. "Import shared preset" first shows how many match, which Mods are missing and whether the game matches, then creates same-named slots for the Mods you have, never overwriting a slot. Every value is checked as untrusted input, and a preset above 4 MB is not exported.
- **Other games**: a first install picks Chinese or English from the system language and asks which game to manage instead of assuming Arknights: Endfield. Genshin Impact, Honkai: Star Rail and Zenless Zone Zero repositories start through XXMI; any repository can choose its XXMI importer.
- **Default slots**: every Mod gets a Default slot with its original defaults, and restoring it reads what the Mod declares now.
- **Saving slots**: a Mod menu's open state, page and position are left out by default, and the main window lists them to keep any; the Shortcuts page can set the loader's auto-save interval, with a backup of d3dx.ini.
- **Batch actions**: add several Mods to a combination preset, copy them to a folder, export them as a combination bundle or delete them.
- **Discord** link in Settings → Diagnostics.

### Fixes and improvements

- Switching to a repository with no source folder no longer ends the app.
- File dialogs work when the manager runs elevated, for example Browse in the Endfield launch settings.
- When the links to a Mod in the loader folder cannot be checked, the Mod is no longer deleted and the dialog says why; batch delete only deletes the Mods it could check. Before, the source folder was deleted anyway, leaving a link to a missing folder.
- A Mod whose defaults could not be read on the first scan gets its Default slot on a later scan.
- An XXMI configuration that is not an object (an array, say) no longer stops the launch; XXMI reports it itself.
- Online images without a declared size are held to the 25 MB limit too.
- Slot switching reports as soon as F10 is sent, says when a switch is still applying, and logs its timing in `startup.log`.
- Smoother overlay animations; clearer hot-apply and key-binding hints; the configuration keeps fields it does not know.
- Internal work that does not change how the app is used: online requests and the update download and checks moved into the core library with unit tests; the repository and settings page layouts are declared in XAML; UI automation tests were added.

### Upgrade

- 4.6.1 and earlier stable releases can update in the app, or download the full ZIP. Existing configuration works as is.
- 4.7.0-preview.1 has app self-update off: download the ZIP and extract over it or into a new folder. The preview kept your update settings, so they come back with this release.
- On first start a "New in 4.7" dialog appears once.

### Known issues and verification limits

- Checked only on demo data or in tests, not yet in a real game: XXMI launches for the three games, click-through in full screen, restoring Default slots, batch actions, the auto-save interval and its effect on performance, elevated file dialogs, auto contrast, importing a shared preset, and F10 and key sending before saves.
- The online character catalogs, the online page and the update check moved into the core library and were tested against simulated network responses; please report anything that behaves differently online.
- The manager takes about 0.25 s of a slot switch; the rest is the loader reloading every Mod on F10.
- Deleting Mods, including batch delete, is permanent. The occasional online-details crash (#15) is still unreproduced.
- Third-party Mods and loaders may lead to account penalties. The package is AGPL-3.0-only; see [LICENSING](../LICENSING.md). Results are in the [verification record](../verification/v4.7.0.md).
