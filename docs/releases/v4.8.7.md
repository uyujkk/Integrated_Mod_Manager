# v4.8.7

基于 v4.8.6 的 Windows x64 正式版。Windows x64 stable release based on v4.8.6.

## 更新内容

4.8.6 的功能搜索按反馈继续调整（[#160](https://github.com/uyujkk/Integrated_Mod_Manager/pull/160)）：保留像 Windows 8 开始屏幕那样铺满窗口的磁贴布局，磁贴本身改成 Windows 11 的样子，磁贴也能直接拿来用。

- **Windows 11 风格的磁贴**：
  - 半透明的卡片、细边框和圆角，左上角是按页面着色的小图标方块；指向时变亮，按下时微微下沉。
  - 背景是一层较薄的亚克力，铺满整个窗口，后面的页面模糊地透出来。
  - 高对比度主题下使用系统颜色。
- **从左下角弹出**：
  - 按 Ctrl+K 后，背景从窗口左下角以圆形展开，磁贴从左到右一列一列地滑入、淡入，全程约 0.4 秒。
  - 动画由系统的合成线程执行，不在每一帧重新排版；磁贴在启动后空闲时就提前建好，第一次打开也不用等。
  - 打开“减少动效”时直接显示。
- **磁贴可以直接用**：
  - 一个功能第一次被选中时，仍然带你到它的位置并框出来；之后再选就直接使用：按下对应的按钮、展开分组或下拉列表、切换视图（例如组合预设、封面）。
  - 会改动数据或开关的功能（启用 Mod、删除、可同时启用多个、保存槽位、恢复到加载器、应用预设、撤销、以管理员身份重启、清除登录、导出诊断等）只把键盘焦点移过去，由你自己点。
  - 选过的功能会记住，重启后也一样。
- **Tab 切换分组**：在磁贴上按 Tab 跳到下一组的第一块，Shift+Tab 回到上一组；在搜索框里按 Tab 或 ↓ 进入第一块磁贴。
- **指引框修复**（样式不变）：
  - 目标在折叠的分组里时，会等分组展开完、页面不再移动后再画框，不会再框在错误的位置。
  - 页面滚动、分组展开或窗口改变大小时，框会跟着目标移动；目标消失时（例如切到别的页面）框也消失。
  - 框淡入显示。
- **其他**：提示文字有中文、英文和俄文。主程序、启动器、更新器和开发者工具使用 4.8.7。“新功能”对话框更新为 4.8.7 的内容，升级后显示一次。快速上手和用户手册已更新。

## What's new

Following feedback on 4.8.6's feature search ([#160](https://github.com/uyujkk/Integrated_Mod_Manager/pull/160)): it keeps the full-window layout of tiles like the Windows 8 start screen, the tiles themselves look like Windows 11, and the tiles can now be used directly.

- **Windows 11 tiles**:
  - Translucent cards with a hairline border and rounded corners, and the feature's icon on a small square tinted in its page's colour; they light up when pointed at and sink a little when pressed.
  - The backdrop is a thin acrylic over the whole window, so the page shows through blurred.
  - High contrast uses the system colours.
- **Opening from the bottom-left**:
  - After Ctrl+K the backdrop spreads from the window's bottom-left corner as a growing circle, and the tiles slide and fade in column by column from the left, in about 0.4 seconds.
  - The animation runs on the system's composition thread, with no layout work per frame; the tiles are built ahead of time while the window is idle after start-up, so the first opening does not wait either.
  - With reduced motion it simply appears.
- **Tiles you can use**:
  - The first time a feature is picked it still takes you to its place and outlines it; after that, picking it uses it: it presses the button, opens the group or the drop-down, or switches the view (for example Presets or Covers).
  - Features that change data or flip a switch (turning a Mod on, deleting, Several at once, saving a slot, restoring to the loader, applying a preset, undoing, restarting as administrator, clearing the sign-in, exporting diagnostics and the like) only get the keyboard focus, so you press them yourself.
  - Features picked once are remembered, also after a restart.
- **Tab between groups**: on a tile, Tab moves to the first tile of the next group and Shift+Tab back; Tab or Down in the search box enters the first tile.
- **Guide ring fixes** (same look):
  - When the place is inside a folded group, the ring waits until the group has opened and the page has stopped moving, so it no longer lands in the wrong spot.
  - The ring follows the place while the page scrolls, a group opens or the window is resized, and goes away when the place does (for example on another page).
  - The ring fades in.
- **Other**: The new texts are in Chinese, English and Russian. The app, launcher, updater and Developer Tools use version 4.8.7. The What's New dialog describes 4.8.7 and shows once after upgrading. The Quick Start and User Guide are updated.

## Known issues

- The new tiles were not checked with screenshots in the light theme, a high-contrast theme (that needs a system setting changed) or Russian; the Russian texts have not been reviewed by a native speaker.
- "Using" a feature directly was not checked one by one in real use for all 82 features; features that need a selected character or Mod first still only say where they are at the bottom.
- The known issues listed for 4.8.6 still apply: a short window fits only two or three rows of tiles and cuts off long feature names; the junction fix has not been checked in a real game with the EFMI loader; and the checks listed for 4.8.4 and 4.8.3. See the [v4.8.6 notes](v4.8.6.md#known-issues).
- See the [v4.8.0 notes](v4.8.0.md#not-yet-confirmed-in-a-real-game) for the scope of other game and loader verification.
