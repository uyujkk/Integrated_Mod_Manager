# v4.8.2

基于 v4.8.1 的 Windows x64 正式版。Windows x64 stable release based on v4.8.1.

## 更新内容

- **游戏内浮窗重新设计（[#134](https://github.com/uyujkk/Integrated_Mod_Manager/pull/134)）**：
  - 浮窗有自己的标题栏，可以拖动。标题栏上有状态圆点、当前 Mod 名称、状态图标、⋯ 菜单和 ✕。圆点为绿色表示正在向所选窗口发送，琥珀色表示选了窗口但发送已关闭，灰色表示还没选窗口。✕ 隐藏浮窗，提示里写明快捷键。
  - 浮窗和快捷键页显示同一个 Mod。这个 Mod 没在游戏里启用时，会标“未启用”，按键不能发送，浮窗会说明启用方法。
  - 目标窗口和“发送”开关可以直接在浮窗里选。按键以键帽显示，点击即发送。“保存预设”下拉按钮里是“保存组合预设”和“保存单 Mod 预设”。
  - 高度跟随内容。可以拖动边缘调整大小。按显示器记住大小和位置，那台显示器不在时回到默认位置。靠近屏幕边缘时贴边。
  - 紧凑模式、紧凑模式字号（12–20）、鼠标穿透、背景不透明度和“重新读取 INI”收进 ⋯ 菜单。
  - 浮窗跟随应用的浅色或深色主题，使用和主窗口一样的控件。背景不透明度、按钮底板和自动对比度照旧生效。
  - 读取结果收进标题栏的状态图标，指向或聚焦时显示全文。需要处理的失败仍完整显示在“保存预设”上方。
  - 按键的发送方式和时序、F10 的发送和等待、全局快捷键、鼠标穿透的机制、自动对比度的计算、槽位切换和预设保存的结果都没有改变。
- **在线页点赞（[#129](https://github.com/uyujkk/Integrated_Mod_Manager/issues/129)、[#132](https://github.com/uyujkk/Integrated_Mod_Manager/pull/132)）**：
  - Mod 详情里的爱心按钮会在管理器里打开这个 Mod 的 GameBanana 页面，登录后可以点赞或取消点赞。
  - 登录在 GameBanana 自己的页面上完成，管理器不读取也不代填。这个页面只能打开该 Mod 的页面和 GameBanana 本站。
  - 登录信息只保存在这台电脑上，和浏览器分开。可以在“设置 → 仓库在线分类 → 清除 GameBanana 登录”删除。
- **设置和反馈（[#135](https://github.com/uyujkk/Integrated_Mod_Manager/pull/135)）**：
  - 宽窗口里展开或收起卡片时，分组不再跳到另一栏。
  - “新功能”对话框和设置里的更新说明新增“加入 Discord 服务器”按钮。
- **切页更快（#135）**：
  - 页面第一次显示后留在窗口里，再次切换只改变可见的页面。之前每次切换都会把整页重新载入和排版。
  - 在本机用真实在线数据测得：再次打开在线页时，第一帧从 141–188 毫秒缩短到 53–73 毫秒；再次打开仪表盘和设置页时约 3–4 毫秒。
  - 查找在线 Mod 是否已安装时，先比对 Mod，再读磁盘。
- **其他**：主程序、启动器和更新器使用 4.8.2。“新功能”对话框更新为 4.8.2 的内容，升级后显示一次。发布说明会自动同步到 Discord（[#131](https://github.com/uyujkk/Integrated_Mod_Manager/pull/131)，仅影响发布流程）。

## 已知问题

- 新浮窗只在测试窗口和合成数据上验证过，下面这些尚未在真实游戏中核对：
  - 在无边框全屏的游戏上拖动和调整大小，浮窗保持置顶。
  - 游戏在前台时拖到屏幕边缘贴边。
  - 两台显示器分别记住位置；拔掉一台后回到默认位置。
  - 游戏中开启鼠标穿透，再用快捷键恢复。
  - 在浮窗里选择真实游戏窗口，发送开关和状态圆点随之变化。
  - 点击键帽，按键送达游戏。
  - 从浮窗用 F10 切换状态槽位。
  - 从“保存预设”下拉按钮保存两种预设。
  - 浅色主题下，在明亮和昏暗画面上的自动对比度。
  - 浮窗打开时切换应用主题。
  - 紧凑模式下的各个字号。
- 点赞只用离线样例页面验证过。以下都没有用真实账号验证：真实登录（包括两步验证和人机验证）、点赞和取消点赞、重启后保持登录、清除登录。
- 切页耗时是在一台 120 Hz 显示器上用真实在线数据测的。首次打开设置、更新和快捷键页时仍要创建页面，约 40–120 毫秒。
- 真实游戏与加载器的其他验证范围见 [v4.8.0 发布说明](v4.8.0.md#尚未在真实游戏中核对的功能)。

## What's new

- **A redesigned in-game overlay ([#134](https://github.com/uyujkk/Integrated_Mod_Manager/pull/134))**:
  - The overlay has its own title bar, which you drag to move it. The title bar shows a status dot, the current Mod's name, a status icon, the ⋯ menu and ✕. The dot is green while keys are sent to the chosen window, amber when a window is chosen but sending is off, and grey when no window is chosen. ✕ hides the overlay, and its tooltip names the hotkey.
  - The overlay shows the same Mod as the Shortcuts page. If that Mod is not enabled in the game, it is marked "not enabled", its keys cannot be sent, and the overlay says how to enable it.
  - You can choose the target window and turn sending on or off in the overlay itself. Keys are shown as key caps and send with a click. **Save preset** is a drop-down with **Save combination preset** and **Save single-Mod preset**.
  - The height follows the content. Drag the edges to resize the overlay. Its size and place are remembered for each display, with a default place when that display is gone. It snaps to screen edges.
  - Compact view, the compact text size (12–20), click-through, background opacity and **Reload INI** are in the ⋯ menu.
  - The overlay follows the app's light or dark theme and uses the main window's controls. Background opacity, element backing and automatic contrast still apply.
  - Read results sit behind the status icon in the title bar; point at it or focus it to read them. Failures that need you still show in full above **Save preset**.
  - Key sending and its timing, F10 sending and waiting, the global hotkey, how click-through works, the automatic contrast calculation, slot switching and preset saving are unchanged.
- **Likes on the Online page ([#129](https://github.com/uyujkk/Integrated_Mod_Manager/issues/129), [#132](https://github.com/uyujkk/Integrated_Mod_Manager/pull/132))**:
  - The heart button in a Mod's details opens its GameBanana page inside the manager, where you can sign in to like or unlike it.
  - You sign in on GameBanana's own page; the manager does not read or fill it in. Only that Mod's page and GameBanana itself can open there.
  - The sign-in is saved only on this computer, separate from your browser. Remove it with Settings → Repository online category → **Clear GameBanana sign-in**.
- **Settings and feedback ([#135](https://github.com/uyujkk/Integrated_Mod_Manager/pull/135))**:
  - On wide windows, opening or closing a card no longer moves its group to the other column.
  - What's New and the release notes in Settings have a **Join the Discord server** button.
- **Faster page switching (#135)**:
  - A page stays in the window after it is first shown, and a switch only changes which page is visible. Before, every switch reloaded and laid out the whole page.
  - Measured with live Online data: going back to the Online page now draws its first frame in 53–73 ms instead of 141–188 ms, and the Dashboard and Settings in about 3–4 ms.
  - The installed-Mod lookup compares the Mod before reading the disk.
- **Other**: The app, launcher and updater use version 4.8.2. The What's New dialog describes 4.8.2 and shows once after upgrading. Release notes are now posted to Discord automatically ([#131](https://github.com/uyujkk/Integrated_Mod_Manager/pull/131); this affects only the release workflow).

## Known issues

- The new overlay was verified only with a test window and synthetic data. These are not yet checked in a real game:
  - Dragging and resizing over a borderless full-screen game, with the overlay staying on top.
  - Snapping to screen edges while the game is in front.
  - Remembering the place on each of two displays, and returning to the default place after one is unplugged.
  - Click-through in game, and restoring the mouse with the hotkey.
  - Choosing the real game window in the overlay, with the send switch and status dot following.
  - Clicking a key cap, and the key reaching the game.
  - Switching state slots with F10 from the overlay.
  - Saving both kinds of preset from the Save preset drop-down.
  - Automatic contrast over bright and dark scenes in the light theme.
  - Changing the app theme while the overlay is open.
  - Each text size in compact view.
- Likes were verified only with offline sample pages. None of these were verified with a real account: a real sign-in (including two-factor codes and the human check), liking and unliking, staying signed in after a restart, and clearing the sign-in.
- The switching times were measured on one 120 Hz display with live Online data. The first visit to Settings, Updates or Shortcuts still creates the page, which takes about 40–120 ms.
- See the [v4.8.0 notes](v4.8.0.md#not-yet-confirmed-in-a-real-game) for the scope of other game and loader verification.
