# 浏览、下载与旧 Mod 整理任务包

本功能已纳入 **4.2.0-preview.2 开发预览整合包**，基于 4.1.1 并保留原有功能。请独立解压使用；没有替换现有版本或发布在线更新。

## 已合并实现

| 任务包 | 内容 | 使用入口 |
| --- | --- | --- |
| 浏览与收藏 | 当前页匹配数量、清空筛选、作者跨页浏览、收藏作者、稍后下载 | 在线页搜索框下方；点击作者名；右键卡片；星形按钮 |
| 下载与去重 | 相同文件／其他变体／旧记录无法确定三类提示；任务中心重试；1–4 个任务并发；可选记住目录 | 卡片下载按钮；更新页的下载任务；在线页齿轮按钮 |
| 旧 Mod 整理 | 选择旧库和目标角色目录、预览、复制导入、同名冲突拦截、撤销未修改副本 | 仓库页视图切换按钮旁的整理导入按钮 |

作者跨页浏览依赖网站作者 ID，范围沿用当前仓库分类和角色条件。普通搜索与 `author:名字` 搜索作用于当前页。旧缓存尝试补全作者 ID；获取失败时提示并退回当前页筛选。

右键卡片可收藏作者或加入稍后下载。收藏作者按游戏分类保存，稍后下载按仓库保存，各保留最多 100 项。

并发数量默认为 2，控制下载与安装执行阶段；任务创建前的读取信息和位置确认不在队列内。失败任务点击“重试”会使用原仓库、原确认目录和原所选文件；目录失效或文件从网站列表消失时会提示。任务和历史持久化；重启后未完成任务标为中断，确认原位置后可重新下载。不会自动恢复执行，不支持断点续传，原残留文件保留。

目录记忆默认关闭；开启后按仓库和角色记录确认过的位置，仅自动复用仍位于原仓库内的目录。需要每次确认时可关闭该选项。

整理导入把旧库的直接子文件夹作为候选 Mod，仅识别含 INI 的文件夹。每批选择一个目标角色目录，保留 Mod 内部结构。原目录保留，目标同名时停止执行。撤销前检查内容哈希与目录结构；修改过、增加文件或无法访问的副本会保留并报告。前置意图和所有权标记用于核对异常退出后的完整副本；可从整理导入菜单检查最近中断记录。暂存目录不会自动删除，不自动猜测角色，也不保证任意断电或其他程序同时修改文件时的事务完整性。

## 验证与限制

- preview.1 的 Core 回归为 806 项；preview.2 新增中断恢复、故障注入和操作上下文测试，最终数量见随包验证状态。
- WinUI Release/x64 构建通过。
- 已在独立窗口检查作者分页、收藏与稍后下载持久化、下载选项和任务中心重试。
- 已手选下载一个 2,865 字节的公开 ZIP，验证自动解压、安装记录和已安装标识；没有启动游戏或运行下载内容。
- 复制导入和撤销的自动化用例覆盖冲突、源文件变化、取消、内容改变及路径边界。
- 已在最终窗口粘贴旧库路径并执行两个模拟 Mod 的预览和复制；列表出现两项新 Mod，四个源文件全部保留，导入记录正确保存。
- 实测中曾有一次详情页在 `Microsoft.UI.Xaml.dll` 中异常退出；重启后同页下载及宽窗口布局可用，原因尚未确认。这个开发版不能据此认定为稳定发行版。

同图缓存竞争已单独修正，两份独立冷缓存窗口验收未再记录该缓存错误。原生闪退尚未取得原始回溯，仍保持未解决。

本包验证状态见随包“验证状态.md”。更详细的原始证据保留在开发工作区的 `docs/development/Browse-Download-Task-Pack.md` 与 `Online-Native-Crash-Investigation.md`。

## preview.3 的四项扩展

- 在线页星形按钮打开“作者与稍后下载”：作者可按收藏／最近访问及名称查找；稍后下载可勾选多个条目，集中确认文件、目录与重复安装后加入原有队列。
- 在线浏览进度按仓库保存。重启恢复作者、角色、页码、搜索、排序、布局与位置；恢复不会自动下载。改变筛选或页码从顶部开始。
- 在线页“本页全部”按钮可切换本页已安装／稍后下载；作者作品仍可跨页浏览，文字和安装状态筛选仍限当前页。
- 本地仓库搜索框旁的“标签”可批量添加、移除或替换标签，右键 Mod 可单独编辑；“筛选”可按标签过滤并保存角色、搜索和标签条件。每个 Mod 最多 16 个标签，标签不改写 Mod 文件。

完整范围见 [preview.3 说明](../releases/v4.2.0-preview.3.md)。
