# 开始使用 / Getting started

## 启动

1. 将 ZIP 完整解压到一个较短的可写目录，保留整个目录结构。
2. 运行根目录 **IntegratedModManager.exe**。ModFolderCopier.exe 是相同功能的兼容启动入口。
3. 首次使用在仪表板新建或编辑仓库，确认源 Mod 目录和加载器目标目录后再操作；“仓库”页的“开始使用”卡片会列出还没完成的步骤。

运行环境：Windows 10 1809 及以上的 x64 系统，需要 .NET 8 x64 运行时。包内包含 Windows App SDK 和 7-Zip 解压组件，普通使用不需要 SDK 或 Visual Studio。

## 常用入口

| 想做什么 | 在哪里操作 |
| --- | --- |
| 搜索页面、角色和 Mod | 按 Ctrl + K 打开命令面板 |
| 发送 Mod 快捷键 | 左侧“快捷键” → 选择 Mod 和游戏窗口 → 开启发送 → 点击按键 |
| 在游戏画面上使用 | 按 Ctrl + Alt + K 打开置顶浮窗 |
| 终末地按键没反应 | “快捷键”页点击“以管理员身份重启管理器” |
| 在游戏中保存预设 | 浮窗的“保存预设”或“保存单 Mod 预设”；保存前会发送 F10 并等待加载器写入 |
| 单个 Mod 的多套参数 | 选中 Mod → 右侧“状态槽位” |
| 查看下载进度 | 左侧导航底部的“下载” |

## 升级与说明

- 可以在软件内更新，或把新版本解压到新目录。手动迁移时，先退出新旧程序，再复制 `WinUI3/config.ini` 和 `WinUI3/beta-shell.json`。
- 不要让两个管理器同时写入同一个目标目录。本包不包含任何游戏文件或 Mod；第三方 Mod 与加载器可能带来账号风险。
- 当前版本的新功能和已知问题见 `docs/releases` 里对应版本的发布说明；使用说明见 [快速上手](zh-CN/快速上手.md)、[用户手册](zh-CN/用户手册.md) 和 [快捷键面板与置顶浮窗](zh-CN/快捷键与浮窗.md)；English: [Quick Start](en/Quick-Start.md)。
