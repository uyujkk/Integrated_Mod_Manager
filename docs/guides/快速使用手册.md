# 集成化 Mod 管理器 v3.8.5 快速使用手册

[English Quick Start](./Quick-Start.en.md) | [完整中文手册](./用户手册.zh-CN.md) | [文档索引](../README.md)

## 安装与首次设置

1. 完整解压发布包，不要在 ZIP 内运行。
2. 双击 `ModFolderCopier.exe`，保留 `WinUI3` 和 `LocalUpdateAgent.exe`。
3. 在仪表板创建或选择仓库。
4. 设置“Mod 仓库”为两层 Mod 目录根路径，“目标文件夹”为游戏或 XXMI 读取的 Mods 目录。
5. 可选选择外部启动器，然后刷新目录。

推荐结构：

```text
Mod 仓库\角色或分类\具体 Mod\文件...
```

第一层是分类，第二层是实际复制的完整 Mod 文件夹。

## 主要功能

- **仓库总览**：为不同游戏建立独立仓库，查看数量和路径状态，双击卡片切换仓库。
- **本地切换**：选择第一层和第二层后，双击 Mod 或点击复制按钮。目标中没有同名目录时复制，已有时再次操作会移除。
- **目录管理**：搜索、新建、重命名第一层分类；删除第二层 Mod 前会确认。
- **压缩包导入**：支持 ZIP、ZIPX、7Z、RAR、CAB、TAR、GZ、BZ2、XZ、ZST 及常见 `tar.*` 格式，可点击导入或拖入第二层区域。
- **预览与链接**：自动查找预览图，也可拖入图片；每个 Mod 可保存独立来源链接并用默认浏览器打开。
- **快捷键说明**：每个 Mod 最多 10 行，点击输入框后直接按单键、组合键、功能键或符号键；这里只记录说明，不注册全局热键。
- **在线 Mod**：按角色头像浏览、收藏角色置顶、搜索、排序、切换列表/方块模式、查看详情与图片，并下载解压。
- **访问要求提示**：尽力识别 Patreon、订阅、付费、点赞解锁、限时免费和依赖组件；最终以作者原页面为准。
- **配置方案**：保存并应用整套启用 Mod 组合。
- **冲突与回滚**：安装前检查冲突；复制、移除和方案切换建立备份，失败自动恢复，也可手动恢复历史备份。
- **下载任务中心**：查看进度、取消任务、打开目录和清理完成记录。
- **Mod 更新**：追踪在线安装记录、去重、检查更新、打开页面或删除追踪；删除追踪不删除本地文件。
- **软件更新**：可开启启动检查；确认后自动下载、显示进度、安装并重启，失败时回滚。也可把新版发布 ZIP 放入程序目录后重启识别。
- **设置与辅助功能**：中文/English、浅色/深色、高对比度、界面密度、减少动效、Tab 导航和缩放适配。
- **诊断报告**：导出脱敏报告，或打开预填 GitHub Issue；提交前由用户检查，程序不会自动上传。

## 常用操作

| 操作 | 方法 |
| --- | --- |
| 切换 Mod | 选中第二层 Mod 后双击，或点复制按钮 |
| 导入压缩包 | 选中第一层后点导入，或拖到第二层区域 |
| 设置预览图 | 选中 Mod 后把图片拖入预览区 |
| 打开在线详情 | 在线列表中点“查看详情” |
| 收藏角色 | 点击角色项右侧星形按钮 |
| 高清看图 | 点击在线详情主图，左右键换图，Esc 关闭 |
| 刷新当前页 | `F5` |
| 页面切换 | `Alt+1` 至 `Alt+5` |
| 聚焦搜索 | `Ctrl+F` |
| 检查软件更新 | `Ctrl+U` |

## 注意事项

- 当前程序未使用商业代码签名，SmartScreen 可能显示未知发布者。请只从官方 GitHub Releases 下载，不要关闭 Defender。
- 在线功能不会绕过登录、验证码、付费、订阅、权限或作者限制。
- RAR/7Z/ZIPX/CAB 依赖 `WinUI3/Tools` 中的 7-Zip 文件，请勿删除。
- 配置、SQLite 数据、缓存和备份保存在 `WinUI3` 目录；软件更新会尽量保留这些数据。
- 分享配置、截图或诊断报告前，请检查是否含个人路径或账号信息。
