## 1. 软件用途

集成化 Mod 管理器把分散保存的 Mod 整理成多个独立仓库，再把选中的完整 Mod 文件夹复制或链接到游戏、加载器实际读取的目标文件夹。它还提供角色头像、压缩包导入、预览图与来源链接、快捷键面板和置顶浮窗、单 Mod 状态槽位、组合预设、在线浏览下载、更新追踪、冲突检查、安装回滚、内置终末地启动、软件更新和诊断报告。

界面左侧依次是：

| 模块 | 用途 |
| --- | --- |
| 仪表板 | 查看仓库、Mod 数量和路径状态；创建或切换仓库；设置终末地启动方式 |
| 仓库 | 文件列表、封面视图和组合预设；管理部署、预览、快捷键说明和状态槽位 |
| 在线 | 按角色浏览 GameBanana Mod，查看详情、图片、要求和安装状态并下载 |
| 更新 | 已追踪 Mod、下载任务、安装安全与备份 |
| 快捷键 | 点击发送 Mod 的按键，打开置顶浮窗，跟随出场角色 |
| 设置 | 语言、主题、动效、在线分类、软件更新、备份和诊断 |

## 2. 安装、启动与升级

### 2.1 系统要求

- Windows 10 1809 或更高版本，推荐 Windows 11；64 位（x64）。
- 需要 .NET 8 x64 运行时。发布包已包含 Windows App SDK，普通用户不需要 Visual Studio 或 .NET SDK。
- 在线浏览、翻译、更新检查和 GitHub 报告需要网络连接。

### 2.2 安装与启动

1. 从 [GitHub Releases](https://github.com/uyujkk/Integrated_Mod_Manager/releases/latest) 下载 `Integrated_Mod_Manager-vX.X.X.zip` 和对应的 `.sha256`。
2. 完整解压到一个较短的可写文件夹，不要在压缩包内运行。
3. 保留 `IntegratedModManager.exe`、`LocalUpdateAgent.exe`、兼容入口 `ModFolderCopier.exe` 和 `WinUI3` 目录的相对位置。
4. 双击 `IntegratedModManager.exe`。

程序没有商业代码签名，SmartScreen 可能显示“发布者未知”。请只从本项目 Releases 下载，不要为此关闭 Microsoft Defender。

### 2.3 从旧版升级

- 4.x 正式版可以在软件内更新（见第 10 节），也可以把新版解压到新目录。手动迁移时先退出新旧两个程序，再复制 `WinUI3/config.ini` 和 `WinUI3/beta-shell.json`。
- 升级前建议备份应用目录、目标 Mod 目录和加载器实际使用的 `d3dx_user.ini`。
- 不要让两个管理器同时写入同一个目标目录。
- 4.0、4.1、4.1.1 的旧版升级说明保留在[归档](../archive/)中。

## 3. 仓库与目录结构

每个仓库保存一套独立设置：名称、Mod 存储文件夹、目标文件夹、可选启动器、在线来源与分类 ID、Wiki 地址和备注。不同游戏、加载器或测试环境请分别建仓库。

```text
Mod 存储文件夹
├─ 角色或分类 A                 <- 第一层
│  ├─ Mod A1                   <- 第二层，实际部署单位
│  └─ Mod A2
└─ 角色或分类 B
   └─ Mod B1
```

- 第一层是分类，通常是角色；第二层是完整的 Mod 文件夹。
- 目标文件夹通常是 XXMI 或游戏读取的 `Mods` 目录。
- 在仪表板双击卡片切换仓库；编辑按钮用于修改路径和在线分类。

## 4. 本地 Mod 管理

### 4.1 首次配置

1. 在仪表板新建仓库，或编辑默认仓库。
2. 设置“Mod 仓库”为两层目录的根目录，“目标文件夹”为游戏或加载器读取的目录。
3. 可选择是否用目录联接部署（见 4.4）和外部启动器 EXE。
4. 点击“刷新目录”，再依次选择角色和 Mod。

### 4.2 角色列表与头像

- 搜索框按名称过滤角色；“+”新建、编辑按钮重命名；每项显示 Mod 数量。
- 每个角色显示头像，依次使用：
  1. 角色文件夹里的 `.imm_avatar.*` 或 `avatar.*` 图片；
  2. 手动绑定的角色；
  3. 与文件夹同名的目录角色（中文名、英文名或别名均可，忽略大小写、全半角和空格）。
- 角色目录与“在线”页共用：终末地用官方干员列表（内置干员表补缺），其他游戏用 Wiki 加 GameBanana 角色分类。目录超过一天未更新时会在后台刷新，新角色一天内出现。
- 选中角色后，点击列表上方的**头像按钮**（或右键角色 → “头像”）可以：选择图片（复制到角色文件夹，原图保留为 `.imm_avatar.previous.*`）、绑定到角色、恢复上一张头像或移除自定义头像。

### 4.3 部署与移除

- 仓库顶部可切换文件列表、封面视图和组合预设；切换视图不会部署 Mod。
- 单击只选择 Mod，刷新预览、链接、快捷键和部署状态；宽窗口内嵌详情，窄窗口点击“详情”。
- 双击 Mod 或使用详情底部的部署按钮切换：目标中没有同名目录时部署，已存在时再次操作会移除。
- 垃圾桶按钮删除的是仓库中的源 Mod，执行前会确认。
- 部署、移除和方案切换前会建立事务备份，失败时自动回滚。

### 4.4 目录联接与每个角色多个 Mod

- 开启“使用目录联接部署 Mod”后，加载器和仓库共用同一份 Mod 文件，不再复制。
- 默认每个角色只启用一个 Mod：启用新的 Mod 会替换同角色其他 Mod 的联接。
- 选中角色后点击头像按钮右边的**多选开关**（或右键 → “允许同时启用多个 Mod”），这个角色就可以同时启用多个 Mod。开关亮起表示允许。
- 编辑仓库时可以把默认值改为允许多个，再对个别角色关闭。
- 复制模式不会自动移除同角色的其他副本。恢复组合预设时，如果某个只允许单选的角色下有多个 Mod，会先询问。

### 4.5 压缩包导入

支持 `.zip .zipx .7z .rar .cab .tar .tar.gz .tar.bz2 .tar.xz .tar.zst .gz .tgz .bz2 .xz .zst`。选中角色后点击“导入到当前选中文件夹”，或把压缩包拖到 Mod 区域（以管理员身份运行时 Windows 不允许拖放，请用选择文件）。

- ZIP 使用内置解压；7Z、RAR、ZIPX、CAB 优先使用发布包内或已安装的 7-Zip；TAR 系列使用 Windows `tar.exe`。
- 找不到 7-Zip 时，可以使用已安装 Bandizip 的控制台工具 `bz.exe`（在程序 `Tools` 文件夹、程序目录、注册的安装位置、常见安装目录和 `PATH` 中查找）。解压前会先用 Windows `tar.exe` 检查所有条目的路径、链接和特殊文件，检查不通过或不支持时停止；RAR5 另做文件头检查，拒绝重定向、分卷、加密文件头和自解压包。7-Zip 解压失败时不会改用 Bandizip。
- 每次 `tar.exe` 或 `bz.exe` 调用最多 10 分钟，超时会停止并报错。
- 加密、损坏或缺少分卷的压缩包可能无法处理。

### 4.6 预览图与来源链接

程序优先查找 `preview.*`、`cover.*`、`thumbnail.*`、`image.*`，再显示 Mod 文件夹中的第一张图片（PNG、JPG、BMP、GIF、WebP）。选中 Mod 后可把图片拖到预览区设为预览图。每个 Mod 可保存独立的来源链接，用默认浏览器打开。Mod 更新后保留原预览图。

### 4.7 快捷键说明

- 详情里的“快捷键”页从 Mod INI 的 `[Key…]` 段只读识别按键，并按界面语言整理功能说明；也可以手动编辑，不限行数。自动扫描最多 512 条。
- 这里只是说明。要点击发送按键，请使用左侧的“快捷键”模块，见[快捷键与浮窗](./快捷键与浮窗.md)。

### 4.8 外部启动器

选择启动器 EXE 后，点击“运行启动器”启动，工作目录为启动器所在目录，适合 XXMI Launcher 等工具。终末地仓库还可以改用内置启动，见[终末地启动](./终末地启动.md)。

## 5. 单 Mod 状态槽位

选中 Mod，打开右侧“状态槽位”页，可以把这个 Mod 当前的 `global persist` 参数保存为命名槽位，每个 Mod 可以有多个；还可以写入 Mod 默认值、导入变体文件、保存整份 `d3dx_user.ini` 快照，以及在游戏运行时热应用（实验）。完整说明见[状态槽位](./状态槽位.md)。

## 6. 快捷键模块与置顶浮窗

左侧“快捷键”模块列出 Mod INI 中的按键绑定，点击即可发送到游戏窗口；置顶浮窗（Ctrl + Alt + K）可以在游戏画面上使用，切换已启用的 Mod、保存组合预设或单 Mod 预设（保存前自动发送 F10）、刷新、热切换状态槽位，并能跟随出场角色。终末地需要以管理员身份运行管理器。完整说明见[快捷键与浮窗](./快捷键与浮窗.md)。

## 7. 组合预设与组合包

在仓库顶部打开“组合预设”，保存当前启用的 Mod 组合，可同时保存 `d3dx_user.ini` 参数；恢复时先恢复组合，再回写参数。组合包可以把预设连同 Mod 文件导出，在另一个仓库安装。完整说明见[组合预设](./组合预设.md)。

## 8. 在线浏览与下载

“在线”页按角色浏览 GameBanana Mod，支持收藏角色和作者、稍后下载、批量下载、搜索排序、详情与高清图片，下载后自动解压安装并记录来源；下载任务在“更新”页集中查看。完整说明见[浏览与下载](./浏览与下载.md)。

程序不会绕过登录、验证码、付费、订阅、权限验证或作者限制；访问要求提示只是尽力识别，以作者原页面为准。

## 9. 更新模块：Mod 更新、安全与任务

### 9.1 已追踪 Mod 更新

在线安装成功后会记录远程 ID、来源链接、预览图和更新时间。更新页可以手动检查，或按每天、每 3 天、每周自动检查；有更新时提示，可以“下载并替换”（先备份旧文件）。删除追踪记录不会删除本地 Mod。

### 9.2 冲突检测

安装或应用方案前会检查目标路径和 INI 冲突。发现冲突时先确认来源与优先级，避免不同 Mod 覆盖同一文件或同一按键。失效的目录联接会被识别并可以清理。

### 9.3 安装备份与回滚

- 部署、移除和方案切换会创建事务备份，失败自动恢复；也可以手动撤销最近变更。
- 备份列表显示时间、涉及的 Mod 和占用空间，可手动恢复。设置中可以把备份上限设为 0.5–100 GB，超出时按时间清理。
- 参数写入另有备份（`d3dx_user.ini.imm-persist-*.bak`、`.imm-snapshot-*.bak`），位于参数文件旁。撤销部署不会撤销参数。

### 9.4 下载任务中心

查看下载、解压的进度和结果，取消任务、重试失败任务、打开输出目录或清理记录。

## 10. 软件更新

- 可在设置中开启或关闭“启动时检查软件更新”。发现新版本会先询问，不会静默安装。
- 确认后自动下载 Release ZIP、显示进度并校验，由独立的更新组件替换文件后重启；仓库、路径、界面设置、Mod 说明、预设、槽位和 SQLite 数据会保留。
- 更新前保留旧文件，新版本启动失败时自动回滚。更新器支持超过 260 个字符的路径。
- 也可以把规范命名的新版 ZIP 放到程序根目录，重启后程序会识别并询问。
- 请使用与 ZIP 文件名完全对应的 `.zip.sha256` 校验。

## 11. 设置、数据与隐私

### 11.1 界面与辅助功能

中文/English、深色/浅色主题和高对比度、舒适/紧凑密度、减少动效、Tab 导航、屏幕阅读器名称和 Windows 缩放。窗口最大化后还原会缩到屏幕工作区的 80% 并居中。

### 11.2 本地数据

主要数据位于 `WinUI3` 目录：

| 文件或目录 | 内容 |
| --- | --- |
| `config.ini` | 主题、语言、快捷键说明、Mod 链接和在线安装来源 |
| `beta-shell.json` | 仓库、当前页面、在线分类、更新选项、组合预设 `ConfigurationProfiles` 和状态槽位 `ModPersistentSlots` |
| SQLite 数据库（`cache/app-index.db`） | 在线分页、角色目录、详情、指标、收藏、版本和文件索引 |
| `cache/online-images` | 在线图片缓存，可删除后重新生成 |
| `snapshots/user-ini` | 整份 `d3dx_user.ini` 快照 |
| `backups` | 配置备份、安装事务备份、软件更新备份和终末地启动记录 |
| `diagnostics` | 本地诊断，例如快捷键发送记录 |

配置写入采用临时文件替换和轮换备份；主配置损坏时会尝试恢复最近的有效备份。加载器的 `d3dx_user.ini` 不一定在程序目录，请选择实际使用的文件并单独备份。

### 11.3 诊断报告

“一键导出诊断报告”收集程序版本、系统摘要、错误日志和脱敏配置摘要，排除本机隐私路径和访问凭据。也可以打开预填的 GitHub Issue；程序不会自动提交，上传前请自行检查。

## 13. 常见问题

- **在线列表为空或加载失败**：确认分类 ID 正确、网络能访问 GameBanana；429 表示限流，请等待后再刷新。在线页加载慢时可能需要代理。
- **下载量暂时显示为 0**：部分列表接口不返回下载量，程序会通过详情回填，网络受限时先显示缓存或 0。
- **RAR、7Z 或 ZIPX 无法解压**：确认 `WinUI3/Tools/7z.exe`、`7z.dll` 未被删除或隔离，并检查压缩包是否加密、损坏或缺少分卷。
- **部署后状态又变成未部署**：部署是开关操作，已存在同名目录时再次操作会移除。
- **预览图不显示**：把图片命名为 `preview.png` 或 `cover.jpg`，或选中 Mod 后拖入预览区。
- **快捷键发送后游戏没反应**：终末地需要以管理员身份运行管理器，见[快捷键与浮窗](./快捷键与浮窗.md#排查)。
- **更新失败**：确认程序目录可写、ZIP 完整且没有在压缩包内运行。更新器会尝试回滚；仍无法启动时，从 Releases 完整解压新版，先备份再迁移旧配置。

## 14. 安全与使用边界

- 本工具不包含游戏文件或 Mod 内容；第三方 Mod 与加载器可能导致账号处罚或封禁。
- 不绕过支付、订阅、登录、权限验证、作者限制或平台规则。
- 在线识别、翻译和自动解压是辅助功能，重要说明以原作者页面为准。安装来源不明的 Mod 前请检查并扫描。
- 分享截图、配置或诊断信息前，确认没有暴露个人路径、账号或访问凭据。

**功能状态（4.6.0）**：目录联接部署、恢复到加载器和组合预设为已验证的稳定功能；导入变体文件尚待用真实导出文件验证；F10 热应用和在线自动翻译仍为实验功能。
