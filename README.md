# 集成化 Mod 管理器

适用于 Windows 10/11 的 WinUI 3 Mod 管理工具。它以“仓库”为单位管理本地 Mod，支持两层目录浏览、复制切换、压缩包导入、图片预览、快捷键说明、在线 Mod 浏览与下载，以及已安装 Mod 的更新追踪。

## 软件作用

集成化 Mod 管理器用于解决以下问题：

- 将散落的 Mod 按游戏、角色或用途整理进多个独立仓库。
- 在“Mod 存储文件夹”和游戏实际读取的“目标文件夹”之间快速复制或移除 Mod。
- 不打开资源管理器也能创建、重命名分类，删除选中的 Mod，并导入常见压缩包。
- 为每个 Mod 保存预览图、来源链接、快捷键和功能描述。
- 从 GameBanana 浏览在线 Mod，查看图片与说明，并下载、解压到本地仓库。
- 记录通过在线模块安装的 Mod，检查其页面是否发布了更新。
- 在同一程序内管理多个游戏或多套 XXMI 配置。

## 系统要求

- Windows 10 1809 或更高版本，推荐 Windows 11。
- 64 位 Windows（`x64`）。
- 在线 Mod、翻译和更新检查需要网络连接。
- 发布包采用自包含 WinUI 3 构建，普通用户通常不需要单独安装 .NET SDK 或 Visual Studio。

## 下载与运行

1. 打开 [Releases](https://github.com/uyujkk/Integrated_Mod_Manager/releases/latest)。
2. 下载最新的 `Integrated_Mod_Manager-vX.X.X.zip`。
3. 将压缩包完整解压到一个可写文件夹，不要直接在压缩包内运行。
4. 双击根目录中的 `ModFolderCopier.exe`。
5. 首次启动后创建或编辑仓库，并设置 Mod 存储文件夹、目标文件夹和可选启动器。

`ModFolderCopier.exe` 是启动入口，实际 WinUI 程序位于 `WinUI3/ModFolderCopier.WinUI.exe`。请保留发布包原有目录结构。

发布包根目录中的 `LocalUpdateAgent.exe` 是本地更新组件。不要单独运行或删除它；主程序只会在用户确认本地更新后调用该组件。

### SmartScreen 提示

当前程序没有商业代码签名证书，Windows SmartScreen 可能显示“发布者未知”。源码和构建脚本均公开在本仓库。请只从本项目 Releases 下载；确认来源可信后，可在 SmartScreen 中选择“更多信息”再决定是否运行。不要为了运行本工具关闭 Microsoft Defender。

## 推荐目录结构

每个仓库使用两层目录：

```text
Mod 存储文件夹
├─ 角色或分类 A
│  ├─ Mod A1
│  ├─ Mod A2
│  └─ Mod A3
├─ 角色或分类 B
│  ├─ Mod B1
│  └─ Mod B2
└─ 角色或分类 C
   └─ Mod C1
```

- 第一层文件夹是分类，例如游戏、角色或服装类型。
- 第二层文件夹是程序实际复制、移除、预览和记录信息的 Mod。
- 目标文件夹通常是 XXMI 或游戏会读取的 Mods 目录。

## 快速开始

1. 在左侧进入“仓库”模块，新建或选择一个仓库。
2. 设置“Mod 仓库”为上面两层结构的根目录。
3. 设置“目标文件夹”为游戏或 Mod 加载器实际读取的目录。
4. 可选设置启动器 EXE，例如 XXMI Launcher。
5. 点击“刷新目录”。
6. 选择第一层分类，再选择第二层 Mod。
7. 双击第二层 Mod 或点击复制按钮进行切换。

切换规则：

- 目标文件夹中没有同名目录时，程序会把整个第二层 Mod 文件夹复制过去。
- 目标文件夹中已经存在同名目录时，再次操作会将目标中的同名 Mod 移除。
- 删除源仓库中的第二层 Mod 是另一项独立操作，执行前会弹出确认窗口。

## 界面与工作流程

### 仪表板

仪表板显示全部仓库或当前仓库的概况，包括分类数、Mod 数和路径是否可用。它适合在多个游戏仓库之间快速确认配置状态。

### 仓库与本地 Mod

每个仓库可以独立保存：

- 仓库名称。
- Mod 存储文件夹。
- 目标文件夹。
- 外部启动器路径。
- GameBanana 来源、目标游戏和皮肤分类 ID。
- 仓库备注。

第一层区域支持搜索、新建和重命名分类。第二层区域用于选择具体 Mod，并支持删除、复制切换和拖放压缩包。

### 压缩包导入

当前支持：

```text
.zip  .zipx  .7z  .rar  .cab
.tar  .tar.gz  .tar.bz2  .tar.xz  .tar.zst
.gz   .tgz     .bz2      .xz      .zst
```

导入方式：

- 顶部“导入到当前选中文件夹”会导入到当前第一层分类。
- 选择第一层分类后，可把压缩包拖到第二层区域自动导入。
- 在线页面下载完成后，会创建独立文件夹并自动解压。

解压规则：

- `.zip` 使用程序内置解压。
- `.7z`、`.rar`、`.zipx`、`.cab` 使用发布包内的 7-Zip。
- `.tar`、`.gz`、`.tgz`、`.bz2`、`.xz`、`.zst` 和 `.tar.*` 使用 Windows `tar.exe`。
- 如果压缩包只有一个顶层文件夹，会优先保留该文件夹结构；散文件或多个目录会整理到新 Mod 文件夹。

### 快捷键与描述

- 每个第二层 Mod 可保存最多 10 行快捷键和功能描述。
- 点击快捷键输入框后直接按键，程序会读取并显示按键。
- 支持 `1`、`Q`、`F1` 等单键。
- 支持 `Ctrl+1`、`Shift+F2`、`Alt+Q` 等组合键。
- 支持 `/`、`;`、`[`、`]`、`\` 等符号键。
- 该区域用于记录 Mod 自身的按键说明，不会向 Windows 注册全局热键。

### 图片预览与 Mod 链接

程序会优先查找：

```text
preview.*  cover.*  thumbnail.*  image.*
```

如果没有这些文件，会尝试显示 Mod 文件夹中的第一张受支持图片。支持 `.png`、`.jpg`、`.jpeg`、`.bmp`、`.gif` 和 `.webp`。

先选择第二层 Mod，再把图片从资源管理器拖入预览区，即可复制并设置预览图。预览区下方可为当前 Mod 保存网页链接，并通过系统默认浏览器快速访问。

## 在线 Mod 浏览

在线模块当前主要接入 GameBanana：

1. 在“设置”中选择当前仓库并打开在线分类配置。
2. 填写来源站点、目标游戏和 GameBanana 皮肤分类 ID。
3. 打开“在线”模块并刷新列表。
4. 使用角色筛选、关键词搜索、排序和分页定位 Mod。
5. 在右侧独立详情面板查看预览图、简介、访问要求和下载入口。
6. 选择本地目录后下载并解压。

不同游戏的分类命名可能不同。当前程序会放行分类名称中包含 `Skins` 的条目，而不是只接受名称完全等于 `Skins` 的分类。

在线列表支持按热度、下载量、点赞量、查看量和更新时间排序。当前热度分最高为 10 分，计算方式为：

```text
min(10, 2 × (
    0.55 × log10(下载量 + 1)
  + 0.30 × log10(点赞量 + 1)
  + 0.15 × log10(查看量 + 1)
))
```

在线内容处理属于尽力识别：

- 程序会查找 Patreon、订阅、付费、点赞解锁、限时免费等文字，并在详情或下载状态中提示可能的额外访问要求。
- 程序会尝试从介绍文本提取快捷键与功能描述。
- 中文界面下会尝试翻译功能描述；英文界面保留原文。
- 网站页面结构、限流、登录、验证码、作者自定义下载方式或网络环境都可能导致识别或下载失败。
- 程序不会绕过付费、订阅、权限验证或 Mod 作者设置的访问限制。

## Mod 更新与软件更新

通过在线模块成功下载的 Mod 会记录页面链接、远程 ID、预览图和上次更新时间。“更新”模块可以：

- 手动检查所有已追踪 Mod。
- 设置每天、每 3 天、每周或仅手动检查。
- 自动合并重复的来源记录。
- 打开在线页面或本地文件夹。
- 删除某一条追踪记录；这不会删除本地 Mod 文件。

“设置”中的软件更新检查会读取 GitHub 最新 Release，显示版本号和更新说明，并打开 Release 页面。下载新版 ZIP 后，也可以直接把它放到当前程序文件夹；下次启动时程序会识别版本并询问是否更新。确认后主程序会退出，由独立更新组件替换文件并重新启动。

## 配置与备份

程序会在 `WinUI3` 运行目录保存本地配置：

- `config.ini`：主题、语言、快捷键、Mod 链接和在线安装来源等。
- `beta-shell.json`：仓库列表、当前页面、在线分类和更新检查设置等。
- `startup.log`：仅在启动器需要记录启动问题时出现。

本地 ZIP 更新会自动保留 `config.ini` 和 `beta-shell.json`。手动移动程序前仍建议备份；这些文件可能包含本机目录路径，不应在提交 Issue、分享截图或上传压缩包时公开。

## 常见问题

### 双击 Mod 后为什么变成“未复制”？

复制操作是开关行为。目标目录已存在同名 Mod 时，再次双击会移除目标目录中的该 Mod。

### 在线列表为空怎么办？

检查仓库的目标游戏和分类 ID，确认分类名称包含 `Skins`，然后检查网络是否能访问 GameBanana。网站限流时可稍后重试。

### RAR 为什么无法解压？

请确认发布包中的 `WinUI3/Tools/7z.exe` 和 `7z.dll` 没有被删除或隔离，并确保压缩包本身未损坏或加密。

### 预览图没有显示怎么办？

优先把图片命名为 `preview.png` 或 `cover.jpg`，也可以选择 Mod 后直接拖入预览区。

### 更新检查会自动安装吗？

不会静默安装。把下载的新版发布 ZIP 放进现有程序文件夹后，下次启动会询问是否安装，必须由用户确认才会更新。
