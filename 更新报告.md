# 集成化 Mod 管理器 v3.8.0 更新报告

> **重要更新 / Major Update**

- 显示版本：`v3.8.0`
- 文件版本：`3.8.0.0`
- 工具作者：`uyujkk`

## 中文

本次版本集中修复代码审查中发现的高风险边界问题，并为后续稳定迭代建立自动化测试与持续集成基础。

### 安全与可靠性

- 压缩包导入会验证所有解压路径，拒绝目录穿越、符号链接和硬链接。
- 文件夹复制、删除和更新替换会阻止重解析点越界，避免操作离开用户选定目录。
- 在线预览图限制请求时长、内容类型和文件大小，过期请求可被取消。
- SQLite、配置恢复、备份清理和关键异常增加明确日志与失败保护。

### 自动更新

- 更新包必须符合正式发布目录结构，并包含可验证的新版本主程序。
- SHA-256 校验结果必须对应当前下载包文件名，防止误用其他文件的哈希。
- 发布包包含托管文件清单，更新时可清理不再使用的旧程序文件，同时保留用户配置、缓存和数据库。
- 新版本无法启动时自动恢复上一版本并重新启动。

### 测试与工程质量

- 新增 `IntegratedModManager.Core` 可测试生产代码库。
- 新增 13 项 xUnit 自动化测试，覆盖路径边界和校验文件解析。
- 新增 GitHub Actions，在每次推送和拉取请求时自动测试并构建 WinUI x64 应用。
- 应用、启动器和本地更新组件统一升级为 `v3.8.0`。

## English

This major update resolves high-risk boundary issues found during code review and adds automated testing and continuous integration for safer future releases.

### Security and reliability

- Archive imports validate every extraction path and reject traversal, symbolic links, and hard links.
- Folder copy, deletion, and update replacement prevent reparse-point escapes outside user-selected locations.
- Online previews enforce request timeouts, media types, and file-size limits, and obsolete requests can be cancelled.
- SQLite, configuration recovery, backup cleanup, and critical exception paths now provide clearer logging and failure protection.

### Automatic updates

- Update archives must match the official release layout and contain a verifiable newer runtime.
- SHA-256 entries must match the downloaded package filename, preventing a hash for another file from being accepted.
- A managed-file manifest removes obsolete application files while preserving user configuration, caches, and databases.
- If the updated runtime fails to start, the updater restores and relaunches the previous version.

### Tests and engineering quality

- Added the testable production library `IntegratedModManager.Core`.
- Added 13 xUnit tests covering path boundaries and checksum-file parsing.
- Added GitHub Actions to run tests and build the WinUI x64 application on every push and pull request.
- Unified the application, launcher, and local updater at `v3.8.0`.
